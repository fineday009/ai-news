## 8. JustVugg/colibri

⭐ 19.7k（本周持续上榜）· C · [链接](https://github.com/JustVugg/colibri)

**是什么**：在 25GB 内存的消费级机器上运行 GLM-5.2（744B MoE）——纯 C、零依赖，专家权重从磁盘按需流式加载。

**What it is**: Run GLM-5.2 (744B MoE) on a 25GB-RAM consumer machine — pure C, zero dependencies, experts streamed from disk.

**为什么值得关注**：本周本地推理方向最亮眼的项目之一。它靠「把专家权重留在磁盘、按需换入」把跑前沿 MoE 模型的内存门槛砍到消费级，纯 C 无依赖让它几乎在任何机器上都能编译。这对「不想上云、只想本地摸大模型」的开发者极具吸引力。

**Why it matters**: One of the standout local-inference projects this week. By keeping expert weights on disk and paging them in on demand, it slashes the memory bar for running a frontier MoE model down to consumer hardware, and pure-C-no-deps means it compiles almost anywhere. Deeply appealing to developers who'd rather run giant models locally than in the cloud.
