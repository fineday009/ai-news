## 2. DeusData/codebase-memory-mcp

⭐ 23.9k（本周 +9,697）· C · [链接](https://github.com/DeusData/codebase-memory-mcp)

**是什么**：一个高性能代码智能 MCP 服务器，用 tree-sitter 解析上百种语言，把代码库索引成持久知识图谱（函数调用、导入、依赖），再通过 MCP 供编码智能体查询。

**What it is**: A high-performance code-intelligence MCP server that parses hundreds of languages with tree-sitter, indexes a codebase into a persistent knowledge graph of calls, imports, and dependencies, and serves it to coding agents over MCP.

**为什么值得关注**：它不内嵌 LLM，而是复用你正在用的 agent，号称索引大型仓库仅数分钟、查询亚毫秒、token 消耗大幅下降，还有类型解析、图查询与可视化。单文件静态二进制、带构建证明——给智能体装「代码记忆」这件事，它做得相当工程化，本周近万星。

**Why it matters**: Rather than embedding an LLM, it leverages the agent you already use — claiming a few-minute index of large repos, sub-millisecond queries, and far fewer tokens — with type resolution, graph queries, and visualization. A single static binary with build attestation makes giving agents "code memory" a genuinely engineered affair, adding nearly 10k stars this week.

**Why it matters**: It positions itself as an abstraction layer, not a point-in-time scraper — when a platform changes access rules, it auto-routes to a fallback backend, folding the long-term chore of "keeping internet access working" into one package. This is the pipe that moves agents from reading local files to reading the whole web, up nearly 9k stars this week.
