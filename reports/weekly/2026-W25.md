## 2. chopratejas/headroom

⭐ 30,145（本周 +9,766）· Python · [链接](https://github.com/chopratejas/headroom)

**是什么**：在工具输出、日志、文件和 RAG 片段抵达 LLM 之前先压缩它们，号称可节省 60%+ 的上下文。

**What it is**: Compresses tool outputs, logs, files, and RAG chunks before they reach the LLM, claiming 60%+ context savings.

**为什么值得关注**：Agent 时代最贵的资源是上下文窗口，冗长的工具回显和日志会迅速吃光 token 预算。headroom 在「喂给模型之前」做一道压缩，直接降本提速，是 Agent 流水线里立竿见影的中间件，本周 +9,766。

**Why it matters**: In the agent era the priciest resource is the context window, and verbose tool echoes and logs burn the token budget fast. headroom inserts a compression pass "before the model sees it," cutting cost and latency immediately—a high-leverage piece of agent middleware, +9,766 this week.

⭐ 9,198（本周 +709）· Python · [链接](https://github.com/LMCache/LMCache)

**是什么**：号称「最快的 KV 缓存层」，为 LLM 推理加速。

**What it is**: LMCache—a KV cache layer billed as the fastest, to supercharge LLM inference.

**为什么值得关注**：长上下文与多轮对话里，重复计算 KV cache 是推理成本的大头。LMCache 通过跨请求复用与高效存取把这部分省下来，对自建推理服务、做高并发应用的团队是实打实的吞吐与成本优化。

**Why it matters**: With long contexts and multi-turn chats, recomputing the KV cache dominates inference cost. LMCache reuses it across requests with efficient storage, delivering real throughput and cost wins for teams self-hosting inference at high concurrency.
