## 2. chopratejas/headroom

⭐ 31,758（本周 +9,475）· Python · [链接](https://github.com/chopratejas/headroom)

**是什么**：在工具输出、日志、文件和 RAG 片段抵达 LLM 之前先压缩它们，号称少用 60–95% 的 token 而答案不变。提供库、代理和 MCP 服务器三种形态。

**What it is**: Compresses tool outputs, logs, files, and RAG chunks before they reach the LLM—claiming 60-95% fewer tokens with the same answers. Available as a library, proxy, and MCP server.

**为什么值得关注**：Agent 跑得越久，上下文成本越失控，headroom 直接卡在「数据进 LLM 之前」这道关上做压缩，三种接入形态降低了落地门槛，是当下省 token 赛道里最实用的工具之一。

**Why it matters**: The longer an agent runs, the more context cost spirals; headroom intercepts right before data hits the LLM, and its three deployment forms lower the adoption bar—one of the most practical tools in the token-saving race.
