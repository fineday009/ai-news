## 2. chopratejas/headroom

⭐ 34.8k（本周新增） · Python · [链接](https://github.com/chopratejas/headroom)

**是什么**：在工具输出、日志、文件和 RAG 片段进入 LLM 之前先压缩它们，号称减少 60–95% 的 token。

**What it is**: Headroom compresses tool outputs, logs, files, and RAG chunks before they reach the LLM, claiming 60–95% fewer tokens.

**为什么值得关注**：长上下文 Agent 最大的隐形成本就是「喂进去的垃圾太多」——冗长日志、重复文件吃掉 token 也拖慢响应。Headroom 在入口处做压缩，直接砍成本，对跑大量 Agent 的团队是立竿见影的省钱利器。

**Why it matters**: The biggest hidden cost of long-context agents is feeding in junk — verbose logs and repetitive files burn tokens and slow responses. Compressing at the entry point cuts cost directly, an immediate money-saver for teams running agents at volume.

## 3. LMCache/LMCache

⭐ 9.3k（本周新增） · Python · [链接](https://github.com/LMCache/LMCache)

**是什么**：为 LLM 打造的「最快 KV 缓存层」，复用历史计算的键值缓存以加速推理。

**What it is**: LMCache is a fast KV-cache layer for LLMs that reuses previously computed key-value caches to speed up inference.

**为什么值得关注**：当多个请求共享相同前缀（系统提示、长文档、RAG 上下文）时，重复计算 KV 缓存是巨大浪费。LMCache 把这些缓存跨请求、跨实例复用，对高并发、长上下文的推理服务能显著降本提速，是 LLM 服务栈里越来越关键的一环。

**Why it matters**: When many requests share the same prefix (system prompts, long documents, RAG context), recomputing the KV cache is huge waste. LMCache reuses those caches across requests and instances, meaningfully cutting cost and latency for high-throughput long-context serving — an increasingly critical piece of the LLM serving stack.

**是什么**：Epic Games 开源的下一代版本控制系统，用 Rust 编写，专为「代码 + 大体积二进制资产」的项目优化（游戏、影视等）。

**What it is**: Lore is Epic Games' next-generation, open-source version control system, written in Rust and optimized for projects that combine code with large binary assets, including games and entertainment.

**为什么值得关注**：Git 处理大体积二进制资产一直很吃力，而游戏开发恰恰满是几个 GB 的美术资源。Lore 用内容寻址 + 分块存储 + 按需拉取（不必整库克隆）从架构上解决这个痛点，目前已有 CLI、服务端和 JS/Python/C#/Go 多语言 SDK，处于 1.0 前的活跃开发期。出自 Epic，分量十足。

**Why it matters**: Git struggles with large binary assets, and game development is full of multi-gigabyte art. Lore tackles this architecturally with content-addressed, chunked storage and on-demand hydration (no full clone), and already ships a CLI, server, and JS/Python/C#/Go SDKs in active pre-1.0 development. Coming from Epic, it carries real weight.
