## 5. ogulcancelik/herdr

⭐ 14.9k（本周 +4,756）· Rust · [链接](https://github.com/ogulcancelik/herdr)

**是什么**：一个住在你终端里的「Agent 多路复用器」。

**What it is**: An agent multiplexer that lives in your terminal.

**为什么值得关注**：当你同时跑好几个编码 Agent，管理它们本身就成了负担。herdr 用 Rust 写成，像 tmux 之于终端一样，把多个并行 Agent 的调度、观察与切换收进一个界面。随着「一人指挥一队 Agent」成为常态，这类编排工具正快速成为刚需。

**Why it matters**: When you run several coding agents at once, managing them becomes its own chore. Written in Rust, herdr is to agents what tmux is to terminals — scheduling, watching, and switching between parallel agents in one interface. As "one human directing a fleet of agents" becomes normal, orchestration tools like this are fast becoming essential.
