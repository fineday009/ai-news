## 2. block/buzz

⭐ 25,002（本周 +5,746）· Rust · [链接](https://github.com/block/buzz)

**是什么**：Block（原 Square）开源的自托管协作平台——人与 AI 代理在共享房间里协作。底层是一个 Nostr relay，消息、代码补丁、工作流步骤与 git 事件汇成统一事件日志，自带搜索与审计。代理能和人一样开仓库、发补丁、评审代码、跑工作流。

**What it is**: A self-hostable collaboration platform from Block (formerly Square) where humans and AI agents work in shared rooms. Built on a Nostr relay, it fuses messages, code patches, workflow steps, and git events into one event log with search and audit trails—agents can open repos, send patches, review code, and run workflows using the same tools as human teammates.

**为什么值得关注**：多数「AI 协作」工具把代理当外挂；buzz 反过来把人和代理放进同一套权限与事件流里，是对「团队里代理是一等公民」这一命题最认真的开源实现之一，且由 Block 这样的正规军操刀。

**Why it matters**: Most "AI collaboration" tools bolt agents on as add-ons; buzz instead puts humans and agents into the same permission and event stream—one of the most serious open-source takes on "agents as first-class teammates," and from a heavyweight like Block.
