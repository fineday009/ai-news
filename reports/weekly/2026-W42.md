## 2. NandhaKishorM/laya

⭐ 32.9k · 2026-09-18 新建 · Python · [链接](https://github.com/NandhaKishorM/laya)

**是什么**：一个"非自回归的 System 1 决策引擎"——不生成文本，而是用小型编码模型在"单次前向"里对文本做分类（choice）、打分（score）、是非判断（yes/no），支持 100+ 语言，附带可校准的置信度。

**What it is**: A "non-autoregressive System 1 decision engine" — instead of generating text, a small encoder model makes choice, score and yes/no decisions over text in a single forward pass, across 100+ languages, with calibrated confidence values.

**为什么值得关注**：它瞄准了一个被大模型"大材小用"的高频场景——路由、护栏、内容审核、工单分流等只需要"判断"而非"写作"的任务。单题约 33ms（批处理约 7ms），"没有文本生成，就没有东西需要解析、也没有东西可以幻觉"，这是把 LLM 从决策链路里换下来的务实思路。

**Why it matters**: It targets a high-frequency job where big LLMs are overkill — routing, guardrails, moderation, ticket triage and other tasks that need a judgment, not prose. At ~33ms per question (~7ms batched) and "no text generation, so nothing to parse and nothing to hallucinate," it's a pragmatic way to swap LLMs out of the decision loop.

## 3. browser-use/jev-ultrafast

⭐ 22.9k · 2026-09-16 新建 · Python · [链接](https://github.com/browser-use/jev-ultrafast)

**是什么**：来自 Browser Use 团队的"最快、最便宜"网页 Agent——每次观测把页面元素编号成表格，模型只从表里选"操作 + 目标"（点击/输入/滚动），默认不看截图、只读结构化 DOM，每步只需一次模型请求。

**What it is**: The "fastest and cheapest" web agent from the Browser Use team — each observation turns page elements into a numbered table, and the model just picks an operation and target (click/type/scroll) from it; by default it reads structured DOM rather than screenshots, needing only one model request per decision.

**为什么值得关注**：它用"固定且经校验的动作空间"换来了速度和确定性——模型从不输出选择器、坐标或 JS，一次苏黎世到伦敦的航班查询自称约 7.1 秒完成。在人人都想让 Agent"又快又省"操作浏览器的当下，这种极简架构给出了可复现的工程答案。

**Why it matters**: It trades a fixed, validated action space for speed and determinism — the model never emits selectors, coordinates or JS, and a Zürich→London flight search reportedly finishes in ~7.1 seconds. As everyone wants agents to drive browsers fast and cheap, this minimalist architecture is a reproducible engineering answer.
