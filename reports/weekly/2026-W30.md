## 2. JustVugg/colibri

⭐ 18.7k · C · [链接](https://github.com/JustVugg/colibri)

**是什么**：一个纯 C、零依赖的推理引擎，能在约 25GB 内存的消费级机器上跑 GLM-5.2（744B MoE）——把专家从磁盘按需流式加载。

**What it is**: A pure-C, zero-dependency inference engine that runs GLM-5.2 (a 744B-parameter MoE) on a ~25GB-RAM consumer machine by streaming experts from disk.

**为什么值得关注**：把 VRAM、内存与存储当成一整套"内存层级"统一调度，让前沿规模的模型在普通电脑上无损运行——不砍精度、不改路由。这是本地推理"以小博大"的又一次硬核突破。

**Why it matters**: It treats VRAM, RAM and disk as one managed memory hierarchy, letting a frontier-scale model run losslessly on an ordinary PC — no precision cuts, no routing changes. Another hardcore "tiny engine, immense model" breakthrough for local inference.
