## 3. google/elephant-goldfish-model

⭐ 19.3k（本周 +5,539）· Python · [链接](https://github.com/google/elephant-goldfish-model)

**是什么**：Google 开源的 AI 助手插件，用 Agent 设计和评审软件："大象"掌握项目上下文并起草规格，"金鱼"评审者不带先前对话、以全新视角审查草稿。

**What it is**: Open-source plugin for designing and reviewing software with agents—"Design with an elephant. Review with a goldfish." The Elephant holds your project context and drafts the spec; Goldfish reviewers examine it without the earlier conversation.

**为什么值得关注**：本周 +5.5k 星，近三成星数来自这一周。长对话里的 Agent 容易被自己的上下文"带偏"，它把"写"和"审"拆给两种角色：金鱼评审者只看草稿和引用的源材料，专门暴露没说出口的假设和盲区，架构取舍与最终批准仍由人来做。支持 Claude Code、Codex、Antigravity 等多种 harness，也能直接拿现有设计文档或 PR 计划对照线上代码做一次 60 秒评审，还提供代码库与文档的漂移报告。

**Why it matters**: +5.5k stars this week, nearly 30% of its total. Agents deep in a long conversation get anchored by their own context, so it splits writing and reviewing between two roles: goldfish reviewers see only the draft and referenced sources, exposing unstated assumptions and blind spots, while a human still makes the architectural trade-offs and approves the spec. It works with Claude Code, Codex, Antigravity and other harnesses, can run a 60-second review of an existing design doc or PR plan against live code, and reports drift between code and docs.

## 4. vercel-labs/agent-browser

⭐ 51.3k（本周 +4,601）· Rust · [链接](https://github.com/vercel-labs/agent-browser)

**是什么**：给 AI Agent 用的浏览器自动化 CLI：打开页面、以无障碍树读取内容，并在 shell 里操作页面元素。

**What it is**: Browser automation CLI for AI agents: open pages, read them as an accessibility tree, and act on elements from the shell.

**为什么值得关注**：本周 +4.6k 星，总星数已过 5.1 万。原生 Rust CLI，`snapshot` 把页面压成紧凑文本，并给每个元素一个 `@e1` 这样的引用，Agent 按引用操作后再读一次页面确认结果。目标被遮挡、隐藏或禁用时点击会直接失败，而不是假装成功，堵住了 Agent 自动化常见的"以为点到了"问题。每个 `--session` 有独立的守护进程和浏览器，也能接管已运行的 Chrome。

**Why it matters**: +4.6k stars this week and now past 51k. A native Rust CLI whose `snapshot` compresses a page into compact text with a ref such as `@e1` for each element; the agent acts on a ref, then reads the page again to confirm the result. A click fails outright when the target is covered, hidden or disabled instead of reporting success, closing off the classic "agent thinks it clicked" failure. Each `--session` gets its own daemon and browser, and it can also attach to a running Chrome.

## 6. deepseek-ai/dsh-superagent-prototype

⭐ 23.2k · TypeScript · 创建于 2026-10-31 · [链接](https://github.com/deepseek-ai/dsh-superagent-prototype)

**是什么**：DeepSeek 团队放出的研究原型——一个面向单个 GitHub 仓库的"主动式"编码 Agent，打包成 DeepSeek Harness 的 bundle。它监听 GitHub（可选飞书），有授权的人提出需求时，它开一个工单、在独立会话和目录里完成工作，再回到原对话里交付（例如一个 PR）；网页面板只显示需要人处理的事项。

**What it is**: A research prototype from DeepSeek's team—"towards a more autonomous agent system": a proactive coding agent for one GitHub repository, packaged as a DeepSeek Harness bundle. It listens to GitHub (and optionally Feishu); when an allowed person asks for work, it opens a work item, does it in its own agent session and directory, and answers in the original conversation, e.g. with a pull request. A web panel shows only what needs a person.

**为什么值得关注**：11 月 1 日上日报时 3.1k 星，如今已达 2.32 万。核心理念是"占用尽量少的人类注意力、交付尽量多的价值"：只在被请求或团队写下的规则允许时行动，只在有人必须行动或能用上结果时开口。官方明确说这是研究代码、非正式产品，但它是前沿实验室公开"团队级自主 Agent"工作方式的一手样本。

**Why it matters**: It had 3.1k stars when it made the daily on November 1 and has 23.2k now. Its core principle is "take as little human attention as possible, give as much value as possible": it acts only when asked or when a team-written rule allows it, and speaks only when someone must act or can use a result. DeepSeek is explicit that this is research code, not an official product, but it's a first-hand look at how a frontier lab works with a team-level autonomous agent.
