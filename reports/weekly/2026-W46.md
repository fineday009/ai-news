## 3. vercel-labs/agent-desktop

⭐ 22.8k（本周 +6,414）· Rust · [链接](https://github.com/vercel-labs/agent-desktop)

**是什么**：给 AI Agent 用的电脑操作（computer use）CLI：通过操作系统的无障碍树（accessibility tree）读取并操作桌面应用。

**What it is**: Computer use CLI for AI agents — read and operate desktop apps through the OS accessibility tree.

**为什么值得关注**：本周 +6.4k 星，周榜涨星第四；11 月 3 日上日报时 1.02 万星，如今已达 2.28 万。主流 computer use 方案靠截图加像素匹配，又慢又脆。agent-desktop 改为对无障碍树做快照，每个可操作元素返回一个 ref，Agent 按 ref 操作、再快照校验，循环完全留在你自己的 Agent 里；同时提供 CLI 与 C 库，覆盖 macOS、Windows、Linux。它和同门的浏览器版 agent-browser（本榜第 6）一起，构成了"Agent 用文本而非像素操作界面"的一套工具。

**Why it matters**: +6.4k stars this week, fourth on the weekly chart; it had 10.2k when it made the daily on November 3 and is at 22.8k now. Mainstream computer-use approaches rely on screenshots and pixel matching, which is slow and brittle. agent-desktop snapshots the accessibility tree instead, returning a ref for every actionable element; the agent acts on a ref and snapshots again to verify, keeping the loop entirely inside your own agent. It ships as both a CLI and a C library across macOS, Windows and Linux, and together with its browser sibling agent-browser (#6 here) it forms a toolkit for agents that operate interfaces through text rather than pixels.

**是什么**：NVIDIA 开源的 Python 框架，在数据之上构建语义化、基于图的推理层，让 LLM 与 Agent 工作流能确定性地生成查询、更好地检索上下文、给出更可解释的结果。

**What it is**: Auto Ontology is a Python framework for building semantic, graph-based reasoning layers over data. It enables deterministic query generation, better context retrieval, and more explainable AI for LLM and agent workflows.

**为什么值得关注**：本周 +5.8k 星，11 月 5 日上日报时 5,330 星，如今已达 1.23 万。它瞄准"Agent 做数据分析时数字算错"这个瓶颈：从企业元数据自动生成本体、调和不同系统中互相矛盾的指标定义，用经过认证的定义和血缘校验 Agent 生成的查询，每个答案都附带出处，并通过 MCP、CLI 和 API 提供给任意 Agent harness。

**Why it matters**: +5.8k stars this week; it had 5,330 when it made the daily on November 5 and is at 12.3k now. It targets the reliability bottleneck of agentic analytics: generating ontologies from enterprise metadata, reconciling conflicting metric definitions across systems, validating agent-generated queries against certified definitions and lineage, returning provenance with every answer, and serving it all to any agent harness via MCP, CLI and API.

## 6. vercel-labs/agent-browser

⭐ 50.4k（本周 +4,601）· Rust · [链接](https://github.com/vercel-labs/agent-browser)

**是什么**：给 AI Agent 用的浏览器自动化 CLI：打开页面、以无障碍树读取内容，并在 shell 里操作页面元素。

**What it is**: Browser automation CLI for AI agents: open pages, read them as an accessibility tree, and act on elements from the shell.

**为什么值得关注**：本次新入选，本周 +4.6k 星，总星数已过 5 万。原生 Rust CLI，`snapshot` 把页面压成紧凑文本，并给每个元素一个 `@e1` 这样的引用，Agent 按引用操作后再读一次页面确认结果。目标被遮挡、隐藏或禁用时点击会直接失败，而不是假装成功，堵住了 Agent 自动化常见的"以为点到了"问题。每个 `--session` 有独立的守护进程和浏览器，也能接管已运行的 Chrome。

**Why it matters**: New this run, +4.6k stars this week and now past 50k. A native Rust CLI whose `snapshot` compresses a page into compact text with a ref such as `@e1` for each element; the agent acts on a ref, then reads the page again to confirm the result. A click fails outright when the target is covered, hidden or disabled instead of reporting success, closing off the classic "agent thinks it clicked" failure. Each `--session` gets its own daemon and browser, and it can also attach to a running Chrome.

## 9. deepseek-ai/dsh-superagent-prototype

⭐ 22.8k · TypeScript · 创建于 2026-10-31 · [链接](https://github.com/deepseek-ai/dsh-superagent-prototype)

**是什么**：DeepSeek 团队放出的研究原型——一个面向单个 GitHub 仓库的"主动式"编码 Agent，打包成 DeepSeek Harness 的 bundle。它监听 GitHub（可选飞书），有授权的人提出需求时，它开一个工单、在独立会话和目录里完成工作，再回到原对话里交付（例如一个 PR）；网页面板只显示需要人处理的事项。

**What it is**: A research prototype from DeepSeek's team—"towards a more autonomous agent system": a proactive coding agent for one GitHub repository, packaged as a DeepSeek Harness bundle. It listens to GitHub (and optionally Feishu); when an allowed person asks for work, it opens a work item, does it in its own agent session and directory, and answers in the original conversation, e.g. with a pull request. A web panel shows only what needs a person.

**为什么值得关注**：11 月 1 日上日报时 3.1k 星，如今已达 2.28 万。核心理念是"占用尽量少的人类注意力、交付尽量多的价值"：只在被请求或团队写下的规则允许时行动，只在有人必须行动或能用上结果时开口。官方明确说这是研究代码、非正式产品，但它是前沿实验室公开"团队级自主 Agent"工作方式的一手样本。

**Why it matters**: It had 3.1k stars when it made the daily on November 1 and has 22.8k now. Its core principle is "take as little human attention as possible, give as much value as possible": it acts only when asked or when a team-written rule allows it, and speaks only when someone must act or can use a result. DeepSeek is explicit that this is research code, not an official product, but it's a first-hand look at how a frontier lab works with a team-level autonomous agent.
