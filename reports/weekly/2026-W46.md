**Why it matters**: +7.9k stars this week; it had 5,330 when it made the daily on November 5 and is at 12.0k now. ## 4. vercel-labs/agent-desktop

⭐ 22.4k（本周 +7,772）· Rust · [链接](https://github.com/vercel-labs/agent-desktop)

**是什么**：给 AI Agent 用的电脑操作（computer use）CLI：通过操作系统的无障碍树（accessibility tree）读取并操作桌面应用。

**What it is**: Computer use CLI for AI agents — read and operate desktop apps through the OS accessibility tree.

**为什么值得关注**：本周 +7.8k 星，周榜涨星第五；11 月 3 日上日报时 1.02 万星，如今已达 2.24 万。主流 computer use 方案靠截图加像素匹配，又慢又脆。agent-desktop 改为对无障碍树做快照，每个可操作元素返回一个 ref，Agent 按 ref 操作、再快照校验，循环完全留在你自己的 Agent 里；同时提供 CLI 与 C 库，覆盖 macOS、Windows、Linux。它和同门的浏览器版 agent-browser 一起，构成了"Agent 用文本而非像素操作界面"的一套工具。

**Why it matters**: +7.8k stars this week, fifth on the weekly chart; it had 10.2k when it made the daily on November 3 and is at 22.4k now. Mainstream computer-use approaches rely on screenshots and pixel matching, which is slow and brittle. agent-desktop snapshots the accessibility tree instead, returning a ref for every actionable element; the agent acts on a ref and snapshots again to verify, keeping the loop entirely inside your own agent. It ships as both a CLI and a C library across macOS, Windows and Linux, and together with its browser sibling agent-browser it forms a toolkit for agents that operate interfaces through text rather than pixels.

## 6. herdrdev/herdr

⭐ 50.5k（本周 +2,213）· Rust · [链接](https://github.com/herdrdev/herdr)

**是什么**：你的编码 Agent 赖以运行的运行时。

**What it is**: The runtime your coding agents live on.

**为什么值得关注**：本次新入选。它不包装也不替代 Claude Code、Codex、Cursor、opencode 等 Agent，而是接管它们所在的终端：客户端关掉或 SSH 断线后终端仍在后台服务器里跑，重启后恢复布局并可续接支持的 Agent 会话；本地与多台 SSH 机器汇到一个窗口，每个窗格标注"工作中 / 卡住 / 空闲"。Agent 还能通过 CLI 和 socket API 自己开窗格、互相发提示、等待另一个 Agent 真正卡住。单个 Rust 二进制、无 Electron，适合同时开多个 Agent 的重度用户。

**Why it matters**: New this run. It doesn't wrap or replace Claude Code, Codex, Cursor, opencode and the rest—it owns their terminals. Terminals keep running in a background server when you close the client or lose SSH; after a restart it restores the layout and can resume supported agent sessions. Local work and saved SSH machines share one window, and every pane is marked working, blocked or idle. Agents can also drive it through the CLI and socket API to spawn panes, prompt each other and wait until another agent is genuinely blocked. One Rust binary, no Electron—built for people running many agents at once.

⭐ 38.6k（本周 +3,150）· [链接](https://github.com/Donchitos/Claude-Code-Game-Studios)

**是什么**：把 Claude Code 变成一个完整的游戏开发工作室——49 个 AI Agent、72 个工作流 skill。

**What it is**: Turn Claude Code into a full game dev studio — 49 AI agents, 72 workflow skills.

**为什么值得关注**：本次新入选。用法是在仓库里对 Claude Code 说一句想要的游戏（如"只在黄昏咬钩的稀有鱼"的钓鱼游戏），它先按类型问一轮问题、写一页游戏简报，确认后做出可双击打开的浏览器原型；交付前用无头浏览器跑脚本按键，检查报错、文字溢出和卡死，并把简报每一条标为已实现、缺失或损坏，交接卡上写明"尚未经真人试玩"。之后可以边玩边改、导出到 itch.io，或升级成带测试和构建的 Vite + TypeScript 项目逐个加功能。它把"Agent 自己验证产物"做成了完整流程。

**Why it matters**: New this run. You open Claude Code in the repo and describe a game (say, a fishing game where rare fish only bite at dusk); it asks one round of genre-specific questions, writes a one-page brief, and on your go-ahead builds a browser prototype that opens with a double-click. Before handing it over it plays scripted key presses in a headless browser to catch errors, overflowing text and freezes, marks every line of the brief built, missing or broken, and the handover card ends "Not yet played by a person." From there you change it by asking, export a clean copy for itch.io, or grow it into a Vite + TypeScript project with tests and a build, one feature at a time. It turns "the agent checks its own output" into a full workflow.

## 9. deepseek-ai/dsh-superagent-prototype

⭐ 22.6k · TypeScript · 创建于 2026-10-31 · [链接](https://github.com/deepseek-ai/dsh-superagent-prototype)

**是什么**：DeepSeek 团队放出的研究原型——一个面向单个 GitHub 仓库的"主动式"编码 Agent，打包成 DeepSeek Harness 的 bundle。它监听 GitHub（可选飞书），有授权的人提出需求时，它开一个工单、在独立会话和目录里完成工作，再回到原对话里交付（例如一个 PR）；网页面板只显示需要人处理的事项。

**What it is**: A research prototype from DeepSeek's team—"towards a more autonomous agent system": a proactive coding agent for one GitHub repository, packaged as a DeepSeek Harness bundle. It listens to GitHub (and optionally Feishu); when an allowed person asks for work, it opens a work item, does it in its own agent session and directory, and answers in the original conversation, e.g. with a pull request. A web panel shows only what needs a person.

**为什么值得关注**：11 月 1 日上日报时 3.1k 星，如今已达 2.26 万。核心理念是"占用尽量少的人类注意力、交付尽量多的价值"：只在被请求或团队写下的规则允许时行动，只在有人必须行动或能用上结果时开口。官方明确说这是研究代码、非正式产品，但它是前沿实验室公开"团队级自主 Agent"工作方式的一手样本。

**Why it matters**: It had 3.1k stars when it made the daily on November 1 and has 22.6k now. Its core principle is "take as little human attention as possible, give as much value as possible": it acts only when asked or when a team-written rule allows it, and speaks only when someone must act or can use a result. DeepSeek is explicit that this is research code, not an official product, but it's a first-hand look at how a frontier lab works with a team-level autonomous agent.
