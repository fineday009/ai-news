## 2. pingdotgg/t3code

⭐ 44.6k（本周 +12,542）· TypeScript · [链接](https://github.com/pingdotgg/t3code)

**是什么**：T3 Code——一个"Agent harness 控制面"：通过手机 App（iOS/Android）、网页端和 Electron 桌面端，控制你电脑上的各个编码 Agent。

**What it is**: T3 Code is an "agent harness control surface": control the agents on your machine from a mobile app (iOS, Android), a web app and an Electron desktop app.

**为什么值得关注**：本周 +1.25 万星，已反超 impeccable 成为周榜涨星第一。它不卖模型也不卖订阅——直接复用你电脑上已登录的 Claude Code、Codex、Cursor、OpenCode 等，统一在一个界面里调度，并且可以从手机远程接管。作者坦言是因为现有桌面 Agent 客户端达不到他们的标准才自己做，并且完全开源、可随时 fork。在"一个人同时用好几个 harness"成为常态的当下，它是多 Agent 控制台赛道里增长最快的一个。

**Why it matters**: +12.5k stars this week, overtaking impeccable as the week's top gainer. It sells neither models nor subscriptions—it reuses the Claude Code, Codex, Cursor, OpenCode and other installs already signed in on your machine, drives them from one interface, and lets you take over remotely from your phone. The authors say they built it because existing desktop agent clients didn't meet their bar, and kept it fully open so you can fork it anytime. With one person running several harnesses now the norm, it's the fastest grower among multi-agent consoles.

## 5. thedotmack/claude-mem

**是什么**：给任意 Agent 的跨会话持久记忆——捕获 Agent 在会话中做的一切，用 AI 压缩后，在之后的会话里注入相关上下文；支持 Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCode 等。

**Why it matters**: +8.0k stars this week to pass 112k. One of the biggest pains with coding agents is amnesia—every new session starts from zero. claude-mem distills sessions into a reusable memory layer that isn't tied to any one agent—worth even more now that running several harnesses at once is the norm.

## 7. deepseek-ai/dsh-superagent-prototype

⭐ 17.2k · TypeScript · 创建于 2026-10-31 · [链接](https://github.com/deepseek-ai/dsh-superagent-prototype)

**是什么**：DeepSeek 团队放出的研究原型——一个面向单个 GitHub 仓库的"主动式"编码 Agent，打包成 DeepSeek Harness 的 bundle。它监听 GitHub（可选飞书），有授权的人提出需求时，它开一个工单、在独立会话和目录里完成工作，再回到原对话里交付（例如一个 PR）；网页面板只显示需要人处理的事项。

**What it is**: A research prototype from DeepSeek's team—"towards a more autonomous agent system": a proactive coding agent for one GitHub repository, packaged as a DeepSeek Harness bundle. It listens to GitHub (and optionally Feishu); when an allowed person asks for work, it opens a work item, does it in its own agent session and directory, and answers in the original conversation, e.g. with a pull request. A web panel shows only what needs a person.

**为什么值得关注**：11 月 1 日上日报时上线一天 3.1k 星，四天后已达 1.72 万，是本周新建仓库里涨得最快的 AI 项目，并已带出 AnyModelBot 等借鉴其设计的衍生产品。核心理念是"占用尽量少的人类注意力、交付尽量多的价值"：只在被请求或团队写下的规则允许时行动，只在有人必须行动或能用上结果时开口。官方明确说这是研究代码、非正式产品，但它是前沿实验室公开"团队级自主 Agent"工作方式的一手样本。

**Why it matters**: It had 3.1k stars on day one when it made the daily on November 1 and reached 17.2k four days later—the fastest-growing new AI repo this week—already inspiring derivatives such as AnyModelBot that borrow its design. Its core principle is "take as little human attention as possible, give as much value as possible": it acts only when asked or when a team-written rule allows it, and speaks only when someone must act or can use a result. DeepSeek is explicit that this is research code, not an official product, but it's a first-hand look at how a frontier lab works with a team-level autonomous agent.
