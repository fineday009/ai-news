As more code is written by agents, having agents audit it is becoming standard.

**Why it matters**: +11.8k stars this week—the week's top gainer by raw stars—and it has now crossed 100k. It goes beyond prompts with installable skills, commands and deterministic detector rules, so an agent can check its own UI again and again. Peers hallmark (+10.5k this week) and taste-skill (+5.7k) are trending too, making "agent-built UIs that don't look AI-made" a category of its own, and impeccable leads it at 100.6k stars.

## 4. pingdotgg/t3code

⭐ 42.2k（本周 +9,770）· TypeScript · [链接](https://github.com/pingdotgg/t3code)

**是什么**：T3 Code——一个"Agent harness 控制面"：通过手机 App（iOS/Android）、网页端和 Electron 桌面端，控制你电脑上的各个编码 Agent。

**What it is**: T3 Code is an "agent harness control surface": control the agents on your machine from a mobile app (iOS, Android), a web app and an Electron desktop app.

**为什么值得关注**：本周新进榜，+9.8k 星，涨星数仅次于两个设计品味项目。它不卖模型也不卖订阅——直接复用你电脑上已登录的 Claude Code、Codex、Cursor、OpenCode 等，统一在一个界面里调度，并且可以从手机远程接管。作者坦言是因为现有桌面 Agent 客户端达不到他们的标准才自己做，并且完全开源、可随时 fork。在"一个人同时用好几个 harness"成为常态的当下，它是多 Agent 控制台赛道里增长最快的之一。

**Why it matters**: A new entry this week, +9.8k stars—behind only the two design-taste projects. It sells neither models nor subscriptions—it reuses the Claude Code, Codex, Cursor, OpenCode and other installs already signed in on your machine, drives them from one interface, and lets you take over remotely from your phone. The authors say they built it because existing desktop agent clients didn't meet their bar, and kept it fully open so you can fork it anytime. With one person running several harnesses now the norm, it's one of the fastest growers among multi-agent consoles.

## 5. thedotmack/claude-mem

⭐ 110.9k（本周 +7,255）· TypeScript · [链接](https://github.com/thedotmack/claude-mem)

**是什么**：给任意 Agent 的跨会话持久记忆——捕获 Agent 在会话中做的一切，用 AI 压缩后，在之后的会话里注入相关上下文；支持 Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCode 等。

**What it is**: Persistent context across sessions for every agent—captures everything your agent does during sessions, compresses it with AI, and injects relevant context back into future sessions. Works with Claude Code, OpenClaw, Codex, Gemini, Hermes, Copilot, OpenCode and more.

**为什么值得关注**：本周 +7.3k 星、突破 11 万。编码 Agent 最大的痛点之一是"失忆"：每开一个新会话就从零开始。claude-mem 把会话过程沉淀成可复用的记忆层，并且不绑定单一 Agent——在"一个人同时用好几个 harness"成为常态的当下，这种跨 Agent 的记忆层价值更大。

**Why it matters**: +7.3k stars this week to pass 110k. One of the biggest pains with coding agents is amnesia—every new session starts from zero. claude-mem distills sessions into a reusable memory layer that isn't tied to any one agent—worth even more now that running several harnesses at once is the norm.

## 7. JetBrains/thinkrail

⭐ 7.2k（本周 +4,812）· TypeScript · [链接](https://github.com/JetBrains/thinkrail)

**是什么**：JetBrains 推出的轻量 Agent IDE，围绕 `pi` 编码 Agent 打造，会随你的使用方式自我定制。

**What it is**: Vibe code with pi in a lightweight, real IDE that customises itself around the way you work—JetBrains' agentic IDE.

**为什么值得关注**：10 月 26 日上日报时只有 1.9k 星，本周一口气 +4.8k、升至 7.2k。老牌 IDE 厂商的新思路：不是把 Agent 塞进 IDE，而是围绕 Agent 重做一个 IDE。每个任务在独立的 git worktree 里并行跑，PR、CI 状态一键处理；项目意图写进一组互相关联的 `SPEC.md`"活规格"，由 Agent 用专用工具读写维护，跨会话不丢失。

**Why it matters**: It had 1.9k stars when it made the daily on October 26 and jumped +4.8k this week to 7.2k. A new approach from a veteran IDE vendor: rather than bolting an agent onto an IDE, it builds the IDE around the agent. Each task runs in parallel in its own git worktree, with PRs and CI handled in one click, and project intent lives in a connected graph of "living spec" `SPEC.md` files the agent reads and maintains through dedicated tools, so it survives across sessions.
