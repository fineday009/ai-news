For anyone letting agents write front-end code, it's guidance straight from the browser vendors.

## 4. vercel-labs/agent-browser

⭐ 52.4k（本周 +3,429）· Rust · [链接](https://github.com/vercel-labs/agent-browser)

**是什么**：给 AI Agent 用的浏览器自动化 CLI：打开页面、以无障碍树读取内容，并在 shell 里操作页面元素。

**What it is**: Browser automation CLI for AI agents: open pages, read them as an accessibility tree, and act on elements from the shell.

**为什么值得关注**：本周 +3.4k 星，总星数达 5.24 万。原生 Rust CLI，`snapshot` 把页面压成紧凑文本，并给每个元素一个 `@e1` 这样的引用，Agent 按引用操作后再读一次页面确认结果。目标被遮挡、隐藏或禁用时点击会直接失败，而不是假装成功，堵住了 Agent 自动化常见的"以为点到了"问题。每个 `--session` 有独立的守护进程和浏览器，也能接管已运行的 Chrome。

**Why it matters**: +3.4k stars this week, now at 52.4k. A native Rust CLI whose `snapshot` compresses a page into compact text with a ref such as `@e1` for each element; the agent acts on a ref, then reads the page again to confirm the result. A click fails outright when the target is covered, hidden or disabled instead of reporting success, closing off the classic "agent thinks it clicked" failure. Each `--session` gets its own daemon and browser, and it can also attach to a running Chrome.

As agents write more and more code, reviewable AI review is one of the most practical references for teams building their own review stack.

## 10. libracoder/kiri

⭐ 10.2k · Rust · 创建于 2026-11-02 · [链接](https://github.com/libracoder/kiri)

**是什么**：一个小巧、快速的容器运行时，支持 macOS、Windows 和 Linux，直接运行你的 Docker 镜像，兼容现有的 docker CLI、Compose 和 buildx。

**What it is**: A tiny, fast container runtime for macOS, Windows and Linux. Runs your Docker images and works with the docker CLI, Compose and buildx you already use.

**为什么值得关注**：11 月 13 日上日报时 1.7k 星，如今已过 1.02 万，是近两周新建仓库中涨得最快的基础设施项目之一。定位是 Docker Desktop 和 OrbStack 的轻量替代：用 Rust 写成，在一台小 Linux 虚拟机里（Linux 上直接用内核）跑容器并实现 Docker Engine API，现有工具照常可用。README 称通过 API 启动并退出一个容器约 2.5 ms、约为 Docker Desktop 的 80 倍快，守护进程约 15 MB；还带 `*.kiri.local` 本地域名与 HTTPS、一条命令起单节点 Kubernetes，以及从 OrbStack/Docker Desktop 一键迁移。

**Why it matters**: It had 1.7k stars when it made the daily on November 13 and has passed 10.2k—one of the fastest-rising infrastructure repos created in the past two weeks. It's pitched as a lightweight replacement for Docker Desktop and OrbStack: written in Rust, it runs containers in one small Linux VM (or straight on the kernel on Linux) and speaks the Docker Engine API, so existing tools just work. The README reports a container starting and exiting in about 2.5 ms through the API—around 80x faster than Docker Desktop—with a ~15 MB daemon, plus `*.kiri.local` domains with HTTPS, one-command single-node Kubernetes, and one-step migration from OrbStack or Docker Desktop.
