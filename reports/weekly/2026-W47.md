For anyone letting agents write front-end code, it's guidance straight from the browser vendors.

## 3. google/elephant-goldfish-model

⭐ 20.4k（本周 +4,249）· Python · [链接](https://github.com/google/elephant-goldfish-model)

**是什么**：Google 开源的 AI 助手插件，用 Agent 设计和评审软件："大象"掌握项目上下文并起草规格，"金鱼"评审者不带先前对话、以全新视角审查草稿。

**What it is**: Open-source plugin for designing and reviewing software with agents—"Design with an elephant. Review with a goldfish." The Elephant holds your project context and drafts the spec; Goldfish reviewers examine it without the earlier conversation.

**为什么值得关注**：本周 +4.2k 星，总星数突破 2 万。长对话里的 Agent 容易被自己的上下文"带偏"，它把"写"和"审"拆给两种角色：金鱼评审者只看草稿和引用的源材料，专门暴露没说出口的假设和盲区，架构取舍与最终批准仍由人来做。支持 Claude Code、Codex、Antigravity 等多种 harness，也能直接拿现有设计文档或 PR 计划对照线上代码做一次 60 秒评审，还提供代码库与文档的漂移报告。

**Why it matters**: +4.2k stars this week, now past 20k. Agents deep in a long conversation get anchored by their own context, so it splits writing and reviewing between two roles: goldfish reviewers see only the draft and referenced sources, exposing unstated assumptions and blind spots, while a human still makes the architectural trade-offs and approves the spec. It works with Claude Code, Codex, Antigravity and other harnesses, can run a 60-second review of an existing design doc or PR plan against live code, and reports drift between code and docs.

## 4. vercel-labs/agent-browser

⭐ 52.1k（本周 +3,760）· Rust · [链接](https://github.com/vercel-labs/agent-browser)

**是什么**：给 AI Agent 用的浏览器自动化 CLI：打开页面、以无障碍树读取内容，并在 shell 里操作页面元素。

**What it is**: Browser automation CLI for AI agents: open pages, read them as an accessibility tree, and act on elements from the shell.

**为什么值得关注**：本周 +3.8k 星，总星数达 5.21 万。原生 Rust CLI，`snapshot` 把页面压成紧凑文本，并给每个元素一个 `@e1` 这样的引用，Agent 按引用操作后再读一次页面确认结果。目标被遮挡、隐藏或禁用时点击会直接失败，而不是假装成功，堵住了 Agent 自动化常见的"以为点到了"问题。每个 `--session` 有独立的守护进程和浏览器，也能接管已运行的 Chrome。

**Why it matters**: +3.8k stars this week, now at 52.1k. A native Rust CLI whose `snapshot` compresses a page into compact text with a ref such as `@e1` for each element; the agent acts on a ref, then reads the page again to confirm the result. A click fails outright when the target is covered, hidden or disabled instead of reporting success, closing off the classic "agent thinks it clicked" failure. Each `--session` gets its own daemon and browser, and it can also attach to a running Chrome.

**What it is**: Secure, fast, efficient, battle-tested at Alibaba's scale. Hybrid architecture code review tool: deterministic pipelines + LLM Agent, precise line-level comments, built-in multi-language ruleset (NPE, thread-safety, XSS, SQL injection), OpenAI & Anthropic compatible.

As agents write more and more code, reviewable AI review is one of the most practical references for teams building their own review stack.
