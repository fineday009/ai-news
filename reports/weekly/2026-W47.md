As agents write more and more code, reviewable AI review is one of the most practical references for teams building their own review stack.

**是什么**：给编码 Agent 用的 Chrome DevTools：以 MCP 服务器和 CLI 两种形式，让 Antigravity、Claude、Cursor、Copilot 等 Agent 控制并检查一个真实运行的 Chrome。

**What it is**: Chrome DevTools for coding agents—available as an MCP server and a CLI, it lets your coding agent (such as Antigravity, Claude, Cursor or Copilot) control and inspect a live Chrome browser.

**为什么值得关注**：本周 +2,795 星；11 月 15 日上日报时 5.64 万，如今 5.87 万。由 Chrome DevTools 团队官方维护，把 DevTools 的完整能力交给 Agent：录制性能 trace 并提炼可执行的优化建议，分析网络请求、截图、读取带 source map 堆栈的控制台消息，再用 Puppeteer 做会自动等待结果的可靠自动化。对"Agent 写完前端却看不到运行效果"的问题，它比纯截图方案更接近人类工程师的调试方式。注意它会把浏览器里的内容暴露给 MCP 客户端，且默认收集使用统计（可用 `--no-usage-statistics` 关闭）。

**Why it matters**: +2,795 stars this week; it had 56.4k when it made the daily on November 15 and is at 58.7k now. Maintained by the Chrome DevTools team itself, it hands agents the full power of DevTools: record performance traces and extract actionable insights, analyze network requests, take screenshots and read console messages with source-mapped stack traces, and automate reliably with Puppeteer, which waits for action results. For the "agent wrote the frontend but can't see it run" problem, it's much closer to how a human engineer debugs than screenshots alone. Note that it exposes browser content to MCP clients and collects usage statistics by default (opt out with `--no-usage-statistics`).

## 10. libracoder/kiri

⭐ 12.1k · Rust · 创建于 2026-11-02 · [链接](https://github.com/libracoder/kiri)

**是什么**：一个小巧、快速的容器运行时，支持 macOS、Windows 和 Linux，直接运行你的 Docker 镜像，兼容现有的 docker CLI、Compose 和 buildx。

**What it is**: A tiny, fast container runtime for macOS, Windows and Linux. Runs your Docker images and works with the docker CLI, Compose and buildx you already use.

**为什么值得关注**：11 月 13 日上日报时 1.7k 星，如今已达 1.21 万，是近三周新建仓库中涨得最快的基础设施项目之一。定位是 Docker Desktop 和 OrbStack 的轻量替代：用 Rust 写成，在一台小 Linux 虚拟机里（Linux 上直接用内核）跑容器并实现 Docker Engine API，现有工具照常可用。README 称通过 API 启动并退出一个容器约 2.5 ms、约为 Docker Desktop 的 80 倍快，守护进程约 15 MB；还带 `*.kiri.local` 本地域名与 HTTPS、一条命令起单节点 Kubernetes，以及从 OrbStack/Docker Desktop 一键迁移。

**Why it matters**: It had 1.7k stars when it made the daily on November 13 and is at 12.1k now—one of the fastest-rising infrastructure repos created in the past three weeks. It's pitched as a lightweight replacement for Docker Desktop and OrbStack: written in Rust, it runs containers in one small Linux VM (or straight on the kernel on Linux) and speaks the Docker Engine API, so existing tools just work. The README reports a container starting and exiting in about 2.5 ms through the API—around 80x faster than Docker Desktop—with a ~15 MB daemon, plus `*.kiri.local` domains with HTTPS, one-command single-node Kubernetes, and one-step migration from OrbStack or Docker Desktop.
