## 4. deeplethe/utopia

⭐ 2.4k · 创建于 08-07 · Rust · [链接](https://github.com/deeplethe/utopia)

**是什么**：号称全球首个开源的企业级世界模型——基于双时态知识图谱、GraphRAG、pgvector 和 PostgreSQL，做 Agent 记忆与时序知识。

**What it is**: Billed as the world's first open-source enterprise world model — built on a bitemporal knowledge graph, GraphRAG, pgvector and PostgreSQL for agent memory and temporal knowledge.

**为什么值得关注**：Agent 长期记忆是当前最难啃的问题之一。utopia 用双时态知识图谱来存"随时间变化的事实"，架构直接落在 Postgres 生态上、便于企业自托管，在一众向量记忆方案里走了更结构化的路线。

**Why it matters**: Long-term agent memory is one of the field's hardest problems. utopia uses a bitemporal knowledge graph to store facts that change over time, sits directly on the Postgres ecosystem for easy enterprise self-hosting, and takes a more structured route than the usual vector-memory approaches.
