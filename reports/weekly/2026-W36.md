## 9. dmmulroy/anti-slop

⭐ 4.1k · TypeScript · 创建于 2026-08-12 · [链接](https://github.com/dmmulroy/anti-slop)

**是什么**：一套有明确主张的 Oxlint 规则，用来拒绝「低证据（low-evidence）」的 TypeScript / JavaScript 写法。

**What it is**: Opinionated Oxlint rules for rejecting low-evidence TypeScript and JavaScript patterns.

**为什么值得关注**：AI 生成代码越来越多，「看起来对但经不起推敲」的模式（滥用 any、想当然的类型断言等）随之泛滥。把这类反模式沉淀成 lint 规则，在 CI 阶段就拦下来，是应对「AI slop」很务实的一招，也顺带受益于 Oxlint 的极快速度。

**Why it matters**: As AI-generated code proliferates, so do patterns that "look right but don't hold up" (any-abuse, careless type assertions). Codifying those anti-patterns as lint rules to catch them in CI is a pragmatic answer to "AI slop," with the bonus of Oxlint's speed.
