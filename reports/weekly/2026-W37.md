## 10. tobi/walgit

⭐ 2.5k · Rust · 8/23 创建 · [链接](https://github.com/tobi/walgit)

**是什么**：一个分布式 Git 服务器，把仓库直接存进对象存储（S3/GCS）而非本地磁盘，因此无需数据库、无需协调，可以随开随关地弹性扩多个实例，同时支持 smart HTTP 拉取/推送、bundle-uri 克隆、Git LFS 等。

**What it is**: A distributed Git server that stores repositories in object storage (S3/GCS) instead of local disk—so it needs no database and no coordination, can scale to many disposable instances, and still supports smart HTTP fetch/push, bundle-uri clones, and Git LFS.

**为什么值得关注**：作者是 Shopify CEO Tobi Lütke，本身就是重量级 builder。把 Git 服务器做成「无状态 + 对象存储」的云原生形态，直击自建 Git 服务的运维与扩展痛点，思路新颖且工程含金量高。

**Why it matters**: Author is Shopify CEO Tobi Lütke, a heavyweight builder in his own right. Making a Git server "stateless + object storage" cloud-native tackles the ops and scaling pain of self-hosted Git, with a fresh idea and real engineering depth.
