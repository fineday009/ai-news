## 2. heygen-com/hyperframes

⭐ 49,042（本周 +5,100）· TypeScript · [链接](https://github.com/heygen-com/hyperframes)

**是什么**：为代理打造的视频渲染框架——用 HTML 描述画面，直接渲染成视频（基于 GSAP/Puppeteer/FFmpeg）。

**What it is**: A video framework built for agents — write HTML to describe frames and render straight to video (via GSAP/Puppeteer/FFmpeg).

**为什么值得关注**：它把「生成视频」从像素扩散模型转向「代码即帧」，让 LLM 能像写网页一样精确控制动画与排版，可控性、可复现性远胜纯生成式，正成为 Agent 做营销/解说视频的主力管线。

**Why it matters**: It reframes video generation from pixel diffusion to "code-as-frames," letting an LLM control animation and layout as precisely as writing a web page — far more controllable and reproducible than pure generative video, and increasingly the go-to pipeline for agent-made marketing/explainer clips.
