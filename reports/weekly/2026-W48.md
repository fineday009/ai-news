## 9. ItsNotRexed/Leonida

⭐ 16.0k · Python · 创建于 2026-11-20 · [链接](https://github.com/ItsNotRexed/Leonida)

**是什么**：Leonida 是 Xbox 版《侠盗猎车手 6》的原生 PC 重编译项目。

**What it is**: Leonida is a native PC recompilation of the Xbox version of Grand Theft Auto 6.

**为什么值得关注**：创建三天就有约 1.6 万星，是本周新建仓库里星数最高的。但请先看清现状：README 明确写着"还很早期，游戏目前无法启动"，没有任何可玩内容。它是一个静态重编译项目——Xbox Series 的 CPU 与 PC 同为 x86-64，所以游戏代码原生加载运行、主机系统软件被重新实现，主机预编译的 RDNA2 GPU 程序被翻译成 SPIR-V 交给 Vulkan。目前真正完成的是着色器这一段：README 称全部 26,503 个着色器已完成翻译并通过 `spirv-val` 校验。仓库不含游戏、密钥或可执行文件，需要你自己的游戏拷贝。把它当作一次公开进行的大型逆向工程来围观比较合适，而不是可以下载的 PC 版。

**Why it matters**: About 16k stars three days after creation—the most-starred repo created this week. But read the status first: the README says plainly that it's early and the game does not boot yet, with nothing playable. It's a static recompilation project: the Xbox Series CPU is x86-64 like a PC, so the game's code is loaded and run natively while the console's system software is reimplemented, and the console's precompiled RDNA2 GPU programs are translated to SPIR-V for Vulkan. What's actually done so far is the shader side: the README reports all 26,503 shaders translated and passing `spirv-val`. The repository contains no game, keys or executable; you need your own copy. Best treated as a large reverse-engineering effort happening in public, not as a PC version you can download.
