## 9. xcl-dev/xcl

⭐ 8,339 · Rust · 创建于 2026-11-20 · [链接](https://github.com/xcl-dev/xcl)

**是什么**：面向 Windows 的 Xbox Series 兼容层——原生运行主机游戏代码，重新实现主机系统库，并把 RDNA2 着色器重编译为 DXIL。

**What it is**: Xbox Series compatibility layer for Windows - runs console game code natively, reimplements the console system libraries and recompiles RDNA2 shaders to DXIL.

**为什么值得关注**：创建六天 8,339 星；11 月 24 日快照时 3,631，昨日 7,912，今天增速明显放缓；仓库已从 ivall/xcl 迁至 xcl-dev 组织，旧地址会自动跳转。XCL 走的是 Wine/Proton 的路线而不是模拟器：Xbox Series 的 CPU 本就是 x64，所以游戏代码不经 CPU 模拟直接在 PC 上原生运行，XCL 负责替代 PC 上没有的主机库（`kernelx.dll`、XGameRuntime、`d3d12_xs.dll` 等），并把主机的 RDNA2 GPU 机器码翻译成 HLSL 再编译为 DXIL。README 称零售游戏已经能跑：Minecraft Preview 和 Unicorn Overlord 可完整游玩，Fortnite 和 XDefiant 在没有在线服务的前提下能运行到游戏本身允许的程度；另一款较新的零售游戏能进入菜单但尚未进入实际游戏。README 还称某款零售游戏着色器包中的全部 26,698 个 RDNA2 程序都已翻译成 HLSL，并有 370 多个自动化测试。以上均为项目自述，适合对主机逆向和图形管线感兴趣的人围观。

**Why it matters**: 8,339 stars six days after creation; it was at 3,631 in the November 24 snapshot and 7,912 yesterday, so growth has slowed sharply today; the repository has moved from ivall/xcl to the xcl-dev organization, and the old address redirects. XCL takes the Wine/Proton route rather than emulation: the Xbox Series CPU is already x64, so the game's code runs natively on a PC with no CPU emulation while XCL stands in for the console libraries a PC doesn't have (`kernelx.dll`, XGameRuntime, `d3d12_xs.dll` and others) and translates the console's RDNA2 GPU machine code to HLSL and then DXIL. The README says retail games already run: Minecraft Preview and Unicorn Overlord are fully playable, and Fortnite and XDefiant work as far as each game goes without its online services; one newer retail game reaches its menus but not gameplay. The README also reports that all 26,698 RDNA2 programs in one retail game's shader pack translate to HLSL, with 370+ automated tests. These are the project's own claims; one to watch for people interested in console reverse engineering and graphics pipelines.
