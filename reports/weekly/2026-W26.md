## 1. google-research/timesfm

⭐ 25.5k（本周 +3,915）· Python · [链接](https://github.com/google-research/timesfm)

**是什么**：TimesFM 是 Google Research 开发的时间序列预测预训练基础模型（Time Series Foundation Model）。

**What it is**: TimesFM (Time Series Foundation Model) is a pretrained time-series foundation model from Google Research for time-series forecasting.

**为什么值得关注**：大模型在文本、图像之后，正把"基础模型"范式延伸到时间序列。一个开箱即用、零样本就能预测的时序模型，对做需求预测、监控、金融、运维的人意义重大——不用为每条曲线单独训练一个模型。

**Why it matters**: After text and images, the foundation-model paradigm is extending to time series. An out-of-the-box, zero-shot forecaster matters a lot for demand forecasting, monitoring, finance, and ops — no need to train a separate model for every curve.

## 5. DeusData/codebase-memory-mcp

⭐ 14.2k（本周 +9,589）· C · [链接](https://github.com/DeusData/codebase-memory-mcp)

**是什么**：高性能代码情报 MCP 服务器，把代码库索引成持久知识图谱（普通仓库毫秒级完成），支持 158 种语言、亚毫秒查询、节省 99% token，单个静态二进制、零依赖。

**What it is**: A high-performance code-intelligence MCP server that indexes codebases into a persistent knowledge graph (an average repo in milliseconds) — 158 languages, sub-millisecond queries, 99% fewer tokens, a single static binary with zero dependencies.

**为什么值得关注**：本周涨星之王（+9.5k）。让 Agent "读懂"大型代码库一直是瓶颈：要么慢，要么烧 token。它用 C 写的静态二进制 + 知识图谱把索引和查询都压到极致，"省 99% token"若属实将直接改善编码 Agent 的成本与上下文质量。

**Why it matters**: This week's star-growth champion (+9.5k). Letting agents "understand" large codebases has been a bottleneck — either slow or token-hungry. Its C-based static binary plus knowledge graph pushes indexing and queries to the limit; if the "99% fewer tokens" claim holds, it directly improves coding-agent cost and context quality.
