## 2. JustVugg/colibri

⭐ 25.9k · 新建于 2026-07-01 · C · [链接](https://github.com/JustVugg/colibri)

**是什么**：在你已有的硬件上跑前沿 MoE 模型——纯 C、零依赖，专家（experts）从磁盘流式加载。

**What it is**: Run frontier MoE models on hardware you already own—pure C, zero dependencies, with experts streamed from disk.

**为什么值得关注**：MoE 大模型参数惊人却"每次只激活少数专家"，它正是利用这一点，把专家权重放在磁盘按需流式载入，让内存有限的普通机器也能跑起原本装不下的模型。纯 C、零依赖的极简工程路线，直击"人人都想本地跑大模型"的核心矛盾，是本月最硬核的推理基建之一。

**Why it matters**: MoE models have staggering parameter counts but "activate only a few experts each step"—colibri exploits exactly that, keeping expert weights on disk and streaming them on demand so a modest machine can run models it couldn't otherwise hold. The pure-C, zero-dependency minimalism hits the core tension of "everyone wants to run big models locally," making it one of the month's most hardcore inference-infra projects.
