## 5. volcengine/OpenViking

⭐ 34.2k（本月 +6,661）· Python · [链接](https://github.com/volcengine/OpenViking)

**是什么**：面向 AI agent 的上下文数据库，把记忆、资源与技能组织成 `viking://` 协议下的虚拟文件系统，让 agent 能确定性地"浏览"上下文，而非查询黑盒向量库。

**What it is**: A context database for AI agents that organizes memories, resources, and skills as a virtual filesystem under the `viking://` protocol, letting agents browse context deterministically instead of querying a black-box vector store.

**为什么值得关注**：字节火山引擎给 agent 上下文一个"文件系统"式的确定性抽象——用路径浏览取代模糊向量检索，可解释、可预测。它和本月多个记忆类项目共同指向同一判断：agent 的下一道门槛是上下文管理，而非模型本身。

**Why it matters**: ByteDance's Volcengine gives agent context a filesystem-style deterministic abstraction—path-based browsing instead of fuzzy vector retrieval, explainable and predictable. Together with the month's other memory projects, it points to the same conclusion: the next frontier for agents is context management, not the model itself.
