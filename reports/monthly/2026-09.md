## 1. volcengine/OpenViking

⭐ 37.1k（本月 +8,745）· Python · [链接](https://github.com/volcengine/OpenViking)

**What it is**: A self-evolving context database for AI agents that unifies memory and knowledge.

**为什么值得关注**：字节火山引擎出品，把「Agent 用什么记住上下文」这一核心问题产品化——不是简单的向量库，而是能随交互自我演化的上下文层；随着长任务、多 Agent 成为主流，记忆/知识的统一存储正成为下一个基础设施战场，大厂下场使其分量十足。

**Why it matters**: From ByteDance's Volcengine, it productizes the core question of "how an agent remembers context" — not a plain vector store but a context layer that self-evolves with interaction. As long tasks and multi-agent setups go mainstream, unified memory/knowledge storage is becoming the next infrastructure battleground, and a big vendor's entry gives it real weight.
