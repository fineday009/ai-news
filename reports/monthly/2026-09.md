## 2. JustVugg/colibri

⭐ 26.8k · C · 创建于 2026-07-01 · [链接](https://github.com/JustVugg/colibri)

**是什么**：在你已有的硬件上运行前沿 MoE（专家混合）模型——纯 C、零依赖，专家（experts）按需从磁盘流式加载。

**What it is**: Run frontier MoE models on hardware you already own — pure C, zero dependencies, experts streamed from disk.

**为什么值得关注**：MoE 模型参数巨大但每步只激活一部分专家，colibri 正是抓住这点，用磁盘流式加载让普通机器也能跑大模型。纯 C、零依赖意味着极易编译部署，是「本地大模型民主化」这条线里技术含量很高的一个。

**Why it matters**: MoE models are huge but activate only a subset of experts per step; colibri exploits exactly that, streaming experts from disk so ordinary machines can run big models. Pure C with zero dependencies makes it trivial to build and deploy — one of the more technically impressive entries in the "democratize local LLMs" thread.
