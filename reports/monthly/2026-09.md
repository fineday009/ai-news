## 2. JustVugg/colibri

⭐ 27.1k · C · 7/01 创建 · [链接](https://github.com/JustVugg/colibri)

**是什么**：在你现有的硬件上跑前沿 MoE（专家混合）模型——纯 C 实现、零依赖，专家权重从磁盘按需流式加载。引擎极小，模型极大。

**What it is**: Run frontier MoE models on hardware you already own—pure C, zero deps, experts streamed from disk on demand. Tiny engine, immense model.

**为什么值得关注**：它把「大模型必须要大显存」的前提撕开了一道口子：用磁盘流式加载专家，让普通机器也能跑动巨型 MoE。零依赖纯 C 的极简路线在本地推理这条最卷的赛道里辨识度极高，还被 Vercel CEO 点名资助，是本月「本地 AI」的标志项目。

**Why it matters**: It cracks the premise that "big models need big VRAM": streaming experts from disk lets ordinary machines run giant MoE models. The zero-dependency, pure-C minimalism stands out in the crowded local-inference race—and it was singled out for funding by Vercel's CEO—making it the month's local-AI standout.
