Written in C for performance, it's the most engineering-forward take on giving agents long-term codebase memory.

## 10. n0-computer/iroh

⭐ 11.2k（本月 +2,584）· Rust · [链接](https://github.com/n0-computer/iroh)

**是什么**：一个为应用加上 QUIC + NAT 穿透的库——「IP 会变，改用拨号密钥」。

**What it is**: A library that adds QUIC + NAT traversal to your apps — "IP addresses break, dial keys instead."

**为什么值得关注**：P2P 与本地优先应用的老难题是「怎么在 NAT 后面互相直连」，iroh 用密钥而非 IP 来寻址，做成可嵌入的 Rust 库。对做去中心化、协作与本地优先软件的开发者是基础设施级利器。

**Why it matters**: The perennial P2P/local-first problem is direct connection behind NAT; iroh addresses peers by key rather than IP, packaged as an embeddable Rust library. Infrastructure-grade leverage for anyone building decentralized, collaborative, or local-first software.
