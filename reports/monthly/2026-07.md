## 8. alibaba/zvec

⭐ 12.7k（本月 +3,005）· C++ · [链接](https://github.com/alibaba/zvec)

**是什么**：一个轻量、极快、进程内运行的向量数据库。

**What it is**: A lightweight, lightning-fast, in-process vector database.

**为什么值得关注**：RAG 与 agent 记忆的普及让向量检索成为标配，但独立向量数据库往往部署重、延迟高。阿里开源的 zvec 走「进程内嵌入」路线，像 SQLite 之于关系库那样把向量检索直接嵌进应用，省去独立服务的运维负担，特别适合中小规模、低延迟的本地场景，是本月务实的基础设施新选择。

**Why it matters**: The spread of RAG and agent memory made vector search table stakes, but standalone vector databases are often heavy to deploy and high-latency. Alibaba's open-source zvec takes the in-process embedded route — like SQLite for relational databases — putting vector search directly inside the app and removing the ops burden of a separate service, ideal for small-to-mid, low-latency local scenarios. A pragmatic new infrastructure option this month.

## 9. n0-computer/iroh

⭐ 11.0k（本月 +2,370）· Rust · [链接](https://github.com/n0-computer/iroh)

**是什么**：一个为应用添加 QUIC 与 NAT 穿透的库，用「以 IP 地址为替代」的方式直连节点。

**What it is**: A library that adds QUIC and NAT traversal to applications as an alternative to addressing by IP.

**为什么值得关注**：点对点直连长期受 NAT、防火墙困扰，iroh 用 Rust 把 QUIC 传输与 NAT 穿透封装成易用的库，让开发者能给应用轻松加上稳健的 P2P 连接。在中心化云服务之外，去中心、直连的网络基础设施重新受到关注，iroh 是这条路线上工程质量出众的一员。

**Why it matters**: Peer-to-peer direct connections have long been plagued by NAT and firewalls; iroh packages QUIC transport and NAT traversal into an easy Rust library, letting developers add robust P2P connectivity to their apps. Beyond centralized cloud services, decentralized direct-connect networking is drawing renewed attention, and iroh is an engineering-standout on that path.
