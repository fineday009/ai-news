## 4. DeusData/codebase-memory-mcp

⭐ 23.9k（本月 +20,690）· C · [链接](https://github.com/DeusData/codebase-memory-mcp)

**是什么**：一个高性能代码智能 MCP 服务器，用 tree-sitter 解析上百种语言，把代码库索引成持久知识图谱，通过 MCP 供编码智能体查询。

**What it is**: A high-performance code-intelligence MCP server that parses hundreds of languages with tree-sitter, indexes a codebase into a persistent knowledge graph, and serves it to coding agents over MCP.

**为什么值得关注**：它不内嵌 LLM，而是复用你正在用的 agent，号称索引大型仓库仅数分钟、查询亚毫秒、大幅省 token，单文件静态二进制带构建证明。本月涨两万余星，是「给智能体装代码记忆」这件事最工程化的实现之一。

**Why it matters**: Rather than embedding an LLM, it leverages the agent you already use — claiming a few-minute index of large repos, sub-millisecond queries, and big token savings — as a single static binary with build attestation. Adding 20k+ stars this month, it's one of the most engineered takes on giving agents code memory.

## 10. n0-computer/iroh

⭐ 11.0k（本月 +2,314）· Rust · [链接](https://github.com/n0-computer/iroh)

**是什么**：一个为应用加上 QUIC 与 NAT 穿透能力的库——用「拨号密钥（dial keys）」而非 IP 地址来建立连接。

**What it is**: A library that adds QUIC and NAT traversal to applications, using "dial keys" instead of IP addresses to establish connections.

**为什么值得关注**：点对点连接的老难题是 NAT 穿透与「用什么来寻址」。iroh 用公钥式的 dial key 取代 IP，让连接跟着「身份」走而非「网络位置」，天然适配移动、多设备与去中心场景。它是本月非 AI 阵营里少见的、对底层网络范式有想法的基础库。

**Why it matters**: The perennial hard problems of peer-to-peer connectivity are NAT traversal and "what to address by." iroh replaces IPs with public-key-style dial keys, so connections follow identity rather than network location — a natural fit for mobile, multi-device, and decentralized scenarios. It's a rare foundational library in the non-AI camp with a real point of view on the underlying network paradigm.
