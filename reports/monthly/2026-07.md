**为什么值得关注**：它不内嵌 LLM 而是复用你正在用的 agent，号称索引 Linux 内核仅 3 分钟、查询亚毫秒、token 消耗降低 99%。单文件静态二进制、SLSA L3 构建证明，把「给智能体装代码记忆」做得极其工程化，本月吸量近两万。

**Why it matters**: Rather than embedding an LLM, it reuses the agent you already run — claiming a 3-minute index of the Linux kernel, sub-millisecond queries, and 99% fewer tokens.
