## 1. diegosouzapw/OmniRoute

⭐ 31.2k（本月 +23,805）· TypeScript · [链接](https://github.com/diegosouzapw/OmniRoute)

**是什么**：免费的 MIT 协议 AI 网关，一个端点接入 290+ 家供应商、500+ 个模型，支持自动 fallback。

**What it is**: A free MIT-licensed AI gateway — one endpoint for 290+ providers and 500+ models, with automatic fallback.

**为什么值得关注**：本月涨星冠军。多模型时代最痛的接入碎片化——各家 API 不同、限流不同、还会宕机——被它用一个统一端点 + 自动切换解决。免费与宽松协议让它迅速成为 LLM 应用层的默认「路由器」，单月 2.3 万星印证了这一刚需。

**Why it matters**: The month's top gainer. The core pain of the multi-model era — fragmented APIs, differing rate limits, provider outages — is solved with one unified endpoint plus auto-fallback. Free and permissively licensed, it quickly became a default "router" for the LLM application layer, and 23.8k stars in a month confirms the need.

## 5. ogulcancelik/herdr

⭐ 21.1k（本月 +13,743）· Rust · [链接](https://github.com/ogulcancelik/herdr)

**是什么**：在终端环境中运行的代理多路复用器（agent multiplexer）。

**What it is**: An agent multiplexer that operates within terminal environments.

**为什么值得关注**：如果你同时跑多个终端代理，切换、并管、复用会话就成了麻烦。herdr 像给代理版的 tmux——在终端里多路复用多个代理会话，用 Rust 保证轻量与响应速度。它踩中了「重度代理用户的日常工作流」这一细分但真实的需求。

**Why it matters**: If you run several terminal agents at once, switching, managing and reusing sessions becomes a hassle. herdr is like tmux for agents — multiplexing multiple agent sessions in the terminal, with Rust keeping it lightweight and responsive. It targets the niche but real need of heavy agent users' daily workflow.
