## 2. antirez/ds4

⭐ 17.9k · 新建于 2026-05-06 · C · [链接](https://github.com/antirez/ds4)

**是什么**：面向 DeepSeek V4 Flash / PRO 的本地推理引擎，支持 Metal、CUDA 与 ROCm，可 SSD 流式加载超显存模型、多机分布式推理，并自带兼容 OpenAI/Anthropic 的服务端。

**What it is**: A local inference engine for DeepSeek V4 Flash/PRO with Metal, CUDA, and ROCm support, SSD streaming for models larger than RAM, distributed inference, and an OpenAI/Anthropic-compatible server.

**为什么值得关注**：Redis 作者 antirez 出手，把「在个人高配机上本地跑大模型」做得工程扎实——2-bit 量化、磁盘 KV 缓存、会话恢复一应俱全。是本地大模型推理里可信度最高的新项目之一。

**Why it matters**: From antirez (creator of Redis), it makes "run big models locally on a high-end PC" seriously engineered — 2-bit quantization, disk-based KV cache, session resumption. One of the most credible new entrants in local LLM inference.

**Why it matters**: Rather than trusting the LLM blindly, it runs deterministic rules alongside the agent — curbing hallucination while keeping coverage — and it's hardened at real enterprise scale, a strong reference for teams operationalizing AI code review.

## 9. n0-computer/iroh

⭐ 11.2k（本月 +2,542）· Rust · [链接](https://github.com/n0-computer/iroh)

**是什么**：一个为应用加上 QUIC + NAT 穿透的库——「IP 会变，改用拨号密钥」。

**What it is**: A library that adds QUIC + NAT traversal to your apps — "IP addresses break, dial keys instead."

**为什么值得关注**：P2P 与本地优先应用的老难题是「怎么在 NAT 后面互相直连」，iroh 用密钥而非 IP 来寻址，做成可嵌入的 Rust 库。对做去中心化、协作与本地优先软件的开发者是基础设施级利器。

**Why it matters**: The perennial P2P/local-first problem is direct connection behind NAT; iroh addresses peers by key rather than IP, packaged as an embeddable Rust library. Infrastructure-grade leverage for anyone building decentralized, collaborative, or local-first software.
