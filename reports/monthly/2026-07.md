## 10. n0-computer/iroh

⭐ 11.6k（本月 +2,909）· Rust · [链接](https://github.com/n0-computer/iroh)

**是什么**：IP 地址会失效，那就改用「拨号密钥」——一个给应用加上 QUIC + NAT 穿透的库。

**What it is**: IP addresses break, dial keys instead—a library that adds QUIC + NAT traversal to your apps.

**为什么值得关注**：点对点连接一直被 NAT 穿透和 IP 漂移折磨，iroh 用「拨号密钥而非 IP」的思路，把 QUIC 与 NAT 穿透封装成开箱即用的库，让应用能在复杂网络里稳定直连。作为一块底层网络基础设施，它不追热点却解决真问题，本月 +2,909 星、Rust 实现，是本期非 AI 阵营里值得开发者收藏的实用库。

**Why it matters**: Peer-to-peer connectivity has long been plagued by NAT traversal and IP drift; iroh's "dial keys, not IPs" approach wraps QUIC and NAT traversal into a ready-to-use library so apps can hold stable direct connections across messy networks. As low-level networking infrastructure it chases no hype but solves a real problem; +2,909 stars this month and a Rust implementation make it a practical library worth bookmarking in this period's non-AI camp.
