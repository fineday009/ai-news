## 1. cloudflare/security-audit-skill

⭐ 53.0k（本月 +29,622）· JavaScript · [链接](https://github.com/cloudflare/security-audit-skill)

**是什么**：面向编码 Agent 的多阶段安全审计技能，产出经过验证、机器可读的发现。

**What it is**: A coding-agent skill for multi-phase security audits that produces verified, machine-readable findings.

**为什么值得关注**：让 Agent 做安全审计最大的风险是"幻觉式告警"——一堆看似吓人实则不存在的问题。Cloudflare 这套技能强调"多阶段 + 经验证 + 机器可读"，把审计做成可核验、可集成进流水线的产物，而不是自由发挥的文字报告。由 Cloudflare 官方出品、本月 +2.96 万星、稳居第一，是"AI + 安全"方向的高质量范本。

**Why it matters**: The biggest risk in letting an agent run a security audit is hallucinated alerts—scary-looking issues that aren't real. Cloudflare's skill emphasizes multi-phase, verified, machine-readable findings, making the audit a checkable artifact you can wire into a pipeline rather than a free-form text report. Official from Cloudflare and +29.6k stars this month, holding #1, it's a high-quality template for AI-meets-security.

## 4. heygen-com/hyperframes

⭐ 75.5k（本月 +21,520）· TypeScript · [链接](https://github.com/heygen-com/hyperframes)

**是什么**：写 HTML，然后渲染成视频——专为 Agent 打造。

**What it is**: Write HTML. Render video. Built for agents.

**为什么值得关注**：让 Agent 直接驱动像素或视频模型来做视频，既不稳定也难控制。hyperframes 换了个聪明的抽象：用 Agent 最擅长的 HTML/CSS 描述画面，再渲染成视频，于是视频也变得可编程、可审查、可版本管理。本月 +2.2 万星，对自动化内容、讲解动画和营销素材都很实用。

**Why it matters**: Having an agent drive pixels or a video model directly is unstable and hard to control. hyperframes picks a smarter abstraction: describe each frame in the HTML/CSS agents are best at, then render it to video, which makes video programmable, reviewable and version-controlled. +21.5k stars this month; handy for automated content, explainer animations and marketing assets.
