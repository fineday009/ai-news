**What it is**: A coding-agent skill for multi-phase security audits with independently verified, machine-readable findings.

**为什么值得关注**：近 30 天 +4.3 万星，总星数 7.20 万，11 月 7 日曾以 +2,548 星登上日榜第一。它把审计拆成可复核的多阶段流水线，要求每条发现都被独立验证，并以机器可读格式输出，直接回应了"Agent 报出来的漏洞能不能信"这个核心问题。随着越来越多代码由 Agent 写成，"由 Agent 来审"正在成为标配，论实质价值它是本月最扎实的一个。

As more code is written by agents, having agents audit it is becoming standard—on substance, it's the month's most solid pick.

## 5. pingdotgg/t3code

**What it is**: T3 Code is an "agent harness control surface": control the agents on your machine from a mobile app (iOS, Android), a web app and an Electron desktop app.

**为什么值得关注**：近 30 天 +3.2 万星，截至 11 月 11 日的 7 天内就有约 1.20 万，一度领跑周榜。它不卖模型也不卖订阅，直接复用你电脑上已登录的 Claude Code、Codex、Cursor、OpenCode 等，统一在一个界面里调度，并可从手机远程接管，且完全开源。当一个人同时用好几个 harness 成为常态，多 Agent 控制台正在成为一层独立的工具，t3code 是其中增长最快的一个。

## 6. heygen-com/hyperframes

⭐ 84.0k（本月 +21,924）· TypeScript · [链接](https://github.com/heygen-com/hyperframes)

**是什么**：写 HTML，然后渲染成视频——专为 Agent 打造。

**What it is**: Write HTML. Render video. Built for agents.

**为什么值得关注**：让 Agent 直接驱动像素或视频模型来做视频，既不稳定也难控制。hyperframes 换了个聪明的抽象：用 Agent 最擅长的 HTML/CSS 描述画面，再渲染成视频，于是视频也变得可编程、可审查、可版本管理。近 30 天 +2.2 万星、总星数突破 8 万，对自动化内容、讲解动画和营销素材都很实用。

**Why it matters**: Having an agent drive pixels or a video model directly is unstable and hard to control. hyperframes picks a smarter abstraction: describe each frame in the HTML/CSS agents are best at, then render it to video, which makes video programmable, reviewable and version-controlled. +21.9k stars in 30 days, now past 80k; handy for automated content, explainer animations and marketing assets.
