## 1. cloudflare/security-audit-skill

⭐ 75.4k（本月 +44,600）· JavaScript · [链接](https://github.com/cloudflare/security-audit-skill)

**是什么**：面向编码 Agent 的多阶段安全审计 skill，产出经独立验证、机器可读的漏洞发现。

**What it is**: A coding-agent skill for multi-phase security audits with independently verified, machine-readable findings.

**为什么值得关注**：近 30 天 +4.5 万星，月榜涨星第一，总星数 7.54 万，11 月 7 日曾以 +2,548 星登上日榜第一。它把审计拆成可复核的多阶段流水线，要求每条发现都被独立验证，并以机器可读格式输出，直接回应了"Agent 报出来的漏洞能不能信"这个核心问题。随着越来越多代码由 Agent 写成，"由 Agent 来审"正在成为标配，论实质价值它是本月最扎实的一个。

**Why it matters**: +44.6k stars over the past 30 days—the monthly chart's top gainer—now at 75.4k, and #1 on the daily board on November 7 with +2,548. It splits audits into a reviewable multi-phase pipeline, requires every finding to be independently verified and emits results in a machine-readable format, which speaks directly to the core question of whether you can trust vulnerabilities an agent reports. As more code is written by agents, having agents audit it is becoming standard—on substance, it's the month's most solid pick.

## 2. pbakaus/impeccable

⭐ 113.0k（本月 +30,662）· Rust · [链接](https://github.com/pbakaus/impeccable)

**是什么**：给编码 Agent 用的设计语言：用 polish、bolder 等指令引导风格，用 critique、audit 做评审，并带确定性检测规则。

**What it is**: The design vocabulary for your coding agent. Steer with polish and bolder, review with critique and audit, and catch problems with deterministic detector rules.

**为什么值得关注**：近 30 天 +3.1 万星、总星数 11.30 万，是"让 Agent 做出不带 AI 味的界面"这一赛道的头部项目；同类的 hallmark（+2.7 万）和 taste-skill（+2.0 万）也在月榜上。它的差异在于不只靠提示词，而是提供可安装的技能、命令和确定性检测规则，让 Agent 能对自己写的 UI 反复自检，比单纯的风格指南更可靠。

**Why it matters**: +30.7k stars in 30 days, now at 113.0k, it leads the category of making agent-built interfaces stop looking AI-made; its peers hallmark (+27.3k) and taste-skill (+20.1k) are on the monthly chart too. What sets it apart is that it goes beyond prompts with installable skills, commands and deterministic detector rules, so an agent can check its own UI again and again—more reliable than a style guide alone.

## 3. pingdotgg/t3code

⭐ 65.4k（本月 +36,872）· TypeScript · [链接](https://github.com/pingdotgg/t3code)

**是什么**：T3 Code——一个"Agent harness 控制面"：通过手机 App（iOS/Android）、网页端和 Electron 桌面端，控制你电脑上的各个编码 Agent。

**What it is**: T3 Code is an "agent harness control surface": control the agents on your machine from a mobile app (iOS, Android), a web app and an Electron desktop app.

**为什么值得关注**：近 30 天 +3.7 万星，月榜涨星第二，截至 11 月 11 日的 7 天内就有约 1.20 万，一度领跑周榜。它不卖模型也不卖订阅，直接复用你电脑上已登录的 Claude Code、Codex、Cursor、OpenCode 等，统一在一个界面里调度，并可从手机远程接管，且完全开源。当一个人同时用好几个 harness 成为常态，多 Agent 控制台正在成为一层独立的工具，t3code 是其中增长最快的一个。

**Why it matters**: +36.9k stars in 30 days, second on the monthly chart, about 12.0k of them in the seven days to November 11, when it led the weekly chart. It sells neither models nor subscriptions: it reuses the Claude Code, Codex, Cursor, OpenCode and other installs already signed in on your machine, drives them from one interface, lets you take over from your phone, and is fully open source. With one person running several harnesses now the norm, multi-agent consoles are becoming a tool layer of their own, and t3code is its fastest grower.

## 4. heygen-com/hyperframes

⭐ 86.6k（本月 +20,375）· TypeScript · [链接](https://github.com/heygen-com/hyperframes)

**是什么**：写 HTML，然后渲染成视频——专为 Agent 打造。

**What it is**: Write HTML. Render video. Built for agents.

**为什么值得关注**：让 Agent 直接驱动像素或视频模型来做视频，既不稳定也难控制。hyperframes 换了个聪明的抽象：用 Agent 最擅长的 HTML/CSS 描述画面，再渲染成视频，于是视频也变得可编程、可审查、可版本管理。近 30 天 +2.0 万星、总星数 8.66 万，对自动化内容、讲解动画和营销素材都很实用。

**Why it matters**: Having an agent drive pixels or a video model directly is unstable and hard to control. hyperframes picks a smarter abstraction: describe each frame in the HTML/CSS agents are best at, then render it to video, which makes video programmable, reviewable and version-controlled. +20.4k stars in 30 days, now at 86.6k; handy for automated content, explainer animations and marketing assets.

## 5. thedotmack/claude-mem

⭐ 118.3k（本月 +17,311）· TypeScript · [链接](https://github.com/thedotmack/claude-mem)

**是什么**：给任意 Agent 的跨会话持久记忆——捕获 Agent 在会话中做的一切，用 AI 压缩后，在之后的会话里注入相关上下文；支持 Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCode 等。

**What it is**: Persistent context across sessions for every agent—captures everything your agent does during sessions, compresses it with AI, and injects relevant context back into future sessions. Works with Claude Code, OpenClaw, Codex, Gemini, Hermes, Copilot, OpenCode and more.

**为什么值得关注**：近 30 天 +1.7 万星，总星数 11.83 万；W45 周榜时 11.41 万。编码 Agent 最大的痛点之一是"失忆"：每开一个新会话就从零开始。claude-mem 把会话过程沉淀成可复用的记忆层，并且不绑定单一 Agent——和 t3code 一样，它押注的是"一个人同时用好几个 harness"的工作方式。

**Why it matters**: +17.3k stars in 30 days, now at 118.3k (114.1k at the W45 weekly). One of the biggest pains with coding agents is amnesia—every new session starts from zero. claude-mem distills sessions into a reusable memory layer that isn't tied to any one agent—like t3code, a bet on people running several harnesses at once.
