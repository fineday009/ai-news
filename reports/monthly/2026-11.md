## 3. heygen-com/hyperframes

⭐ 77.2k（本月 +22,225）· TypeScript · [链接](https://github.com/heygen-com/hyperframes)

**是什么**：写 HTML，然后渲染成视频——专为 Agent 打造。

**What it is**: Write HTML. Render video. Built for agents.

**为什么值得关注**：让 Agent 直接驱动像素或视频模型来做视频，既不稳定也难控制。hyperframes 换了个聪明的抽象：用 Agent 最擅长的 HTML/CSS 描述画面，再渲染成视频，于是视频也变得可编程、可审查、可版本管理。近 30 天 +2.2 万星，对自动化内容、讲解动画和营销素材都很实用。

**Why it matters**: Having an agent drive pixels or a video model directly is unstable and hard to control. hyperframes picks a smarter abstraction: describe each frame in the HTML/CSS agents are best at, then render it to video, which makes video programmable, reviewable and version-controlled. +22.2k stars in 30 days; handy for automated content, explainer animations and marketing assets.

## 7. thedotmack/claude-mem

⭐ 109.5k（本月 +14,011）· TypeScript · [链接](https://github.com/thedotmack/claude-mem)

**是什么**：给任意 Agent 的跨会话持久记忆——捕获 Agent 在会话中做的一切，用 AI 压缩后，在之后的会话里注入相关上下文；支持 Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCode 等。

**What it is**: Persistent context across sessions for every agent—captures everything your agent does during sessions, compresses it with AI, and injects relevant context back into future sessions. Works with Claude Code, OpenClaw, Codex, Gemini, Hermes, Copilot, OpenCode and more.

**为什么值得关注**：近 30 天 +1.4 万星、突破 10.9 万。编码 Agent 最大的痛点之一是"失忆"：每开一个新会话就从零开始，之前的决策和踩过的坑全丢了。claude-mem 把会话沉淀成可复用、且不绑定单一 Agent 的记忆层；在同一个人同时用好几个 harness 成为常态的当下，它是这个方向里被最广泛使用的实现之一。

**Why it matters**: +14.0k stars in 30 days to pass 109k. One of the biggest pains with coding agents is amnesia—every new session starts from zero, losing prior decisions and hard-won lessons. claude-mem distills sessions into a reusable memory layer that isn't tied to any one agent; now that one person running several harnesses is the norm, it's one of the most widely used implementations of the idea.
