## 1. colbymchenry/codegraph

⭐ 49,089（本月 +47,635）· TypeScript · [链接](https://github.com/colbymchenry/codegraph)

**是什么**：预先索引的代码知识图谱，随代码变更自动同步，服务于 Claude Code、Cursor 等编码智能体。

**What it is**: A pre-indexed code knowledge graph that auto-syncs on code changes, built for coding agents like Claude Code and Cursor.

**为什么值得关注**：智能体在大型代码库里最常翻车的，就是「看不全、记不住结构」。codegraph 把仓库变成持续更新的图谱，让 Agent 在改动前就能拿到准确的依赖与调用关系。本月暴涨近 4.8 万星，是「上下文工程」从临时检索走向持久结构化的标志性项目。

**Why it matters**: An agent's most common failure in large codebases is not seeing or remembering the structure. codegraph turns a repo into a continuously updated graph, giving the agent accurate dependency and call relationships before it makes changes. Adding nearly 48k stars this month, it marks context engineering's shift from ad-hoc retrieval to persistent structure.

## 4. ruvnet/RuView

⭐ 73,850（本月 +19,369）· Rust · [链接](https://github.com/ruvnet/RuView)

**是什么**：把普通 WiFi 信号转化为实时空间智能——无需摄像头或可穿戴设备，即可检测人体存在、呼吸心率、跌倒与穿墙移动。

**What it is**: Turns commodity WiFi signals into real-time spatial intelligence—detecting presence, breathing and heart rate, falls, and through-wall motion without cameras or wearables.

**为什么值得关注**：它不是概念演示：支持约 9 美元的 ESP32-S3 节点采集 WiFi CSI，提供 Hugging Face 上的预训练模型（保留集时序三元组准确率 82.3%），并接入 Home Assistant、Apple/Google/Alexa 智能家居。把「无界感知」从论文带到可落地的消费级硬件，在健康监护与适老场景想象力十足。

**Why it matters**: It's not a demo: it supports ~$9 ESP32-S3 nodes for WiFi CSI capture, ships pre-trained models on Hugging Face (82.3% held-out temporal-triplet accuracy), and integrates with Home Assistant and Apple/Google/Alexa homes. Bringing device-free sensing from papers to deployable consumer hardware, it's brimming with potential for health monitoring and aging-in-place.
