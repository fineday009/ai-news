## 1. vercel-labs/agent-desktop

⭐ 10.2k（今日 +2,275）· Rust · [链接](https://github.com/vercel-labs/agent-desktop)

**是什么**：给 AI Agent 用的电脑操作（computer use）CLI：通过操作系统的无障碍树（accessibility tree）读取并操作桌面应用。

**What it is**: Computer use CLI for AI agents — read and operate desktop apps through the OS accessibility tree.

**为什么值得关注**：主流 computer use 方案靠截图加像素匹配，又慢又脆。agent-desktop 改为对无障碍树做快照，每个可操作元素返回一个 ref，Agent 按 ref 操作、再快照校验，循环完全留在你自己的 Agent 里；同时提供 CLI 与 C 库，覆盖 macOS、Windows、Linux。适合想让编码 Agent 驱动原生桌面应用的开发者。

**Why it matters**: Mainstream computer-use approaches rely on screenshots and pixel matching, which is slow and brittle. agent-desktop snapshots the accessibility tree instead, returning a ref for every actionable element; the agent acts on a ref and snapshots again to verify, keeping the loop entirely inside your own agent. It ships as both a CLI and a C library across macOS, Windows and Linux — a good fit for developers who want coding agents to drive native desktop apps.

## 2. JustVugg/colibri

⭐ 46.7k（今日 +675）· C · [链接](https://github.com/JustVugg/colibri)

**是什么**：用纯 C、零依赖在你已有的硬件上运行前沿 MoE（混合专家）模型，专家权重按需从磁盘流式加载。

**What it is**: Run frontier MoE models on hardware you already own — pure C, zero deps, experts streamed from disk.

**为什么值得关注**：MoE 模型动辄上百 GB，普通设备根本装不下。colibri 把"专家从磁盘流式调入"做成默认路径，让内存有限的机器也能跑大模型，且没有 Python/CUDA 依赖负担。9 月上榜时还是 2.75 万星，如今已逼近 4.7 万，仍在持续增长，是本地大模型推理里最有代表性的项目之一。

**Why it matters**: MoE models can be hundreds of GB and simply won't fit on ordinary machines. colibri makes streaming experts off disk the default path, so memory-limited hardware can still run large models — with no Python/CUDA dependency baggage. It was at 27.5k stars when it last made our list in September and is now approaching 47k, still climbing — one of the defining projects in local LLM inference.

## 3. storytold/craft-anything

⭐ 4,723 · Rust · 创建于 2026-10-31 · [链接](https://github.com/storytold/craft-anything)

**是什么**：看懂任何网站、应用或游戏是怎么工作的，再让 AI 做出你自己的版本；一个纯 Rust 的开源洁净室（clean-room）引擎。

**What it is**: Craft Anything: understand how any software works, and craft your own — an open-source, clean-room engine in pure Rust.

**为什么值得关注**：它把"研究原作 → 编码 Agent 构建 → 与原作逐项比对 → 迭代"做成固定的四步流水线，并给出相似度与未对齐清单。默认的 Clean room 模式只用可见信息（截图、可见文本、布局测量），不读原作代码；Deep 模式才调用反汇编、伪 C、Ghidra 等工具，供私人研究使用。出自此前推出 wordcraft、photocraft 等纯 Rust 套件的 ArtCraft 团队，创建 3 天即近 4.7k 星，目前仍是 early alpha。

**Why it matters**: It turns "study the original → have a coding agent build → check against the original → refine" into a fixed four-step pipeline with a similarity score and a list of what doesn't match yet. The default Clean room mode works only from what's visible (screenshots, visible text, measured layout) and never reads the original's code; Deep mode unlocks disassembly, pseudo-C and Ghidra for private use. From the ArtCraft team behind the pure-Rust wordcraft and photocraft suites, it hit nearly 4.7k stars within 3 days — still early alpha.

## 4. p-e-w/heretic

⭐ 38.2k（今日 +420）· Python · [链接](https://github.com/p-e-w/heretic)

**是什么**：免训练的语言模型修改工具：移除审查、抑制"AI 腔"、减少谄媚等。

**What it is**: Training-free language model modification: remove censorship, suppress slop, reduce sycophancy, and more.

**为什么值得关注**：它把过去需要精细数据集和微调的"abliteration"流程做成开箱即用的自动管线，如今目标也从单纯去审查扩展到抑制套话和谄媚这类行为特征。对研究模型对齐边界、做红队测试和本地部署的人很有价值；同时伴随明显的滥用风险，更适合在受控研究环境中使用。8 月底上榜时 2.87 万星，现已 3.8 万。

**Why it matters**: It turns "abliteration" — previously a fine-tuning task needing curated datasets — into a turnkey automated pipeline, and its scope has widened from removing censorship to suppressing behavioral traits like slop and sycophancy. Valuable for alignment research, red-teaming and local deployment, it also carries obvious misuse risk and belongs in controlled research settings. It was at 28.7k stars in late August; it's now at 38.2k.

## 5. CopilotKit/OpenDuet

⭐ 1,864 · TypeScript · 创建于 2026-10-21 · [链接](https://github.com/CopilotKit/OpenDuet)

**是什么**：开源的"主动型"AI Agent 模板：替你把工作做完，同时让你随时掌握进展。

**What it is**: An Open Source template for a proactive AI agent that gets your work done and keeps you in the loop.

**为什么值得关注**：多数 Agent 只在被叫到时才动，OpenDuet 反过来：每天早上给你一份简报，在自己的一台电脑上持续干活，只在需要你时回来；发送、付款、签署或删除任何东西前，都会先展示它要做什么并等你确认。可自托管、自选模型，可在 Web、手机、Slack、Teams 中使用，基于 CopilotKit 的 OpenBot 构建（线程与记忆依赖一个免费的 CopilotKit Intelligence 项目），目前处于早期开发阶段。

**Why it matters**: Most agents only act when called; OpenDuet flips that — it starts your day with a brief, keeps working on a computer of its own, and comes back only when something needs you. Before it sends, pays, signs or deletes anything, it shows exactly what it's about to do and waits for your answer. Self-hostable with your choice of model, usable on web, mobile, Slack and Teams, and built on CopilotKit's OpenBot (threads and memory require a free CopilotKit Intelligence project); still in early development.

## 6. karpathy/nanochat

⭐ 60.0k（今日 +321）· Python · [链接](https://github.com/karpathy/nanochat)

**是什么**：100 美元能买到的最好的 ChatGPT——最简洁的 LLM 训练实验框架。

**What it is**: The best ChatGPT that $100 can buy.

**为什么值得关注**：nanochat 在单个 GPU 节点上覆盖分词、预训练、微调、评测、推理全流程，代码极简可改。README 称 2019 年训练成本约 4.3 万美元的 GPT-2 级模型，现在约 48 美元（8×H100 约 2 小时）即可复现，并维护一个"Time-to-GPT-2"速通排行榜，其中已有 autoresearch 自动调参的成绩。想真正弄懂 LLM 训练全栈的人，这是最好的起点之一。

**Why it matters**: nanochat covers tokenization, pretraining, finetuning, evaluation and inference on a single GPU node, with minimal, hackable code. Per the README, a GPT-2-grade model that cost ~$43,000 to train in 2019 now costs ~$48 (~2 hours on an 8×H100 node), and the repo keeps a "Time-to-GPT-2" speedrun leaderboard that already includes entries from autoresearch-driven tuning. One of the best starting points for anyone who wants to truly understand the full LLM training stack.

**是什么**：一站式 Python 爬虫框架，从单次请求到全站并发抓取都能处理。

**What it is**: 🕷️ The BEST Web Scraping framework that handles everything from a single request to a full-scale crawl!

**为什么值得关注**：它把快速 HTTP 请求、隐身浏览器、JS 渲染、Cloudflare Turnstile 处理、并发爬取和代理轮换整合进一个库；解析层支持自适应元素追踪（网站改版后仍能重新定位元素）和干净的 Markdown 输出。还提供 MCP 服务器和 Agent Skill，让 AI Agent 能直接调用——是"给 Agent 喂网页数据"这条链路上很扎实的基础设施。

**Why it matters**: It bundles fast HTTP requests, stealth browsers, JS rendering, Cloudflare Turnstile handling, concurrent crawling and proxy rotation into one library; the parser supports adaptive element tracking (re-locating elements after a site redesign) and clean Markdown output. With an MCP server and an Agent Skill, AI agents can call it directly — solid infrastructure for the "feed web data to agents" pipeline.

**为什么值得关注**：kornia 把图像变换、相机几何、特征匹配等经典视觉算子做成可微分、可在 GPU 上批量运行的 PyTorch 组件，能直接嵌进深度学习训练管线。随着机器人、3D 重建和具身智能升温，这类"几何 + 学习"的底层库重新获得关注，是老牌项目今日的一次明显回暖。

With robotics, 3D reconstruction and embodied AI heating up, "geometry + learning" foundations like this are drawing renewed attention — a clear uptick today for a long-standing project.

### 播客要点 / Podcast

**Unsupervised Learning · Ep 95: Modal CEO on the Future of Inference, the Chaos of the GPU Market & Origins of the Sandbox Bet** · [节目频道 / Channel](https://www.youtube.com/@RedpointAI)

核心观点：算力远不是一个高效市场，真正持久的护城河不是推理优化技巧，而是围绕推理的一整套产品组合。

- **GPU 市场像"露天集市"**：Modal 创始人兼 CEO 形容 GTC 现场像"GPU 的露天黑市"，在酒店大堂交换号码、靠深夜 WhatsApp 群找卡；Modal 每周要谈两三笔算力交易，已对接 25 家云。算力因地域、网络、可靠性而高度异构，很难像标准合约那样在交易所买卖。
- **推理技巧不持久**：更快的 kernel、更高效的 KV cache 终会被抄走；更持久的是把推理、沙箱、强化学习等相邻产品做成组合。Cognition 用 Modal 的沙箱跑 RL rollout，Ramp 用它跑后台编码 Agent。
- **约 95% 合并代码由 Agent 参与编写**：但基础设施有大量可靠性尾部风险，仍需人来监督；反直觉的是最积极用 Agent 的是资深工程师——"像多了 10 个实习生"，给一套完整测试集就能让 Agent 花三天写出一个文件系统。
- **NeoLab 的隐性杠杆**：GPU 合约通常只需预付约 30%，融 10 亿就能锁 30 亿算力，之后的月付依赖持续融资；一旦 VC 收紧，部分 NeoLab 可能转型成 NeoCloud 转售算力。
- **不是每家公司都要自己的模型**：按收入加权，大部分 token 会来自后训练模型；但按公司数量，多数公司并不需要自己做后训练，RL 即服务的难点是能否产品化而非沦为服务生意。

The takeaway: compute is nowhere near an efficient market, and the durable moat isn't inference tricks but a portfolio of products around inference.

- **The GPU market is a bazaar**: Modal's founder and CEO likens GTC to "an open air drug market, but, like, GPUs" — trading numbers in hotel lobbies and late-night WhatsApp groups. Modal does two or three compute deals a week across 25 clouds; compute varies so much by location, networking and reliability that it can't trade like a fungible contract.
- **Inference tricks don't last**: faster kernels and better KV caches eventually get copied; what lasts is a portfolio of adjacent products — inference, sandboxes, RL. Cognition runs RL rollouts in Modal sandboxes; Ramp runs background coding agents on it.
- **~95% of merged code is agent-written to some extent**, but infrastructure has heavy reliability tail risk and still needs human supervision. Counterintuitively, senior engineers adopt agents most — "like giving them 10 interns"; hand an agent a full test suite and it can write a file system in three days.
- **NeoLabs' hidden leverage**: GPU commitments typically need ~30% upfront, so a $1B raise can lock in ~$3B of compute, with monthly bills that depend on further fundraising. If VC pulls back, some NeoLabs may pivot into NeoClouds reselling capacity.
- **Not every company needs its own model**: weighted by revenue, most tokens will come from post-trained models, but most companies won't do their own post-training; the open question for RL-as-a-service is whether it can become a product rather than a services business.
