## 2. deepseek-ai/DeepInfer

⭐ 22.5k · Python · [链接](https://github.com/deepseek-ai/DeepInfer)

**是什么**：DeepSeek 生产环境大规模推理所用的高性能推理框架，本次开源离线推理部分，支持 DeepSeek-V4.1-Flash。

**What it is**: DeepInfer: the high-performance, large-scale inference framework that powers DeepSeek's production services—this release open-sources offline inference, supporting DeepSeek-V4.1-Flash.

**为什么值得关注**：10 月 16 日创建、10 天 2.2 万星。它把 FlashMLA、DeepGEMM、DeepEP 等自家内核串成完整运行时，带 MoE 专家并行 + 负载均衡、草稿 token 加速解码、批次不变推理与确定性采样、结构化输出，并同时支持 NVIDIA SM100 和华为昇腾 950。KV cache 系统和 PD 分离等组件尚未开源，但作为"DeepSeek 怎么把自家模型跑快"的一手参考，价值极高。

**Why it matters**: Created Oct 16, 22k stars in ten days. It stitches DeepSeek's own kernels (FlashMLA, DeepGEMM, DeepEP and more) into a full runtime with MoE expert parallelism plus load balancing, draft-token decoding speedups, batch-invariant inference and deterministic sampling, structured outputs, and support for both NVIDIA SM100 and Huawei Ascend 950. The KV-cache system and prefill/decode disaggregation aren't included yet, but as a first-hand look at how DeepSeek makes its own models fast, it's hugely valuable.

## 3. Zagitta/gpu-unlock

⭐ 7.2k · C · [链接](https://github.com/Zagitta/gpu-unlock)

**是什么**：把 NVIDIA RTX 30 系显卡的 FP16/BF16 指令发射速率解锁到对应专业卡水平的 Linux 内核模块。

**What it is**: Unlock FP/BF16 instruction issue rate on Nvidia 3000's cards to their professional equivalents—a Linux kernel module.

**为什么值得关注**：它在官方驱动加载前完成解锁，所以不用每次驱动更新都重新打补丁。作者在 3090 Ti 上实测 BF16 稠密 GEMM 从 87 涨到 157 TFLOPS，用户报告 3060–3090 普遍有 +25% 到 +80% 的提升，LLM prefill 也随之变快。对手里有一堆 30 系卡做本地推理/微调的人，这几乎是白送的算力。它会改动硬件底层状态，使用前务必看清兼容性列表和风险。

**Why it matters**: It runs the unlock before the official driver loads, so you don't have to re-patch after every driver release. The author measured BF16 dense GEMM on a 3090 Ti rising from 87 to 157 TFLOPS, and user reports across 3060–3090 cards show roughly +25% to +80%, with LLM prefill speeding up too. For anyone doing local inference or fine-tuning on a pile of 30-series cards, that's close to free compute. It does change low-level hardware state, so read the compatibility table and the risks first.

## 4. OpenMOSS/MOSS-Image

⭐ 1.9k · Python · [链接](https://github.com/OpenMOSS/MOSS-Image)

**是什么**：MOSS-Image 官方仓库，一个 5B 参数的 DiT 基座文生图模型，主打高质量文字渲染、版式生成和高效微调。

**What it is**: Official repository for MOSS-Image, a 5B-parameter base DiT model with high-quality text rendering, layout generation, and efficient fine-tuning.

**为什么值得关注**：开源文生图里"能写对字、能控版式"的小模型不多。MOSS-Image 支持最长 4K token 的提示词和元素位置控制，同时开放 Base 与 SFT 两版权重，发布当天就接入 SGLang、vLLM-Omni 和 ComfyUI，社区一周内就做出了 8 步蒸馏和 LoRA 训练器。另一个看点是它在非 NVIDIA 的异构 GPU 上训练完成。

**Why it matters**: Few small open text-to-image models can render text accurately and control layout. MOSS-Image accepts prompts up to 4K tokens with element-placement control, ships both Base and SFT weights, had day-0 support in SGLang, vLLM-Omni and ComfyUI, and within a week the community had an 8-step distillation and LoRA trainers. It was also trained on heterogeneous, non-NVIDIA GPU platforms.

## 7. JetBrains/thinkrail

⭐ 1.9k（今日 +51）· TypeScript · [链接](https://github.com/JetBrains/thinkrail)

**是什么**：JetBrains 推出的轻量 Agent IDE，围绕 `pi` 编码 Agent 打造，会随你的使用方式自我定制。

**What it is**: Vibe code with pi in a lightweight, real IDE that customises itself around the way you work—JetBrains' agentic IDE.

**为什么值得关注**：老牌 IDE 厂商的新思路：不是把 Agent 塞进 IDE，而是围绕 Agent 重做一个 IDE。每个任务在独立的 git worktree 里并行跑，PR、CI 状态一键处理；项目意图写进一组互相关联的 `SPEC.md`"活规格"，由 Agent 用专用工具读写维护，跨会话不丢失。星数还不高，但值得盯。

**Why it matters**: A new approach from a veteran IDE vendor: rather than bolting an agent onto an IDE, it builds the IDE around the agent. Each task runs in parallel in its own git worktree, with PRs and CI handled in one click, and project intent lives in a connected graph of "living spec" `SPEC.md` files the agent reads and maintains through dedicated tools, so it survives across sessions. Star counts are still small, but it's worth watching.

## 10. ly05010419/MacNativeGames

⭐ 5.5k · C · [链接](https://github.com/ly05010419/MacNativeGames)

**是什么**：在 Apple 芯片的 Mac、iPhone、iPad 上原生运行你自己的《王国之泪》和《旷野之息》——不是模拟器，游戏的 ARM64 代码直接执行，NVN 图形接口在 Metal 上重建。需自备游戏。

**What it is**: Play your own Tears of the Kingdom and Breath of the Wild natively on Apple silicon Mac, iPhone and iPad. Not an emulator: the game's ARM64 code runs directly, NVN rebuilt on Metal. Bring your own game.

**为什么值得关注**：Switch 与 Apple 芯片同为 ARM64，它不翻译 CPU 指令，只重建系统层和图形 API，所以性能远好于传统模拟。这是近期"原生兼容层"浪潮里技术含量最高的项目之一（同类还有 nxnative、d2r-mobile）。授权方面，项目要求自备合法游戏副本。

**Why it matters**: Switch and Apple silicon are both ARM64, so instead of translating CPU instructions it only rebuilds the system layer and graphics API, which runs far faster than traditional emulation. It's one of the most technically impressive entries in the recent wave of "native compatibility layers" (alongside nxnative and d2r-mobile). On licensing, the project requires a legally owned copy of the game.

### 推文精选 / Tweets

**Box CEO Aaron Levie** 预测流经网络安全 Agent 的 token 很快会是现在的 1000 倍：攻击面增长太快，人力早已跟不上，大多数公司本来就没有大厂那样的安全资源。Agent 群可以分头调用各种安全工具、试验不同攻击变体、读日志、评估企业数据风险——这在几个月前还做不到，因为长时运行 Agent 和 computer use 不够好，模型也没在安全领域深度训练过。他认为身份、防火墙、网络、代码扫描、数据保护每一层都有机会，这也是对"攻防平衡"保持乐观的理由之一。

Box CEO **Aaron Levie** predicts we'll soon have 1,000x more tokens flowing through cyber agents than today. The attack surface is growing faster than humans can keep up, and most companies never had big-company security resources to begin with. Agent swarms can fan out across any security tool, test variations of attacks, read logs and assess enterprise data for risk—something that wasn't possible a few months ago, before long-running agents and computer use got good enough and models were trained deeply on cyber. He sees opportunity at every layer (identity, firewall, network, code scanning, data protection) and calls it one reason to be optimistic about the offense/defense balance. ([链接 / link](https://x.com/levie/status/2114187326406766604))

**Vercel CEO Guillermo Rauch** 说他招人时最看重的"第 0 号技能"，是拿捏好指导 AI 的分寸：有时你管太多，而它其实比你更懂；有时你管太少，它就会跑偏、带着错误偏见或缺少上下文。另一条里他注意到模型偏爱 gate、evidence、culprit、provenance、contract 这类"侦探/审计"词汇，因为工程大多是在调试和理解现有系统；他好奇高效工作所需的"最小可用英语"到底有多少，猜测比 ASD-STE100 简化技术英语的约 900 个词还少得多。

Vercel CEO **Guillermo Rauch** says the "#0 skill" he hires for is calibrating how much to guide the AI: sometimes you over-guide when it actually knows better than you, and sometimes you under-guide and it goes off-track, picks up the wrong biases or misses context. In another post he noticed models love detective/auditor vocabulary like gate, evidence, culprit, provenance and contract, because most engineering is debugging and understanding existing systems. He wonders what the "minimum viable English" for productive work really is, and suspects it's far smaller than the ~900 words of ASD-STE100 Simplified Technical English. ([链接 / link](https://x.com/rauchg/status/2114085432749347086) · [链接 / link](https://x.com/rauchg/status/2114164830403989880))

**Ryo Lu**, who has led design at Cursor and Notion, wrote a long essay called "struggle together." His programming and design skill came from failing and starting over, and from the discomfort of working with other people—the difficulty that turned collaborators into "a band" and some of his closest friends. Now that an agent is always there and endlessly patient, he worries we're removing the difficulty before understanding what it taught us, and giving ourselves fewer reasons to leave the screen and work through differences with people.
