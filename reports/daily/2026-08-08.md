### 播客要点 / Podcast

**The MAD Podcast with Matt Turck — How to Build Long-Horizon AI Agents（嘉宾：Basis 联合创始人 Mitch Troyanovsky）**

核心要点：真正的长时代理，瓶颈不在模型有多聪明，而在「英文（规格）」写得有多好、以及代理如何为未来的自己留下可继承的记忆。

- **英文比代码更珍贵**：Mitch 的金句——"The English is more precious because the English affects the performance. The code does not affect the performance."（影响表现的是你写给代理的自然语言规格，而不是代码抽象得漂不漂亮。）人们常纠结于没抽象好的代码文件，却对糟糕的上下文视而不见。

- **评测通过 ≠ 能上生产**：100 个 eval 全过也不代表能泛化到真实世界。类比：如果一个人只是靠翻维基百科才答对，会计师事务所不会雇他——代理同理。

- **《记忆碎片》式的长时记忆**：像电影《Memento》里失忆的主角靠给自己写便条推进目标一样，长时代理需要为「醒来后的自己」留下笔记；运行数小时是几条便签，运行数月就是层层文件夹——这套「本体（ontology）」实际上往往就是一个虚拟文件系统。

- **用「behaviors」而非纯 prompt**：把「希望代理如何行动」写进 markdown 文件（例如「返回 PPT 前先渲染成图检查排版」），既能被人审阅，也能被一个 LLM「裁判」逐条判定代理是否表现出该行为并据此打分。

- **不需要 Move 37**：真实经济中的工作靠的是可靠地把事做对，而不是奥数级的惊天妙手——"You don't need the Move 37s… but not doing work in the real economy."

The Takeaway: for real long-horizon agents, the bottleneck isn't model brilliance—it's how well you write the "English" (the spec) and how the agent leaves inheritable memory for its future self. Mitch Troyanovsky (co-founder of Basis, whose agents run autonomously for hours to days on tasks like end-to-end tax returns) argues the natural-language spec drives performance far more than code abstraction ("The English is more precious…"); that 100 passing evals don't prove real-world generalization; that long-horizon agents need Memento-style notes-to-self, scaling from a few notes over hours to nested folders over months (an "ontology" that's often just a virtual file system); that "behaviors" belong in reviewable markdown files an LLM judge can grade; and that real economic work needs reliability, not Olympiad-level "Move 37" flourishes.

🔗 https://www.youtube.com/@DataDrivenNYC/videos
