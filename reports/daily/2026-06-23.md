## 1. firecrawl/firecrawl

⭐ 137.4k（今日 +615）· TypeScript · [链接](https://github.com/firecrawl/firecrawl)

**是什么**：一套把整个网页抓取、搜索、交互封装成 API 的服务，专为大规模喂给 LLM/Agent 设计。

**What it is**: The API to search, scrape, and interact with the web at scale. 🔥

**为什么值得关注**：Agent 要"看见互联网"，最大痛点就是网页抓取与清洗。Firecrawl 把反爬、渲染、Markdown 化都做成稳定接口，是目前生态里被集成最广的数据入口之一，今日仍在稳定涨星。

**Why it matters**: The hardest part of letting an agent "see the web" is scraping and cleaning pages. Firecrawl turns anti-bot handling, rendering and Markdown conversion into a stable API, making it one of the most widely integrated data front-doors in the ecosystem — and it's still climbing today.

## 2. heygen-com/hyperframes

⭐ 30.1k（今日 +395）· TypeScript · [链接](https://github.com/heygen-com/hyperframes)

**是什么**：写 HTML，渲染成视频，专为 Agent 打造。

**What it is**: Write HTML. Render video. Built for agents.

**为什么值得关注**：把视频生产降维成"写 HTML/CSS"，正好踩中 LLM 最擅长的母语。相比让模型直接生成像素，用代码描述画面更可控、可复用，是近期"agentic video"路线里很有代表性的一个实现。

**Why it matters**: It reduces video production to writing HTML/CSS — the LLM's native tongue. Describing frames with code is far more controllable and reusable than asking a model to paint pixels directly, making it a representative bet in the recent "agentic video" wave.

### 播客 / Podcast

**Training Data — Logan Kilpatrick：《Why the Model Eats the Harness》**（Logan Kilpatrick 负责 Google AI Studio 与 Gemini API）

>
> **Training Data — Google DeepMind's Logan Kilpatrick: "Why the Model Eats the Harness"** (Logan Kilpatrick runs Google AI Studio and the Gemini API)

要点：

- **核心判断**：Agent harness 正取代单纯的 API，成为贯穿 Google 全线产品的新"主线"。Antigravity 这套 harness 不只是 IDE，而是 IDE + Web + CLI + SDK 的生态，并反过来驱动搜索、Gemini app、云等产品变成 agentic native。
- **编码即通用 harness**：Logan 直言"编码已被证明是通用的 Agent harness"——为编码打磨出的那套，约 80% 能直接复用到消费级、24/7 常驻等其它场景。
- **后训练的威力**：Gemini 3.5 Flash 的提升"完全来自后训练"，仅靠 post-training 就超过了上一代 Pro 模型。
- **窄域超级智能**：编码已经"好到像窄域超级智能"，接下来更可能在可验证性强的领域（数学、金融、科学）先爆发，最终形成"锯齿状超级智能"。
- **金句**："我作为开发者，感觉自己在世界里拥有了更多的能动性……现在的问题反过来了——我会想，这个想法能不能做得更有野心一点。"

>
> Takeaways:
>
> - **Core thesis**: the agent harness is replacing the bare API as the new through-line across all of Google's products. Antigravity isn't just an IDE but an ecosystem (IDE + web + CLI + SDK) that in turn powers search, the Gemini app and cloud as agentic-native products.
> - **Coding as the general harness**: Logan is blunt that "coding has proved to be the general-purpose agent harness" — roughly 80% of what's polished for coding carries straight over to consumer and always-on 24/7 use cases.
> - **Post-training's power**: Gemini 3.5 Flash's gains were "all post-training," surpassing the previous Pro model with post-training alone.
> - **Narrow superintelligence**: coding is already "so good it feels like narrow superintelligence," and the next breakouts will likely come in verifiable domains (math, finance, science), ending in a "jagged superintelligence."
> - **Memorable quote**: "I feel like I have more agency in the world… now I have the opposite problem, which is I'm kicking around an idea and I'm like, I could probably make this even more ambitious."
