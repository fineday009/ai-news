## 2. baidu/Unlimited-OCR

⭐ 3,950 · Python · [链接](https://github.com/baidu/Unlimited-OCR)

**是什么**：百度开源的长文档 OCR 系统，用单一统一模型一次性解析超长文档与多页 PDF，支持单图与批量推理。

**What it is**: Baidu's open-source long-document OCR — "Welcome the Era of One-shot Long-horizon Parsing." A single unified model parses lengthy documents and multi-page PDFs in one shot, with both single-image and batch inference.

**为什么值得关注**：在"文档转 Markdown / 结构化解析"成为 RAG 与 Agent 标配输入的当下，把整本长文档一次喂进去而不是切页拼接，是工程上的实打实进步；大厂背书 + 实质模型，比满屏的 skill 合集更有含金量。

**Why it matters**: As document-to-Markdown / structured parsing becomes a standard input layer for RAG and agents, ingesting a whole long document in one shot instead of stitching pages is a real engineering win. A big-lab-backed, substantive model — more weight than the wall of skill bundles around it.

## 3. DietrichGebert/ponytail

⭐ 52,757 · JavaScript · [链接](https://github.com/DietrichGebert/ponytail)

**是什么**：一个让 AI 编码智能体"像房间里最懒的资深工程师那样思考"的技能——按"懒惰阶梯"先查代码是否已存在、能否用原生特性或现成依赖，再决定要不要动手写。

**What it is**: An agent skill that makes coding agents think like the laziest senior dev in the room — a "laziness ladder" that checks whether code already exists, whether a native feature or existing dependency can do the job, before writing anything new. "The best code is the code you never wrote."

**为什么值得关注**：直击大模型"过度工程、能写就写"的通病，官方基准号称在真实任务上把生成代码量砍掉约 54% 而保持安全与校验。理念简单但踩中痛点，单日冲到 5 万星，是今天最热的"反向技能"。

**Why it matters**: It hits the over-engineering, write-first instinct of LLMs head-on; the project's benchmarks claim ~54% less generated code on real tasks while keeping safety and validation intact. A simple idea that lands on a real pain point — 52k stars and the hottest "anti-skill" of the day.

## 7. fguzman82/gateGPT

⭐ 561 · Verilog · [链接](https://github.com/fguzman82/gateGPT)

**是什么**：把一个完整的小语言模型烧进自定义芯片——用 RTL 实现 Karpathy 的 microGPT，跑在 Xilinx Virtex-5 FPGA 上，靠持久化 KV 缓存做增量解码，约 5.6 万 tokens/秒生成人名。

**What it is**: A full Transformer baked into a custom chip — microGPT in RTL, generating names on a Virtex-5 FPGA at ~56k tokens/second, with a persistent KV cache for incremental decoding.

**为什么值得关注**：在"全是软件 skill"的榜单里，这是一股清流——把 Transformer 推理一路压到硅片层面，关注数据通路、微码时序与定点运算。对硬件工程师和 AI 系统研究者是难得的开源参考，新意拉满。

**Why it matters**: Amid a feed wall-to-wall with software skills, this is a refreshing outlier — pushing Transformer inference all the way down to silicon, with real attention to datapath, microcode sequencing and fixed-point arithmetic. A rare open reference for hardware engineers and AI-systems researchers; maxed-out novelty.
