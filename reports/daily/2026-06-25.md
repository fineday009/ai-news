## 1. apple/container

⭐ 42.4k（今日 +1,838）· Swift · [链接](https://github.com/apple/container)

**是什么**：Apple 官方工具，在 Mac 上用轻量级虚拟机创建并运行 Linux 容器，用 Swift 编写、针对 Apple 芯片优化。

**What it is**: A tool for creating and running Linux containers using lightweight virtual machines on a Mac, written in Swift and optimized for Apple silicon.

**为什么值得关注**：它把"每个容器一台微型 VM"的隔离模型带到 macOS 原生体验，启动快、隔离强，是 Docker Desktop 之外的官方级替代。对所有在 Mac 上做后端、跑 CI 或本地开发的工程师都直接受用。

**Why it matters**: It brings a "one lightweight VM per container" isolation model to a native macOS experience — fast startup, strong isolation, and an Apple-grade alternative to Docker Desktop. Directly useful for anyone doing backend work, CI, or local dev on a Mac.

## 2. google-labs-code/design.md

⭐ 17.5k（今日 +619）· TypeScript · [链接](https://github.com/google-labs-code/design.md)

**是什么**：来自 Google Labs 的一份格式规范，用 `DESIGN.md` 向编码 Agent 描述视觉身份，让 Agent 对设计系统有持久、结构化的理解。

**What it is**: A format specification from Google Labs for describing a visual identity to coding agents — `DESIGN.md` gives agents a persistent, structured understanding of a design system.

**为什么值得关注**：当 Agent 越来越多地写前端，"风格漂移"成了真问题。把品牌色、间距、组件规则写进一个可被 Agent 读取的标准文件，等于给 AI 一份不会忘的设计宪法，比每次在 prompt 里复述更可靠。

**Why it matters**: As agents write more frontend code, "style drift" becomes a real problem. Encoding brand colors, spacing, and component rules into a standard file the agent reads is like handing AI a design constitution it won't forget — more reliable than re-explaining it in every prompt.

**Why it matters**: Running a single agent is now routine; the bottleneck has shifted to managing ten at once without chaos. Orca packages parallel orchestration, bring-your-own-subscription, and cross-device control into an IDE-grade experience — right on the most painful coordination point today.

## 🎙️ Builders 动态 / What Builders Are Saying

The biggest topic among builders today is Anthropic's **Claude Tag** launch — tag Claude in a Slack channel and it spins up a sandboxed instance to clone repos, write code, and test. Several practitioners weighed in on the "AI as a teammate, not a tool" paradigm shift, alongside open-model competition and AI pricing.

**Boris Cherny (Claude Code, Anthropic)** explained how Claude Tag works: tag Claude in a channel and it spins up an instance with its own sandbox — cloning repos, writing code, testing, and compiling all in an isolated environment that's thrown away when done; one instance per thread, with its own memory and permissions per channel.

### 播客要点 / Podcast Notes

**No Priors — 《Biohub: The Future of Biology is Open-Source》**，对话 Mark Zuckerberg、Priscilla Chan 与首席科学家 Alex Rives。要点：

**No Priors — "Biohub: The Future of Biology is Open-Source"**, featuring Mark Zuckerberg, Priscilla Chan, and Head of Science Alex Rives. Key points:

- **开源是放大器**：Biohub 选择以开源项目交付工具和数据，"把工具交到更多科学家手里"比建一座私有数据工厂更能加速科学；Cell-by-Gene 这类社区语料就是例证。

- **Open source as a multiplier**: Biohub delivers tools and data as open-source projects because "giving tools to the whole scientific community" accelerates science more than a private data factory — community corpora like Cell-by-Gene are the proof.

- **蛋白质世界模型**：最新发布的 ESM/ESMFold 是一个基于语言模型、用数十亿条蛋白质序列训练的"蛋白质生物学世界模型"，是面向科学发现的开放系统。

- **A world model of proteins**: the newly released ESM/ESMFold is a language-model-based "world model of protein biology" trained on billions of protein sequences — an open system built for scientific discovery.

- **可编程生物学**：当建模覆盖生物的每个层级，就能在数字世界里回答原本只能在实验室提出的问题，把"设计一个分子、开发一款药"的门槛大幅拉低。

- **Programmable biology**: when modeling spans every biological layer, you can answer experimentally in the digital world — sharply lowering the barrier to "design a molecule, develop a drug."

- **走向个体化医疗**：他们的愿景是为每位患者创造专属药物，乃至有朝一日 FDA 接受基于个人模型的"虚拟一期临床试验"。

- **Toward personalized medicine**: the vision is a medicine for every individual patient — and one day the FDA accepting a model-based "virtual phase-one clinical trial."
