## 1. XiaomiMiMo/MiMo-Code

⭐ 10,092 · TypeScript · [链接](https://github.com/XiaomiMiMo/MiMo-Code)

**是什么**：小米开源的终端编码助手，能读写代码、执行命令、管理 Git，并带跨会话持久记忆、树状任务跟踪、规格驱动的 compose 模式和语音输入；通过 dream/distill 机制自我蒸馏知识，可接入多家模型（含免费的 MiMo Auto 通道）。

**What it is**: Xiaomi's open-source terminal coding assistant that reads/writes code, runs commands, and manages Git, with persistent cross-session memory, tree-structured task tracking, a spec-driven compose mode, and voice input. It self-distills knowledge via dream/distill operations and supports multiple LLM providers, including a free MiMo Auto channel.

**为什么值得关注**：这是又一家大厂把自己的"Claude Code 式"编码代理直接开源——口号 "Models and Agents Co-Evolve" 点出它想做的是模型与 harness 一起进化，而非单纯套壳。免费 MiMo Auto 通道降低了试用门槛，自蒸馏与持久记忆则是当下 agent harness 竞争的核心战场。

**Why it matters**: Another major vendor open-sources its own "Claude Code-style" coding agent — the "Models and Agents Co-Evolve" tagline signals it wants the model and the harness to improve together rather than just wrap an API. The free MiMo Auto channel lowers the barrier to trying it, while self-distillation and persistent memory hit the very features the agent-harness race is fought over today.

## 2. tursodatabase/turso

⭐ 20,366（今日 +801）· Rust · [链接](https://github.com/tursodatabase/turso)

**是什么**：一个用 Rust 编写、兼容 SQLite 的进程内 SQL 数据库（SQLite 的彻底重写版）。

**What it is**: An in-process SQL database written in Rust and compatible with SQLite — a full rewrite of SQLite.

**为什么值得关注**：SQLite 是世界上部署最广的数据库之一，用 Rust 重写以获得内存安全、原生异步 I/O 和可扩展性，是一项野心极大的工程。今日 +801 显示开发者愿意为"现代化的 SQLite"买单，对边缘计算、本地优先应用和嵌入式场景意义重大。

**Why it matters**: SQLite is one of the most widely deployed databases on earth, so rewriting it in Rust for memory safety, native async I/O, and extensibility is an enormously ambitious undertaking. A +801 day shows developers want a modernized SQLite, and it matters a lot for edge, local-first, and embedded use cases.

## 3. Tencent-Hunyuan/UniRL

⭐ 652 · Python · [链接](https://github.com/Tencent-Hunyuan/UniRL)

**是什么**：腾讯混元开源的统一多模态模型强化学习框架（UniRL）。

**What it is**: A framework for unified multimodal model reinforcement learning, open-sourced by Tencent Hunyuan.

**为什么值得关注**：多模态模型的 RL 训练（尤其是把图像理解与生成统一在一套奖励/训练流程里）一直缺少现成的工程框架。来自腾讯混元团队、面向"统一多模态"的开源实现，给研究者和团队省下了大量自建 RL 管线的成本，是模型训练侧少见的实质性开源。

**Why it matters**: RL training for multimodal models — especially unifying image understanding and generation under one reward/training pipeline — has lacked ready-made engineering frameworks. An open implementation from Tencent's Hunyuan team aimed at "unified multimodal" saves researchers and teams the heavy cost of building RL pipelines from scratch, a rare piece of substantive open-sourcing on the training side.

An open project that bundles cloning, dictation, and creation into a local studio is compelling for dubbing, podcasting, accessibility, and privacy-sensitive work — extending the trend of bringing AI creative tools on-device.

## 7. shadcn/improve

⭐ 5,788 · 多语言 · [链接](https://github.com/shadcn/improve)

**是什么**：用你最强的模型审计整个代码库、并为更便宜的模型写好执行计划——把"高端模型做规划、低端模型做执行"的分工固化成工作流。

**What it is**: Use your most capable model to audit your codebase and write plans that cheaper models then execute — codifying a "strong model plans, cheap model executes" division of labor.

**为什么值得关注**：作者是 shadcn/ui 的创造者，影响力本身就是看点。更重要的是它抓住了 agent 经济学的核心矛盾：旗舰模型贵、便宜模型弱，于是用贵的做一次性深度审计与规划，再让便宜模型批量执行，是当下控制 token 成本最务实的范式之一。

**Why it matters**: The author created shadcn/ui, so the influence alone draws attention. More importantly it nails the core tension of agent economics: flagship models are expensive and cheap models are weak, so using the expensive one for a one-time deep audit and plan, then letting cheap models execute at scale, is one of the most pragmatic patterns for controlling token cost right now.
