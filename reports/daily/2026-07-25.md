## 1. shiyu-coder/Kronos

⭐ 33.5k（今日 +499）· Python · [链接](https://github.com/shiyu-coder/Kronos)

**是什么**：面向金融时序的开源基础模型，用专门的分词器把连续价格数据离散化，再喂给自回归 Transformer，基于全球 45+ 交易所的 K 线数据训练，覆盖预测、回测等量化任务。

**What it is**: An open-source foundation model for financial time-series. A specialized tokenizer discretizes continuous price data for a large autoregressive Transformer, trained on candlestick (K-line) data from 45+ global exchanges, covering forecasting and backtesting.

**为什么值得关注**：不是又一个"炒股脚本"，而是真正的预训练模型——提供 Hugging Face 权重、推理 API 与微调管线，把"给股价建基础模型"从论文变成了可落地的量化基础设施，今日仍在快速涨星。

**Why it matters**: Not another trading script but a genuine pretrained model — it ships Hugging Face weights, inference APIs and fine-tuning pipelines, turning "a foundation model for prices" into deployable quant infrastructure, and it is still climbing fast today.

### 播客要点 / Podcast

**The MAD Podcast with Matt Turck — 《The Biggest Chip Ever Built — Why OpenAI Runs On It》（嘉宾：Cerebras CEO Andrew Feldman）**

- 速度成了 AI 的主轴：正确指标是"每用户每秒 token 数"，快 token 就是更有生产力的 token；这是 AI 的"宽带时刻"，就像 Netflix 从寄 DVD 变成电影公司。

- Cerebras 造出了计算史上最大的芯片（晶圆级，约为一块 GPU 的 58 倍）——芯片越大，推理越快。

- "在沙漠里的十年"：2020 年他们解决了没人解决过的晶圆级难题，却无人问津，所有人都说会失败，于是他们又造了下一代。

- 观点：CUDA 已不再是 NVIDIA 的护城河——从 GPU 切换到 Cerebras 云"只需八次按键"；并点出行业里"没人谈的三种短缺"。

- Speed is now AI's main axis: the right metric is tokens/second/user; this is AI's "broadband moment," like Netflix going from mailing DVDs to becoming a movie studio. Cerebras built the largest chip in computing history (wafer-scale, ~58× a GPU) — bigger chips mean faster inference. After a "decade in the desert" (they solved wafer-scale in 2020 and nobody cared), Feldman argues CUDA is no longer NVIDIA's moat — switching from a GPU to Cerebras in the cloud "takes eight keystrokes" — and flags "three shortages nobody talks about."

> 金句 / Quote: "How big is the market for slow search? How big is the market for dial up? It's zero." —— Andrew Feldman
