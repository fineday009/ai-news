## 1. browser-use/jev-ultrafast

⭐ 2.5k（两天新增约 2.5k，动量全站最高）· Python · [链接](https://github.com/browser-use/jev-ultrafast)

**是什么**：一个用「动态索引化动作空间」完成网页任务的浏览器自动化 Agent——不再为每一步生成冗长指令，而是借助 TypeSafe 的 Jev 直接做离散的「操作 + 目标」决策，只在必要时才请求文本生成。

**What it is**: A browser-automation agent that completes web tasks via a dynamic, indexed action space — instead of generating verbose instructions per step, it uses TypeSafe's Jev to make discrete operation/target decisions and only asks for text generation when needed.

**为什么值得关注**：官方 demo 里一次 Google Flights 搜索只用 7.1 秒、比同类少 75% 的浏览器协议调用——它把「减少网络往返、砍掉多余截图」做到了极致。对被 Agent 速度和成本劝退的团队，这是把网页自动化从「能跑」推向「可用」的关键一跃，也印证了 Jev 这类快速决策模型正在重塑 Agent 栈。

**Why it matters**: Its demo runs a Google Flights search in 7.1 seconds with 75% fewer browser-protocol calls than comparable approaches, squeezing out network round-trips and needless screenshots. For teams put off by agent latency and cost, it's the leap from "it runs" to "it's usable," and evidence that fast decision models like Jev are reshaping the agent stack.

**Why it matters**: Open-sourcing frontier math results alongside proofs a machine can check line by line is a milestone for AI-for-math — moving from "plausible-looking derivations" to something trustworthy and reviewable. Passing 1.9k stars in two days shows formal verification plus large models is drawing mainstream attention.

## 3. Edge0-AI/Edge0

⭐ 1.9k · Python · [链接](https://github.com/Edge0-AI/Edge0)

**是什么**：面向 Apple Silicon 的 MoE 大模型流式推理框架——按需从存储流式加载专家权重、提前预测路由、并用训练好的 LoRA 适配器补回量化损失，随框架附带 35B 与 8B 两档现成模型。

**What it is**: A streaming inference framework for MoE models on Apple Silicon — it streams expert weights from storage on demand, predicts routing ahead of time, and uses trained LoRA adapters to recover quantization loss; it ships with ready-to-run 35B and 8B tiers.

**为什么值得关注**：官方数据里 35B 模型在 2.9GB 峰值内存下跑到 14.9–17.7 tok/s、质量只掉 3.9 分。把「大 MoE 塞进 Mac」从玄学变成可量化工程，对想在本地跑强模型又受限于内存的开发者极具吸引力。

**Why it matters**: Its numbers show the 35B model hitting 14.9–17.7 tok/s at just 2.9 GB peak memory with only a 3.9-point quality drop. It turns "fit a big MoE on a Mac" from folklore into measurable engineering — highly appealing to developers who want a capable local model but are gated by memory.

## 4. Tencent/BrowserSkill

⭐ 4.3k（今日 +1,302）· TypeScript · [链接](https://github.com/Tencent/BrowserSkill)

**是什么**：让 AI Agent 直接使用你本机那个已登录、正在用的真实浏览器，而不打断你的工作。

**What it is**: Lets AI agents use your real, already-logged-in browser without interrupting your work.

**为什么值得关注**：大多数浏览器 Agent 要么开一个干净的无头浏览器（丢失登录态），要么强占你的窗口。BrowserSkill 复用你已有的会话与身份，绕过了重新登录和验证码这个最大摩擦点，对需要在已授权网站上自动化的场景是务实之选。今日 +1,302 星，是榜单主力动量之一。

**Why it matters**: Most browser agents either spin up a clean headless browser (losing your logins) or hijack your window. BrowserSkill reuses your existing sessions and identity, sidestepping the biggest friction — re-login and captchas — a pragmatic choice for automating on sites you're already authorized on. Its +1,302 stars today is among the board's top momentum.

## 5. TencentCloud/Octop

⭐ 3.5k（今日 +367）· Python · [链接](https://github.com/TencentCloud/Octop)

**是什么**：一个自托管、支持多用户的 AI 助手平台，多个专属 Agent 可并行运行，用一个进程同时提供 Web 面板、CLI、即时通讯（飞书/钉钉/Discord 等）与自动化任务，全部由本地 SQLite 支撑。

**What it is**: A self-hosted, multi-user AI assistant where specialized agents run in parallel — one process serves a web dashboard, CLI, IM channels (Feishu/DingTalk/Discord, etc.) and automation tasks, all backed by a local SQLite database.

**为什么值得关注**：它把「对话、工作区、凭证」都收拢到你自己的机器上，用统一架构解决了 AI 助手四散、隐私与厂商锁定的问题。对想要带持久记忆和知识库、又不愿把数据交给云的家庭、小团队和开发者很对味。

**Why it matters**: It consolidates conversations, workspaces and credentials onto your own machine, using a unified architecture to fight assistant fragmentation, privacy worries and vendor lock-in. It fits households, small teams and developers who want persistent memory and knowledge bases without handing data to the cloud.

**Why it matters**: Robotics is shifting from training task-specific policies toward pretraining a large model that jointly understands world dynamics and actions. **Why it matters**: As "just add parameters" hits diminishing returns, adding effective depth at inference via recurrent/looped structure is a cheap route to stronger reasoning. As research shipped with an official page and code, it's a followable entry point for anyone tracking model-architecture innovation.

**Why it matters**: It turns the input method you use all day into a passive language-learning surface — every keystroke quietly builds foreign vocabulary. Embedding learning into an existing high-frequency habit, plus Rust's performance and offline privacy, is a clever differentiator.
