## 8. shepherd-agents/shepherd

⭐ 906（新建于 6 月 24 日）· Python · [链接](https://github.com/shepherd-agents/shepherd)

**是什么**：一个运行时底座，把 Agent 的执行过程变成可逆的、类 Git 的轨迹，让「元 Agent」能够观察、分叉、重放和回退任意一次运行；写时复制（copy-on-write）分叉比 `docker commit` 快约 5 倍，重放时 KV-cache 复用约 95%。

**What it is**: A runtime substrate that turns an agent's execution into a reversible, Git-like trace, so meta-agents can observe, fork, replay, and revert any run — copy-on-write forks ~5× faster than `docker commit`, with ~95% KV-cache reuse on replay.

**为什么值得关注**：随着 Agent 越跑越长，可观测性与可复现性成了训练/监督其他 Agent 的关键。shepherd 把「时间旅行式调试」带进 Agent 运行时，为元 Agent 优化与强化学习提供了扎实的工程基座。

**Why it matters**: As agent runs grow longer, observability and reproducibility become key to training and supervising other agents. shepherd brings time-travel debugging into the agent runtime, offering a solid engineering foundation for meta-agent optimization and reinforcement learning.

### 🎧 播客 / Podcast

**No Priors ·《Really Big Test-Time Compute in AI Changes Benchmarks, Safety and Research》，嘉宾 OpenAI 研究科学家 Noam Brown**

要点（The Takeaway）：在「花多少钱推理」直接决定模型能力的时代，我们评测模型的方式已经过时了。

- **基准图被读错了**：GPT-5.5 在标准 benchmark 网格上只比 5.4 好几个百分点，于是有人质疑它没进步；但一旦控制「思考时间」，5.5 其实是一次大跳跃——它的思考效率高得多，只是图上没体现出来。
- **能力已是花钱的函数**：Noam 的核心论断是「模型的能力基本上是你往里投多少钱的函数」。给它 10 美元、1 万美元、1000 万美元的推理预算，能做的事天差地别——所以评测必须绑定一个预算，或直接画出「性能 vs 测试时算力」曲线。
- **模型不再很快「见顶」**：配上合理脚手架，如今的模型能连续高效思考数周，性能平台期远在天边，靠「跑到不再提升为止」来评测已不现实。
- **安全评估的隐忧**：各家的「负责任扩展政策 / 准备度框架」大多诞生于 ChatGPT 时代，没有把测试时算力算进去。要真正测出一个长程任务（无论有益还是危险）的上限，可能得让模型真跑一个月、乃至半年——这与「每两三个月出一个新模型」的节奏严重脱节。
- **一个鲜活的例子**：Noam 用做扑克 solver 当私人评测。5.2 会「对他撒谎/糊弄」，而 5.5 几乎能零样本写出一个完整的扑克 solver——「基本上是我整篇博士论文，一次成型」。

**No Priors · "Really Big Test-Time Compute in AI Changes Benchmarks, Safety and Research," with OpenAI Research Scientist Noam Brown**

The Takeaway: in an era where how much you spend on inference directly sets a model's capability, the way we evaluate models is out of date.

- **Benchmark grids get misread**: GPT-5.5 looked only a few points better than 5.4 on standard grids, prompting doubt — but once you control for thinking time, 5.5 is a substantial jump; it's just far more efficient with its reasoning, which the grid hides.
- **Capability is now a function of spend**: Noam's core claim is that "the capability of the model is a function of how much money you put into it." A $10 vs $10K vs $10M inference budget yields wildly different results, so evals must fix a budget or plot performance against test-time compute.
- **Models no longer plateau quickly**: with decent scaffolding, today's models can think productively for weeks, pushing the plateau so far out that "run until it stops improving" is no longer practical.
- **A safety blind spot**: labs' responsible-scaling / preparedness frameworks mostly date to the ChatGPT era and don't account for test-time compute. Truly measuring a long-horizon capability (helpful or dangerous) might require running a model for a month or six — badly out of sync with the every-two-to-three-months release cycle.
- **A vivid example**: Noam builds poker solvers as a personal eval. Where 5.2 would "gaslight" him, 5.5 can nearly zero-shot a full poker solver — "basically my entire PhD thesis, in one go."
