## 2. erkamyaman/rust-anything

⭐ 1,565 · Rust · 创建于 2026-11-16 · [链接](https://github.com/erkamyaman/rust-anything)

**是什么**：把整个应用一段一段地改写成 Rust，每一步都与原程序录制下来的行为做比对。

**What it is**: Rewrite your whole app in Rust, one piece at a time, checked against the original's recorded behavior at every step.

**为什么值得关注**：它先录制 Node.js/TypeScript、Python、C、Go、Ruby 或 Java 应用当前的行为，再让编码 Agent（或你自己）写 Rust，每段改写都必须与录制结果一致才继续推进，README 称回放 38,251 个录制用例零差异。也可以只移植最慢的热点路径，示例里 TypeScript 搜索从每次 10 ms 降到 0.5 ms；作者也坦言它只能发现录制覆盖到的问题。`rust-anything setup` 会把 MCP 服务器和工作流 skill 注册到 Claude Code、Codex、Cursor 和 Gemini CLI，两天前刚创建。

**Why it matters**: It records what your Node.js/TypeScript, Python, C, Go, Ruby or Java app does today, then lets your coding agent (or you) write the Rust, only moving on when each rewritten piece matches the recording—the README reports 38,251 recorded cases replayed with 0 mismatches. You can also port just a hot path; one TypeScript search example drops from 10 ms to 0.5 ms per query, and the author is upfront that it can only catch what the recording covers. `rust-anything setup` registers its MCP server and workflow skill with Claude Code, Codex, Cursor and Gemini CLI. Created just two days ago.
