## 1. github/spec-kit

⭐ 135,795（今日 +1,015）· Python · [链接](https://github.com/github/spec-kit)

**是什么**：GitHub 官方的「规范驱动开发（Spec-Driven Development）」工具包，帮你先把需求写成结构化规范，再让 AI 编码代理据此实现。

**What it is**: GitHub's official toolkit for Spec-Driven Development — you write requirements as a structured spec first, then let AI coding agents implement against it.

**为什么值得关注**：随着代理写代码越来越强，瓶颈从「怎么写」转向「写什么」。spec-kit 把规范作为一等公民，给 vibe coding 加了缰绳；作为官方项目背书强、生态大，今日仍有四位数增长，是这套方法论走向主流的信号。

**Why it matters**: As agents get better at writing code, the bottleneck shifts from "how" to "what." spec-kit makes the spec a first-class artifact, putting reins on vibe coding; with official GitHub backing and a large ecosystem, its continued four-digit daily gain signals the methodology going mainstream.

## 7. p1neappleXpress/OpenFlux

⭐ 1,174（今日 +198）· Go · [链接](https://github.com/p1neappleXpress/OpenFlux)

**是什么**：网络协议栈研究工具——一个支持可插拔传输的 TCP 隧道，可把 TCP 连接经 WebRTC DataChannel 等非常规传输转发，客户端提供 SOCKS5 代理接口。

**What it is**: A network-stack research tool — a TCP tunnel with pluggable transports that routes TCP over unconventional carriers like WebRTC DataChannels, exposing a client-side SOCKS5 proxy.

**为什么值得关注**：可插拔传输架构让研究者能快速试验各种「把流量藏进正常协议」的方案，对网络协议、抗封锁与隐私研究都是趁手的实验平台；纯 Go、依赖少，上手快。

**Why it matters**: The pluggable-transport design lets researchers quickly experiment with tunneling traffic inside ordinary protocols — a handy bench for networking, censorship-resistance and privacy research; pure Go with few dependencies makes it easy to run.

## 9. tigerless-labs/agent-memory

⭐ 1,039 · Python · [链接](https://github.com/tigerless-labs/agent-memory)

**是什么**：面向 AI 代理的长期记忆运行时——以纯 Markdown 作为事实来源，本地排序检索，外加一个独立的「睡眠期」整理层；Claude Code 与 Codex 可共享同一记忆库，无需 API key。

**What it is**: A long-term memory runtime for AI agents — plain Markdown as the source of truth, local ranked retrieval, and an independent sleep-time "manage" layer; Claude Code and Codex share one store, no API key needed.

**为什么值得关注**：用 Markdown 存记忆意味着可读、可 diff、可版本化，避免了向量库黑盒；「睡眠期整理」这种类脑设计和跨工具共享记忆的思路，正是当下 Agent 记忆层最热的方向之一。

**Why it matters**: Storing memory as Markdown keeps it human-readable, diffable and version-controllable, avoiding an opaque vector store; its brain-like "sleep-time consolidation" and cross-tool shared memory sit squarely in one of the hottest areas of agent infrastructure right now.

Guest Richard Socher (one of AI's most-cited researchers, whose new company Recursive raised $650M, author of *The Eureka Machine*) on recursive self-improvement (RSI):

- 科学进步其实在放缓：知识从「一个整体」裂解成「迷宫」——3.4 万本期刊各立门户、子领域细到无人能通盘掌握，成了创新瓶颈。
- Scientific progress is actually slowing: knowledge has fragmented from a body into a labyrinth — 34,000 journals and hyper-specialized subfields no one person can span — which throttles innovation.

- 「凡是能模拟、能验证的，AI 终将攻克」；而最容易构建验证器的领域是编程——软件在吞噬世界，AI 在吞噬软件。
- "Anything you can simulate" and verify, AI will eventually solve; the easiest domain to build verifiers for is programming — software is eating the world, and AI is eating software.

- 幻觉在科学中可能是特性而非缺陷：受控的「大胆假设」能催生新想法，随后再用实验反复验证。

- 自动驾驶式的机器人实验室已有雏形（如 Periodic Labs），但真正成熟他判断还要 2–3 年。
- Self-driving robotic labs already have early attempts (e.g., Periodic Labs), but he pegs real maturity at 2–3 years out.
