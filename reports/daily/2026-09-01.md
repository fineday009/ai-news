## 1. earendil-works/pi

⭐ 100.1k · TypeScript · [链接](https://github.com/earendil-works/pi)

**是什么**：AI 智能体工具箱——统一的 LLM API、智能体循环、终端 UI 与编码智能体 CLI 一体化。

**What it is**: AI agent toolkit: unified LLM API, agent loop, TUI, and a coding-agent CLI, all in one.

**为什么值得关注**：把"接多家模型 + 跑智能体循环 + 终端交互 + 编码 CLI"这套重复造轮子的活儿收敛成一个统一底座，开发者不必再拼装五六个库。星数已破 10 万，是当下 agent 基建赛道最受关注的开源项目之一。

**Why it matters**: It collapses the perpetually-reinvented stack — multi-model access, an agent loop, a terminal UI, a coding CLI — into one coherent base, so developers stop wiring together five or six libraries. Past 100k stars, it is one of the most-watched open-source projects in agent infrastructure right now.

## 2. jingyaogong/minimind

⭐ 56.3k（今日 +495）· Python · [链接](https://github.com/jingyaogong/minimind)

**是什么**：2 小时从零训练一个 6400 万参数的 LLM，含预训练、SFT、强化学习（PPO/GRPO/CISPO）与工具调用的完整实现。

**What it is**: Train a 64M-parameter LLM from scratch in ~2h, with full implementations of pretraining, SFT, reinforcement learning (PPO/GRPO/CISPO), and tool use.

**为什么值得关注**：它把大模型训练的整条链路拆到个人开发者用一块普通 GPU 就能跑完，是理解现代 LLM 内部机制最扎实的动手教程之一——不是概念讲义，而是能跑通的真实代码。

**Why it matters**: It shrinks the whole model-training pipeline down to something an individual can run end-to-end on a modest GPU — one of the most substantive hands-on ways to understand how modern LLMs actually work, real runnable code rather than a slide deck.

**Why it matters**: From ByteDance's Volcano Engine, it folds memory, retrieval, and skills into one self-evolving storage layer written in Rust, aimed squarely at agents' biggest weakness — long-term context and accumulated experience. A signal of a major vendor formally entering agent infrastructure.

## 4. TencentCloud/TencentDB-Agent-Memory

⭐ 25.4k（今日 +410）· JavaScript · [链接](https://github.com/TencentCloud/TencentDB-Agent-Memory)

**是什么**：面向 AI 智能体的团队级记忆中枢，把对话、文档与代码沉淀为四类可复用记忆资产（聊天记忆、技能、Wiki、代码图谱）。

**What it is**: A team-level memory hub for AI agents that turns conversations, docs, and code into four reusable memory assets — Chat Memory, Skills, Wiki, and CodeGraph.

**为什么值得关注**：与 OpenViking 隔空竞争，思路却更偏"团队协作"：让一个团队的多个智能体共享同一套沉淀经验，跨会话持久、可集中管理。腾讯云出品，进一步说明"智能体记忆"正在从功能变成一层独立的基础设施。

**Why it matters**: It competes with OpenViking but leans toward team collaboration — letting a team's many agents share one pool of accumulated experience that persists across sessions and is centrally managed. From Tencent Cloud, more evidence that "agent memory" is becoming its own infrastructure layer rather than a feature.

## 5. firecrawl/pdf-inspector

⭐ 17.4k（今日 +228）· Rust · [链接](https://github.com/firecrawl/pdf-inspector)

**是什么**：快速的 Rust PDF 库，默认自动判别 PDF 是文本型还是扫描件，带位置信息抽取文本并转为干净的 Markdown，无需 OCR。

**What it is**: Fast Rust PDF library that detects whether a PDF is text-based or scanned, extracts text with position awareness, and converts to clean Markdown — no OCR needed.

**为什么值得关注**：RAG 与文档管线里"喂进去的第一步"往往最脏——扫描件、乱版式全卡在这里。它用 Rust 把这一步做快、做准，还能先分类避免无谓的 OCR 开销，是数据管线里被低估但极实用的一环。来自 Firecrawl 团队。

**Why it matters**: In RAG and document pipelines the very first step — ingestion — is usually the dirtiest, where scanned files and messy layouts derail everything. This makes that step fast and accurate in Rust, and classifies first to skip needless OCR cost. An underrated but highly practical piece of the data pipeline, from the Firecrawl team.

## 6. cactus-compute/needle

⭐ 9.9k（今日 +180）· Python · [链接](https://github.com/cactus-compute/needle)

**是什么**：14MB 的端侧基座模型，面向手机、可穿戴、智能家居与机器人；Needle 2 是一个约 4500 万参数、擅长工具调用与结构化抽取的开源模型，塞进单个 14MB 二进制、约 28MB 内存即可运行。

**What it is**: A 14MB on-device foundation model for phones, wearables, smart home, and robots; Needle 2 is an open ~45M-parameter model for tool calling and structured extraction that fits in a single 14MB binary and runs in ~28MB of RAM.

**为什么值得关注**：当行业都在卷参数上限时，它反向把"够用的智能"压到极小体积，让工具调用与结构化抽取能真正跑在边缘设备上、无需联网。这条路线对隐私、离线与机器人场景意义重大。

**Why it matters**: While the industry races toward ever-larger parameter counts, this goes the other way — squeezing "good-enough intelligence" into a tiny footprint so tool calling and structured extraction can run on edge devices with no network. That direction matters enormously for privacy, offline use, and robotics.
