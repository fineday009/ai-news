## 1. cloudflare/security-audit-skill

⭐ 7.5k（今日 +927）· JavaScript · [链接](https://github.com/cloudflare/security-audit-skill)

**是什么**：一个供编码 Agent 使用的技能，可执行多阶段安全审计，并产出经过独立验证、机器可读的漏洞结论。

**What it is**: A coding-agent skill for multi-phase security audits with independently verified, machine-readable findings.

**为什么值得关注**：AI 做安全审计最大的痛点是「幻觉误报」，Cloudflare 的做法是让每条结论都经过独立验证再输出结构化结果，把不可信的 LLM 猜测变成可复核的证据链。对想把 AI 接进安全流水线又怕被误报淹没的团队，这是难得的工程范式。

**Why it matters**: The biggest problem with AI security audits is hallucinated false positives; Cloudflare's answer is to independently verify each finding before emitting structured output, turning untrustworthy LLM guesses into a reviewable evidence chain. For teams wanting AI in their security pipeline without drowning in noise, it's a rare engineering blueprint.

**为什么值得关注**：在真机上研究 iOS、做安全测试或自动化一直受硬件限制，这个工具把虚拟 iOS 设备的搭建自动化，还提供从最小改动到完整越狱的多档安全变体。对移动安全研究者和 iOS 开发者是极具想象空间的基础设施。

**Why it matters**: Researching iOS, doing security testing, or automating has long been gated by physical hardware; this tool automates spinning up virtual iOS devices with security variants from minimal patches to full jailbreak. For mobile-security researchers and iOS developers, it's infrastructure with huge upside.
