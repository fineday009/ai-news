## 1. xai-org/grok-build

⭐ 24.1k · Rust · 7 月 14 日新建 · [链接](https://github.com/xai-org/grok-build)

**是什么**：xAI 推出的编码 Agent 终端界面（TUI）与运行框架，全屏、支持鼠标交互、可扩展。

**What it is**: SpaceXAI's coding agent harness and TUI — fullscreen, mouse-interactive, and extensible.

**为什么值得关注**：不到一个月冲上 2.4 万星，是继 Codex、Claude Code 之后又一个大厂自研编码 Agent。用 Rust 写成、主打终端全屏交互，说明「谁家的模型配谁家的 harness」正在成为大厂标配打法。

**Why it matters**: 24k stars in under a month makes it the latest first-party coding agent from a frontier lab, after Codex and Claude Code. Written in Rust with a fullscreen terminal UX, it signals that "every lab ships its own harness" is becoming standard practice.

## 2. openai/codex-security

⭐ 8.5k · TypeScript · 7 月 13 日新建 · [链接](https://github.com/openai/codex-security)

**是什么**：OpenAI 官方的 Codex Security 命令行工具与 TypeScript SDK，用于发现、验证并修复安全漏洞。

**What it is**: OpenAI's Codex Security CLI and TypeScript SDK for finding, validating, and fixing security vulnerabilities.

**为什么值得关注**：把「AI 找漏洞」从演示做成了可以装进 CI 的工具链——关键在于它不仅报告漏洞，还会做验证（validate）再给修复方案，直击 AI 安全扫描误报率高的痛点。已发布到 npm，工程化程度高。

**Why it matters**: it turns "AI finds bugs" from a demo into a CI-installable toolchain — crucially it doesn't just report vulnerabilities, it validates them before proposing a fix, tackling the false-positive problem that plagues AI security scanners. Already shipped on npm.

## 4. img2threejs/img2threejs

⭐ 9.6k · Python · 7 月 15 日新建 · [链接](https://github.com/img2threejs/img2threejs)

**是什么**：把参考图中的物体重建为纯代码、程序化生成、带质量校验、可动画的 Three.js 模型；主打 token 高效的图生 3D。

**What it is**: rebuild the object in a reference image as a code-only, procedural, quality-gated, animation-ready Three.js model — token-efficient image-to-3D.

**为什么值得关注**：不走生成网格/点云的老路，而是让模型直接产出程序化的 Three.js 代码，天生可编辑、可动画、体积小。「质量门控」的设计让它比一发即弃的 3D 生成更适合真正进产品。

**Why it matters**: instead of generating meshes or point clouds, it has the model emit procedural Three.js code — inherently editable, animatable, and tiny. Its "quality-gated" design makes it far more production-ready than fire-and-forget 3D generation.

**Why it matters**: as more agents need to run persistently, schedule resources, and manage permissions, an "agent OS" abstraction starts to make sense. Rust-based and openly licensed, it's one of the few projects doing real infrastructure work amid a sea of "skills collections".

## 6. drumih/turbo-fieldfare

⭐ 4.9k · Swift · 7 月 17 日新建 · [链接](https://github.com/drumih/turbo-fieldfare)

**是什么**：在任意 M 系列 MacBook 上，用约 2GB 内存跑 Gemma 4 26B-A4B 推理。

**What it is**: Gemma 4 26B-A4B inference in ~2 GB of RAM on any M-series MacBook.

**为什么值得关注**：26B 参数的模型压进 2GB 内存跑，把端侧大模型推理的门槛又拉低了一截。借助 Metal/GPGPU 深度优化，让「不联网、纯本地」的大模型体验在普通 Mac 上真正可行。

**Why it matters**: squeezing a 26B-parameter model into 2 GB of RAM lowers the bar for on-device LLM inference another notch. Deep Metal/GPGPU optimization makes a genuinely offline, fully-local large-model experience feasible on an ordinary Mac.

## 8. uber/ADR

⭐ 723 · Python · Apache-2.0 · 今日登上 Trending · [链接](https://github.com/uber/ADR)

**是什么**：通过可观测性、安全基准测试与威胁检测来保护企业级 AI Agent，已在 Uber 内部部署。

**What it is**: ADR secures enterprise AI agents through observability, security benchmarking, and threat detection — deployed at Uber.

**为什么值得关注**：星数不高，但胜在「真在生产里跑」——由 Uber 开源、配有 arXiv 论文，专治 prompt injection、MCP 滥用等 Agent 特有的安全问题。当大家都在造 Agent 时，把 Agent 当成攻击面来防守的成熟方案还很稀缺。

**Why it matters**: modest star count, but it's the real deal — open-sourced by Uber with an accompanying arXiv paper, purpose-built for agent-specific threats like prompt injection and MCP abuse. While everyone is busy building agents, mature tooling that treats the agent itself as an attack surface remains scarce.

### 播客要点 / Podcast

**Unsupervised Learning —《AI Vibe Check：中国开源模型、蒸馏与 Hugging Face 被攻破》**

- 开场即抛出「连不懂 AI 的家长都发来短信问『OpenAI 的 Agent 攻破 Hugging Face』是怎么回事」——主持人认为这类事件是「科幻照进现实」的信号，是真正的大事，值得认真对待。

- 关于中国开源模型为何这么强，嘉宾认为「蒸馏」远不能解释全部：蒸馏是一种必然，美国实验室、中国实验室、Meta 等非前沿公司都在做。

- 开源之争中 Anthropic 被舆论推到了「反派」位置——它是唯一没签那封公开信的公司，风向正在转向不利于大实验室（Palantir CEO Alex Karp 在 CNBC 上的一段爆火发言被视为集中体现）。

- 政策层面开始认真讨论「许可制」：真正的前沿级模型在公开发布前，是否需要通过某种美国政府认证？这必然会激怒自由意志主义者，但确实是一个正在浮现的政策方向。

- 数据层面，真实世界的使用数据可能比花钱买 RL 环境/标注更有价值；由此实验室可能更激进地把模型直接推给客户、或收购相关公司来拿到这类数据。

**Unsupervised Learning — "AI Vibe Check: Chinese Open Models, Distillation & The Hugging Face Breach"**

- It opens with "even parents who know nothing about AI are texting to ask about OpenAI's agents hacking into Hugging Face" — the hosts read such incidents as sci-fi come to life, a genuinely big deal worth taking seriously.

- On why Chinese open models are so strong, the guest argues distillation explains far less than many claim: distillation is an inevitability that US labs, Chinese labs, and non-frontier players like Meta are all doing.

- In the open-source debate, Anthropic has been cast as the "bad guy" — the sole company that didn't sign the open letter — with sentiment turning against the large labs (Palantir CEO Alex Karp's viral CNBC rant is cited as the sharpest encapsulation).

- On policy, a licensing regime is being seriously discussed: should truly frontier-class models have to clear US-government certification before public release? It would enrage libertarian-minded folks, but it's a real emerging direction.

- On data, real-world usage data may prove more valuable than bought RL environments and labels — pushing labs to offer models directly to customers, or acquire companies, more aggressively to capture it.
