## 1. cloudflare/computer

⭐ 3.3k（今日 +891）· TypeScript · [链接](https://github.com/cloudflare/computer)

**是什么**：给你的 Agent 一台「电脑」。它是一套虚拟文件系统基础设施，让 Agent 和应用能在容器、隔离 shell、JS Worker 等多种后端上执行代码，通过 Durable Object 抽象文件读写与 shell 命令。目前是预览版。

**What it is**: "Give your agent a computer." A virtual-filesystem infrastructure that lets agents and apps execute code across multiple backends — containers, isolate shells, JS workers — abstracting file operations and shell commands through a Durable Object. Currently a preview.

**为什么值得关注**：Agent 要真正干活就需要一个持久、可编程的执行环境，而不是每次都拉起一台重型 VM。Cloudflare 把这层沙箱做进边缘网络，意味着 Agent 应用可以就近、低成本地拿到「一台机器」，是 agentic 基建里很关键的一块拼图。

**Why it matters**: To actually get work done, an agent needs a persistent, programmable execution environment — not a heavyweight VM spun up each time. By baking this sandbox into its edge network, Cloudflare gives agent apps a nearby, low-cost "machine," a key piece of the agentic-infra puzzle.

**Why it matters**: Turning messy office documents into structured Markdown before feeding an LLM or RAG pipeline is unavoidable grunt work. anydoc chases speed and consistency in Rust; from the Firecrawl team and past 5k stars in four days, it shows the "document-ingestion" layer is getting serious attention again.

## 3. sqliteai/waste

⭐ 1.8k · C · 新建于 2026-07-28 · [链接](https://github.com/sqliteai/waste)

**是什么**：把 2.78 万亿参数的完整 Kimi K3 模型「跑」在超出可用内存的机器上——直接从磁盘流式加载被激活的权重。

**What it is**: Run the full 2.78-trillion-parameter Kimi K3 model beyond available RAM by streaming activated weights directly from disk.

**为什么值得关注**：前沿开放模型越做越大，但绝大多数人没有能塞下它的显存/内存。按需从磁盘取权重、只加载 MoE 实际激活的那部分，是把「巨型模型跑在普通硬件上」变成可能的关键路子，和今天的 kimi-k3-in-c、colibri 一脉相承。

**Why it matters**: Frontier open models keep growing, but almost nobody has the VRAM/RAM to hold one. Fetching weights from disk on demand and loading only the experts a MoE actually activates is a key path to running giant models on ordinary hardware — of a piece with kimi-k3-in-c and colibri.

## 4. Accio-Lab/RealReplicaBench

⭐ 1.0k · HTML · 新建于 2026-08-02 · [链接](https://github.com/Accio-Lab/RealReplicaBench)

**是什么**：面向长周期 Agent 的评测框架，含 107 个任务，覆盖浏览器操作、命令行、API 和文档处理，在隔离容器里以确定性方式评分，任务运行在真实商业软件的高保真、可复现副本上。

**What it is**: An evaluation framework for AI agents with 107 tasks spanning browser operations, CLI tools, APIs, and document handling, graded deterministically in isolated containers atop high-fidelity, reproducible replicas of real business software.

**为什么值得关注**：Agent 从「会答题」到「会干活」之间隔着一道鸿沟，而多数基准还停留在问答。用可复现的真实业务系统副本 + 确定性评分来量化长周期任务能力，正是当下评测最缺的一环。

**Why it matters**: There's a gulf between an agent that answers questions and one that does work, yet most benchmarks stay in Q&A territory. Measuring long-horizon task ability on reproducible replicas of real business systems with deterministic grading is exactly what evaluation lacks right now.

**为什么值得关注**：Agent 拿到工具与权限后，就成了新的攻击面：越权、被投毒、被诱导执行危险动作。Uber 把这套「给 Agent 做 EDR」的思路开源，说明企业已在认真对待 Agent 上生产后的安全治理，而非事后补锅。

**Why it matters**: Once agents get tools and permissions, they become a new attack surface — privilege abuse, poisoning, being coaxed into dangerous actions. Uber open-sourcing this "EDR for agents" signals enterprises are taking agent-in-production security seriously, not patching after the fact.

### 播客要点 / Podcast

**Training Data ·《Chai Discovery's Bitter Lesson: Drug Design Is Another Scaling Problem》**

要点一：Chai Discovery 想把「药物发现」变成「药物设计」——不再在数十亿分子里大海捞针，而是像写代码那样，给出你想要的分子「梦想态」，让模型直接生成。

要点二：这是一家「苦涩教训（bitter lesson）信徒」公司——押注扩大数据、模型与算力，并为此找出可靠的 scaling laws；核心原则之一是「简单」，砍掉像旧模型那样 23 个子模块的复杂度。

要点三：验证是关键。生物学「太容易骗自己」，所以实验室仍不可或缺——能评估、能验证，才能持续「爬坡」。他们坚持与礼来、诺华、辉瑞、Argenx 等药企合作，用真实世界检验模型是否真的能泛化，而非只在一两个精挑的任务上好看。

Takeaway 1: Chai Discovery wants to turn drug *discovery* into drug *design* — instead of screening billions of molecules for a needle in a haystack, you specify the molecule's "dream state" and the model generates it, the way LLMs do for code.

Takeaway 2: It's a "bitter-lesson"-pilled company — betting on scaling data, models, and compute, and finding reliable scaling laws to do so. A core principle is simplicity, cutting the 23-submodule complexity of earlier models.

Takeaway 3: Verification is the crux. Biology lets you "fool yourself so easily," so the lab stays essential — only what you can evaluate and verify can you hill-climb. They deliberately partner with Eli Lilly, Novartis, Pfizer, and Argenx to test real-world generalization rather than looking good on one or two cherry-picked tasks.

> 「我们是一家非常信奉苦涩教训的公司，所以我们真心相信扩大数据、扩大模型、扩大算力。」

> "We're a very bitter-lesson-built company, so we really believe in scaling data, scaling models, scaling compute."
