## 1. deepreinforce-ai/Ornith-1

⭐ 815（新项目 · 6/21 创建）· Python · [链接](https://github.com/deepreinforce-ai/Ornith-1)

**是什么**：一套面向智能体编码的开源自改进模型（9B 稠密版，以及 35B、397B 的 MoE 版本），用强化学习同时优化「解题」与「搜索脚手架」两端。

**What it is**: An open-source, self-improving model family for agentic coding — a 9B dense model plus 35B and 397B mixture-of-experts variants — trained with reinforcement learning to optimize both solution generation and the search scaffolding around it.

**为什么值得关注**：官方基准显示 397B 版在 SWE-Bench Verified、Terminal-Bench 上逼近 Claude Opus 级别，且 MIT 开源。一个新团队用可下载的权重把「前沿编码智能体」这件事拉回开放阵营，这类叙事在今年格外稀缺，值得盯一盯它的复现与生态。

**Why it matters**: The team's own benchmarks put the 397B variant near Claude Opus territory on SWE-Bench Verified and Terminal-Bench, all under an MIT license. A new team pulling "frontier coding agent" back into the open-weights camp is a rare story this year — worth watching whether the numbers reproduce and an ecosystem forms.

## 3. diegosouzapw/OmniRoute

⭐ 8.6k（今日 +387）· TypeScript · [链接](https://github.com/diegosouzapw/OmniRoute)

**是什么**：一个免费 AI 网关：单一端点聚合 231+ 家模型提供商（50+ 免费），可把 Claude Code、Codex、Cursor、Cline、Copilot 接到免费的 Claude/GPT/Gemini，并用分层压缩省下 15–95% token、智能自动回退、支持 MCP/A2A 与多模态。

**What it is**: A free AI gateway — one endpoint fronting 231+ model providers (50+ free) — that connects Claude Code, Codex, Cursor, Cline, and Copilot to free Claude/GPT/Gemini, with stacked compression that saves 15–95% of tokens, smart auto-fallback, and MCP/A2A plus multimodal support.

**为什么值得关注**：它把「换模型/省 token/防限流」这些日常痛点收敛到一个网关里，尤其对靠免费额度做实验的开发者很实用。聚合类项目多如牛毛，它的差异化在 token 压缩和自动回退这两件工程细活上。

**Why it matters**: It collapses the daily pains of swapping models, saving tokens, and dodging rate limits into a single gateway — handy for developers experimenting on free tiers. Aggregators are a dime a dozen; its edge is in the unglamorous engineering of token compression and automatic fallback.

**为什么值得关注**：当大家开始同时跑好几个 Claude Code / Codex 会话时，「怎么管住这群 agent」本身成了新需求。用 Rust 做终端原生多路复用，轻量、快、契合命令行工作流——是「一次一个 agent」向「一群 agent 并行」过渡期里的顺手工具。

**Why it matters**: Once you're running several Claude Code / Codex sessions at once, "how do I wrangle this herd of agents" becomes its own need. A Rust-native terminal multiplexer is lightweight, fast, and fits command-line workflows — a handy tool for the transition from one-agent-at-a-time to a parallel fleet.
