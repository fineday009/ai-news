## 1. JustVugg/colibri

⭐ 27.5k（今日 +98）· C · [链接](https://github.com/JustVugg/colibri)

**是什么**：用纯 C、零依赖在你已有的硬件上运行前沿 MoE（混合专家）模型，专家权重按需从磁盘流式加载。

**What it is**: Run frontier MoE models on hardware you already own — pure C, zero dependencies, experts streamed from disk.

**为什么值得关注**：MoE 模型动辄上百 GB，普通设备根本装不下。colibri 把"专家从磁盘流式调入"做成默认路径，让内存有限的机器也能跑大模型，且没有 Python/CUDA 依赖负担，部署极轻。对想在本地折腾大模型的人是实打实的降门槛。

**Why it matters**: MoE models can be hundreds of GB and simply won't fit on ordinary machines. colibri makes streaming experts off disk the default path, so memory-limited hardware can still run large models — with no Python/CUDA dependency baggage, deployment stays extremely light. A real lowering of the bar for anyone tinkering with big models locally.

## 3. diegosouzapw/OmniRoute

⭐ 64.3k（今日 +626）· TypeScript · [链接](https://github.com/diegosouzapw/OmniRoute)

**是什么**：MIT 协议的免费 AI 网关——一个端点接入 352 家供应商、跨多个平台的 1200+ 模型。

**What it is**: A free MIT-licensed AI gateway: one endpoint, 352 providers, 1,200+ models across multiple platforms.

**为什么值得关注**：模型碎片化是当前应用开发者的头号痛点，来回适配各家 API 成本高。OmniRoute 用统一端点抹平差异，切换、比价、做故障转移都简单许多。同类里它的覆盖面（352 家供应商）尤其激进，适合需要多模型兜底的团队。

**Why it matters**: Model fragmentation is a top pain point for app developers — adapting to each provider's API is costly. OmniRoute flattens the differences behind one endpoint, making switching, price comparison, and failover far simpler. Its coverage (352 providers) is unusually aggressive, ideal for teams that need multi-model fallback.

## 4. AlexsJones/llmfit

⭐ 35.8k（今日 +258）· Rust · [链接](https://github.com/AlexsJones/llmfit)

**是什么**：数百个模型与供应商，一条命令就能算出你的硬件到底能跑哪些。

**What it is**: Hundreds of models and providers — one command to find what runs on your hardware.

**为什么值得关注**：面对满天飞的开源模型，"我这台机器能不能跑"往往要试半天。llmfit 用 Rust 写成、跑得快，直接根据显存/内存给出可行清单，省去反复下载踩坑。和 colibri 呼应了同一个趋势：让本地推理不再是玄学。

**Why it matters**: With open models everywhere, "can my machine run this?" usually means a lot of trial and error. Written in Rust and fast, llmfit reads your VRAM/RAM and returns a feasible shortlist, sparing you repeated downloads and dead ends. It echoes colibri's theme: making local inference less of a guessing game.
