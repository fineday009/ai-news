## 1. homeassistant-ai/ha-mcp

⭐ 6.7k（今日 +790）· Python · [链接](https://github.com/homeassistant-ai/ha-mcp)

**是什么**：Home Assistant 的 MCP 服务器，让 Claude、ChatGPT 等 AI 助手直接配置和自动化你的智能家居。

**What it is**: Configure and automate Home Assistant with Claude, ChatGPT, and other AI assistants.

**为什么值得关注**：今日日榜涨星第五，在近 7 天未上榜的项目中居首。它不只是"读几个传感器"，而是能管理配置与自动化的完整 MCP 服务：推荐以 HA-MCP 集成在 Home Assistant 进程内运行，适配所有安装方式，可通过 HACS 或 Home Assistant 2026.11+ 自带的 Marketplace 安装；连接方式可选纯本地或经 webhook 远程访问，还有管理员侧边栏面板管理工具、功能开关与备份，文件/YAML 编辑类工具默认关闭。对想用自然语言改自动化、又在意权限边界的智能家居玩家很实用。

**Why it matters**: Fifth-biggest gainer on today's chart and the top one not featured in the past week. It goes beyond reading a few sensors: it's a full MCP server for managing configuration and automations. The recommended install runs it in-process as the HA-MCP integration, works on every Home Assistant install type, and installs through HACS or the built-in Marketplace on Home Assistant 2026.11+. You can keep it local-only or enable remote access via webhook; an admin sidebar panel manages tools, feature flags and backups, and the file/YAML editing tools are off by default. Useful for smart-home owners who want to edit automations in plain language while keeping permissions in check.

## 2. expo/exact

⭐ 2.3k · Rust · 创建于 2026-11-02 · [链接](https://github.com/expo/exact)

**是什么**：一次编写，原生运行在 Web、macOS、iOS 和 Linux 上，而且 AI Agent 能在每个平台上构建、运行、看到并测试它。

**What it is**: Write an app once. It runs natively on the web, macOS, iOS, and Linux, and an AI agent can build it, run it, see it, and test it on every one of them.

**为什么值得关注**：出自 Expo 团队，是一个面向 Agent 设计的跨平台运行时：界面用小型声明式语言 Contract 描述，数据逻辑用 TypeScript 或 Rust；Web 端编译成约 20 KB 运行时驱动真实 DOM，macOS/iOS/Linux 端由 Rust runner 落成 AppKit/UIKit 等原生控件。README 给出一个实测：全新 Agent 按提示从空仓库做出 Todo 应用、在三个平台通过测试约用时 57 分钟。"让 Agent 自己验证 UI"是当前 AI 写 App 的最大短板，Exact 直接把它做进了框架。

**Why it matters**: From the Expo team, it's a cross-platform runtime designed for agents: you describe the interface in Contract, a small declarative language, and write data logic in TypeScript or Rust. On the web it compiles to a ~20 KB runtime driving the real DOM; on macOS, iOS and Linux a Rust runner renders native AppKit/UIKit-style controls. The README reports a fresh agent building a todo app from a clean clone and passing tests on three platforms in about 57 minutes. Letting agents verify their own UI is the biggest gap in AI-built apps today, and Exact builds that into the framework.

## 8. Leviidev/Henge

⭐ 1.9k · C · 创建于 2026-11-02 · [链接](https://github.com/Leviidev/Henge)

**是什么**：在 iPhone 和 iPad 上运行 macOS 的模拟器。

**What it is**: Emulate macOS on iOS and iPadOS—"macOS on your iPhone and iPad."

**为什么值得关注**：iOS 不给 App 提供虚拟化能力，Henge 就自己写了 JIT、MMU 和虚拟设备来执行 Mac 的 arm64 代码，不依赖 QEMU 或 Virtualization.framework；它在设备上直接下载并还原苹果官方恢复镜像，不解密不打补丁，图形经虚拟 GPU 用 Metal 回放，Safari、Discord 等都能绘制。README 称在 iPhone 17 Pro 上约 15 秒进入锁屏。需要 JIT 与约 43 GB 空间，Apple 账号登录仍会失败，但作为工程作品相当硬核。

**Why it matters**: iOS gives apps no hypervisor, so Henge runs the Mac's arm64 code through its own JIT, MMU and devices, without QEMU or Virtualization.framework. It downloads Apple's restore image and restores it on the device without decrypting or patching anything, and replays a virtual GPU's commands with Metal, so Safari and Electron apps like Discord draw. The README says macOS reaches the lock screen in about 15 seconds on an iPhone 17 Pro. It needs JIT and about 43 GB free, and Apple Account sign-in still fails, but it's a seriously impressive piece of engineering.

### 播客 / Podcast

**Latent Space**：[What Frontier Labs Buy: A Data Deep Dive with Handshake AI — Garrett Lord & Team](https://www.youtube.com/@LatentSpacePod)

一句话结论：前沿实验室买的已经不是"标注"，而是专家亲手搭建的仿真工作世界和评分细则——难点在于把"什么算好"写清楚。

- 数据工作的主角从时薪十美元的大学生变成了投行、律师、医生等专家；但他们也指出，不必非得是顶尖教授，两年资历的投行分析师就足以在很多任务上训练模型，因为模型在普通一年级分析师的工作上仍常出错。
- 一条有价值的训练/评测数据，要先搭出整个环境：Excel、Outlook、FactSet、Bloomberg、SEC EDGAR 等工具的仿真版本跑在 Docker 里，再灌入逼真的邮件和数据室文件。纯靠模型合成的数据"就是 slop"，必须由专家引导 Agent 反复打磨。
- 最难的是评分细则（rubric）：一道任务可能有上百条标准（他们举过 146 条的例子），约一半是"第一年 EBITDA 对不对"这类硬性数字检查。早期有条标准写成"找到净利润 100"，模型就在 Excel 里新建一页，列出 1 到一百万的所有数字——教训是标准既不能太含糊被钻空子，也不能太死板误伤正确答案。
- "87% 的基准分"对银行家来说等于不能用——还得逐条审计；用他们的话说，95% 正确就是 100% 错误，因为修一份有瑕疵的产出不比从头做省时间。
- 想训练自家领域模型的公司：如果数据足够干净、不可被钻空子、是长周期任务，且形状与目标任务一致，有些模型只用约一百条数据就能显著爬坡。节目开场的说法是，这个市场三年前约十亿美元，如今约百亿，三年后很可能到千亿。

The takeaway: frontier labs aren't buying "labels" anymore—they're buying expert-built simulated workplaces and grading rubrics, and the hard part is writing down what "good" means.

- Data work has shifted from college students at ten dollars an hour to experts like investment bankers, lawyers and doctors. Yet the team notes you don't need the world's best professor: a two-year banker can train models in depth on plenty of tasks, because models still fail on ordinary first-year analyst work.
- One valuable unit of training or eval data starts with authoring an entire environment: simulated versions of Excel, Outlook, FactSet, Bloomberg and SEC EDGAR running in Docker, populated with realistic email threads and data-room files. Purely model-generated data "is slop"—experts have to steer the agents and iterate.
- Rubrics are the hardest part: a single task can carry hundreds of criteria (they cite one with 146), about half of them hard numeric checks like "is year-one EBITDA right?" One early criterion read "look for net income of 100," so the model added a sheet listing every number from one to a million. The lesson: criteria must be neither so vague they get reward-hacked nor so specific they reject good answers.
- An 87% benchmark score means a banker can't use it at all, since they'd have to audit everything. As one put it, if it's 95% right it's 100% wrong, because fixing a flawed output takes as long as building from scratch.
- For companies training their own domain models: some models can hill-climb on about a hundred data points if those points are pristine, not reward-hackable, long-horizon and shaped exactly like the target task. The cold open frames the market as about $1 billion three years ago, about $10 billion now, and likely $100 billion three years from now.
