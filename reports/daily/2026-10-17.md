## 1. cursor/plugins

⭐ 12.0k（今日 +278）· TypeScript · [链接](https://github.com/cursor/plugins)

**是什么**：Cursor 官方插件规范与官方插件集合。

**What it is**: The Cursor plugin specification and its set of official plugins.

**为什么值得关注**：继 Claude Code 之后，Cursor 也把「插件」正式标准化。编辑器的能力正从内置功能转向开放插件生态，谁定义了规范，谁就握住了第三方工具的入口。对做 AI 编辑器集成的开发者，这是必须跟进的一手参照。

**Why it matters**: After Claude Code, Cursor is now formalizing a plugin standard of its own. Editor capabilities are shifting from built-in features to an open plugin ecosystem, and whoever defines the spec controls the entry point for third-party tooling. For anyone building AI-editor integrations, this is a first-party reference to track.

## 2. MadsLorentzen/ai-job-search

⭐ 48.6k（今日 +898）· Python · [链接](https://github.com/MadsLorentzen/ai-job-search)

**是什么**：基于 Claude Code 的求职 Agent：扫描招聘网站、按你的简历给每个岗位 1–5 分打分、定制 ATS 友好的简历与求职信、准备面试。

**What it is**: An AI job-search agent built on Claude Code that scans job boards, scores each posting 1–5 against your CV, tailors an ATS-friendly resume and cover letter, and preps you for interviews.

**为什么值得关注**：它把「找工作」拆成一条可跑的 Agent 流水线，本地运行、数据自持。虽与 career-ops 等同类项目思路相近，但单日近千星的动量说明「求职自动化」正成为普通人最先愿意托付给 Agent 的高频场景之一。

**Why it matters**: It turns the job hunt into a runnable agent pipeline that runs locally and keeps your data on your own machine. The idea overlaps with peers like career-ops, but ~900 stars in a day shows "job-hunt automation" is becoming one of the first high-frequency tasks ordinary people are willing to hand to an agent.

**Why it matters**: After Anthropic and Cursor, a platform vendor is now authoring "official skills" itself, piping developer.android.com best practices straight into agents, installable via the Android CLI or as a Claude Code / Codex plugin. It's another vote of confidence from a major player in the open skills standard.

## 4. tangency-labs/solidcraft

⭐ 3.1k · Rust · 10-07 新建 · [链接](https://github.com/tangency-labs/solidcraft)

**是什么**：纯 Rust 写的开源参数化 3D CAD，支持桌面、Web，并通过 MCP 做自动化（BREP / STEP / WASM）。

**What it is**: An open-source parametric 3D CAD application in pure Rust — desktop, web, and automation through MCP (BREP / STEP / WASM).

**为什么值得关注**：参数化 CAD 向来是闭源重镇，这个项目不仅开源，还从第一天就把 MCP 自动化作为一等公民——意味着 Agent 可以直接驱动建模。在一众「界面克隆」里，它是少见真正啃硬核几何内核的作品。

**Why it matters**: Parametric CAD has long been a closed-source stronghold; this project is not only open but treats MCP automation as a first-class citizen from day one — meaning an agent can drive the modeling directly. Among a wave of "UI clones," it's a rare one actually tackling a hard geometry kernel.

## 5. academa-labs/manimgx

⭐ 1.6k · Python · 10-05 新建 · [链接](https://github.com/academa-labs/manimgx)

**是什么**：面向 Agent 的动画引擎——用 Manim 的 Python API 写数学与 3D 视频，底层换成 Rust GPU 核心，渲染极快。

**What it is**: An animation engine for agents — write math and 3D videos with Manim's Python API, backed by a Rust GPU core for blazing-fast rendering.

**为什么值得关注**：Manim（3Blue1Brown 那套）本以慢著称，重写 GPU 核心后让 Agent 批量生成讲解视频变得现实。随着「HTML→视频」「让 Agent 做短视频」成风，一个快到能进 Agent 循环的动画引擎正好卡住缺口。

**Why it matters**: Manim (the 3Blue1Brown toolkit) is notoriously slow; a rewritten GPU core makes agent-driven batch generation of explainer videos practical. As "HTML-to-video" and "agents making short videos" take off, a rendering engine fast enough to sit inside an agent loop fills exactly the right gap.

### 播客要点 / Podcast

**The MAD Podcast with Matt Turck —《Jev：会做决策而非生成文本的 AI》（嘉宾：TypeSafe CEO Diogo Almeida）**

**The MAD Podcast with Matt Turck — "Jev: The AI That Makes Decisions, Not Text" (guest: Diogo Almeida, CEO of TypeSafe)**

- Jev 是一种「机器原生（machine-native）」模型：不生成文本，而是在单次前向传播里直接做分类/打分/是否判断——即所谓「System One」决策引擎。一个月前还无人知晓，如今成了 AI 圈被抄最多的模型（发布视频 4000 万播放、日活约百万、日处理约一万亿 token、三分之一的财富 500 强在用），并刚完成 87 亿估值 7.5B 的 A 轮。

- Jev is a "machine-native" model: instead of generating text, it makes a classification / score / yes-no decision in a single forward pass — a "System One" decision engine. Unknown a month ago, it's now the most-copied model in AI (40M launch-video views, ~1M daily users, ~1 trillion tokens/day, a third of the Fortune 500), fresh off an $870M Series A at a $7.5B valuation.

- 核心主张是从「每秒智能」转向「每美元智能」：当智能单价暴跌，builders 会去做那些以前「本可以做、但因 AI 太贵而懒得做」的应用。

- The core thesis shifts from "intelligence per second" to "intelligence per dollar": once the unit price of intelligence collapses, builders start making the apps they "could have built before but didn't bother with because AI was too expensive."

- 对自我改进式 AGI 持怀疑，主张「Build prod, not God（造产品，别造神）」；并断言「分类是 AI-complete 的」——一个通用分类器本身就逼近通用智能，所以把 Jev 说成「只是个分类器」反而是种恭维。

- He's skeptical of recursive self-improvement toward AGI, favoring "Build prod, not God," and argues "classification is AI-complete" — a universal classifier approaches general intelligence, so dismissing Jev as "just a classifier" is actually a compliment.

- 他认为抄袭者只复制了接口、没复制智能，并预言这种实用自动化会像半导体那样触发「杰文斯悖论」，把机器智能的市场越做越大。最记忆点的一句自评：「95% 爱因斯坦，5% 憨豆先生——而如果它不告诉你何时是憨豆，你又怎么敢拿去自动化任何东西？」

- He says copycats clone the interface but not the intelligence, and predicts this practical automation will trigger a Jevons-paradox expansion of the market for machine intelligence, like semiconductors did. His most memorable self-assessment: "95% Einstein, 5% Mr. Bean — and if it doesn't tell you when it's Mr. Bean, how are you going to automate anything?"
