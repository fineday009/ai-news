## 3. mksglu/context-mode

**为什么值得关注**：随着编码 Agent 跑得越来越久、读的文件越来越多，上下文成本与"记忆丢失"成了最现实的瓶颈（Anthropic 内部也在为此重造工具链）。一个即插即用、能直接省 token 又保住上下文的中间层，击中了每个重度 Agent 用户的痛点。

**Why it matters**: As coding agents run longer and read more files, context cost and "lost memory" have become the most practical bottlenecks (Anthropic is even rebuilding its own toolchain around this). A plug-in layer that cuts tokens and preserves context speaks directly to every heavy agent user's pain.

## 4. HKUDS/CLI-Anything

⭐ 52.6k（今日 +103）· Python · [链接](https://github.com/HKUDS/CLI-Anything)

**是什么**：来自港大数据智能实验室（HKUDS）的开源项目，口号"让一切软件原生可被 Agent 调用"。它用一条七步流水线为专业软件自动生成 Python CLI——分析源码、设计命令、实现、写测试、出文档、发布到 PATH，并附带 SKILL.md 供 Agent 发现命令；已覆盖 GIMP、Blender、LibreOffice、OBS、Godot、ComfyUI 等 40+ 应用。

**What it is**: An open-source project from HKU's Data Intelligence Lab (HKUDS), tagged "Making ALL Software Agent-Native." A seven-phase pipeline auto-generates a Python CLI for professional software — analyzing source, designing commands, implementing, testing, documenting and publishing to PATH, each shipping a SKILL.md so agents can discover commands; 40+ apps already covered, including GIMP, Blender, LibreOffice, OBS, Godot and ComfyUI.

**为什么值得关注**：Agent 擅长推理却不擅长"操作真实专业软件"，而脆弱的 GUI 自动化、阉割版重实现都解决不好。CLI-Anything 让 Agent 调用真实后端（无头 LibreOffice、Blender 的 Python API 等），用 `--json`、REPL、可撤销的项目状态把 GUI 软件变成可脚本化的工具，还配了 CLI-Hub 包管理器——这是"让 Agent 真正会用软件"方向上少见的系统性方案。

**Why it matters**: Agents reason well but struggle to drive real professional software, and fragile GUI automation or stripped-down reimplementations don't cut it. CLI-Anything makes agents call real backends (headless LibreOffice, Blender's Python API) and turns GUI apps into scriptable tools via `--json`, a REPL and undoable project state, with a CLI-Hub package manager to boot — a rare systematic take on actually teaching agents to use software.

### 播客要点 / Podcast

**《David Silver and Lasse Espeholt of Ineffable Intelligence: A Superlearner for the Age of Experience》— Training Data**

David Silver（AlphaGo 背后的关键人物）与 Lasse Espeholt 离开 DeepMind、创立 Ineffable Intelligence，聊他们对"超智能"的押注：

- **超智能来自"经验"而非人类数据**：Silver 一贯的信念是，真正的智能应当像人类与进化那样"自己去发现知识"——通过强化学习从经验中不断变强，而不是模仿人类数据。"能永远持续学习、发现知识的系统"，才是通往超智能的本质。
- **涌现式复杂度**：进化只给了"适者生存"这样极简单的目标，却催生出全部生命的复杂性；人类追逐简单目标→协作→沟通→交易→算术→科学。所以他们不去手工雕刻"科学""语言"的奖励函数，而让 Agent 自己发现——"如果连这都破解不了，我们永远造不出能发现全新知识领域的 Agent。"
- **在模拟中造超智能**：只要模拟是图灵完备的，计算、经济、语言、数学都能在其中完整表达。在模拟里训练可无限并行、完美复现，也最安全，可能比在现实中快 10–100 倍——例外是量子计算这类只存在于现实世界的东西。
- **金句**："provably, everything we mean by computation can be expressed completely inside simulation."（可证明地，我们所说的一切'计算'都能完整地在模拟里表达。）

**Key points from Training Data — "David Silver and Lasse Espeholt of Ineffable Intelligence: A Superlearner for the Age of Experience":**

David Silver (a key figure behind AlphaGo) and Lasse Espeholt, who left DeepMind to found Ineffable Intelligence, on the bet they're making on superintelligence:

- **Superintelligence comes from experience, not human data**: Silver's long-held conviction is that real intelligence should "discover knowledge for itself" the way humans and evolution did — getting better and better through reinforcement learning from experience, rather than imitating human data. A system that "can just keep learning and discovering knowledge forever" is the essence of the path to superintelligence.
- **Emergent complexity**: Evolution handed out only the simplest goal — survival of the fittest — yet all of life's complexity emerged; humans pursued simple goals → coordination → communication → trade → arithmetic → science. So they refuse to hand-craft a reward that spells out "science" or "language," and instead expect agents to discover those — "if we can't crack this problem, we're never gonna have agents that discover whole new fields of knowledge."
- **Building superintelligence in simulation**: as long as a simulation is Turing-complete, computation, economies, language and mathematics can all be fully expressed inside it. Training in simulation can be infinitely parallelized, perfectly reproducible and the safest place to do it — possibly 10–100x faster than reality, with exceptions like quantum computation that only exist in the real world.
- **Memorable quote**: "provably, everything we mean by computation can be expressed completely inside simulation."
