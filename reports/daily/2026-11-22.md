## 1. FlashML-org/FreeVideo

⭐ 4,163（今日 +428）· Python · [链接](https://github.com/FlashML-org/FreeVideo)

**是什么**：在你已有的电脑上生成视频。FreeVideo 最低只需 8 GB 显存和 16 GB 内存即可运行 MiniMax H3，并根据硬件自适应加速路径。

**What it is**: Make videos on the computer you already own. FreeVideo runs MiniMax H3 in as little as 8 GB of VRAM and 16 GB of RAM, with acceleration adapted to your hardware.

**为什么值得关注**：今日 +428 星。它是面向消费级 GPU 的 MiniMax H3 本地推理引擎，以 ComfyUI 插件形式运行，并提供 Windows、macOS、Linux 启动器；核心是统筹显存、内存和磁盘，按硬件选择权重格式（GeForce 与 RTX 30 系用 int8，工作站和数据中心卡用 FP8）并自动探测可用的注意力内核。更新很密：10 月 2 日开源，v0.4.0 让 Claude Code、Codex 等 Agent 可以自己生成视频并支持一分钟以上的长视频和时间线编辑，11 月 10 日的 v0.5.0 加入本地图片生成。适合想在自己机器上跑视频模型、又没有高端显卡的创作者。

**Why it matters**: +428 stars today. It's a local inference engine for MiniMax H3 on consumer GPUs that runs as a ComfyUI plugin, with launchers for Windows, macOS and Linux; the core idea is coordinating VRAM, system memory and disk, choosing the weight format per GPU (int8 on GeForce and RTX 30-series cards, FP8 on workstation and datacenter cards) and probing the available attention kernels automatically. Releases come fast: open-sourced on October 2, v0.4.0 let agents such as Claude Code or Codex make videos on their own and added videos over a minute long plus a timeline editing view, and v0.5.0 on November 10 added local image generation. A fit for creators who want to run a video model on their own machine without a high-end card.

## 2. agent-substrate/substrate

⭐ 8,101（今日 +87）· Go · [链接](https://github.com/agent-substrate/substrate)

**是什么**：Agent Substrate 的核心系统——在 Kubernetes 上为数百万 Agent 提供零信任沙箱。

**What it is**: Agent Substrate: the core system. Zero-trust sandboxing for millions of agents on Kubernetes.

**为什么值得关注**：它的出发点是 Agent 大部分时间都在等模型、等工具、等人：把数量更多的"actor"（有状态的工作负载）映射到数量更少的就绪"worker"上，空闲的 actor 会被快照移出内存，请求到来时再恢复。README 称密度比标准容器高 10 倍，恢复耗时低于 500 毫秒。安全模型把每个 actor 都视为不可信且互相敌对：一律运行在 gVisor 或 Cloud Hypervisor 微虚拟机里，不支持普通 Linux 容器；每个 actor 获得短期的 SPIFFE 证书，沙箱内不持有任何 API key 或云凭证，由内置的出口网关在服务端注入。它是一个低约束的运行时而不是 Agent SDK，跑在标准 Kubernetes 上，适合要在多租户环境里大规模托管 Agent 的平台团队。

**Why it matters**: It starts from the fact that agents spend most of their lives waiting on models, tools or humans: a larger set of "actors" (stateful workloads) is mapped onto a smaller pool of ready "workers", idle actors are snapshotted out of memory and restored when a request arrives. The README claims 10x higher density than standard containers and resume in under 500ms. The security model treats every actor as untrusted and mutually hostile: everything runs in gVisor or a Cloud Hypervisor microVM, plain Linux containers are not supported, each actor gets a short-lived SPIFFE certificate, and the sandbox never holds API keys or cloud tokens—the built-in egress gateway injects credentials server-side. It's a low-opinion runtime rather than an agent SDK and runs on standard Kubernetes, a fit for platform teams hosting agents at scale across tenants.

**是什么**：让你的 Agent 控制你的手机。

**What it is**: Let your agent control your phone.

**为什么值得关注**：它让 Claude Code、Codex 或任意 Agent 在真实手机上滑动、点击、输入和读屏，不需要越狱、不需要 Xcode，也不用在手机上装任何东西：iPhone 通过 Mac 的"iPhone 镜像"窗口操作（需要 macOS 15+ 和 iOS 18+），Android 通过 adb，在 macOS、Linux、Windows 上都能用。安装方式是把一段 setup prompt 发给你的编码 Agent，由它装好 CLI 并带你走完需要动手的步骤；`phone-harness doctor` 用来检查环境。项目另有托管的云手机服务和 MCP 入口，并提供 Hermes Agent 与 OpenClaw 的集成。适合想把只有手机 App 才能完成的任务交给 Agent 的开发者。

**Why it matters**: It lets Claude Code, Codex or any agent scroll, tap, type and read on a real phone with no jailbreak, no Xcode and nothing installed on the phone: iPhone goes through the Mac's iPhone Mirroring window (macOS 15+ and iOS 18+), Android over adb from macOS, Linux or Windows. You install it by sending a setup prompt to your coding agent, which installs the CLI and walks you through the steps that need your hands; `phone-harness doctor` checks the setup. There's also a hosted cloud-phone service with an MCP endpoint, plus integrations for Hermes Agent and OpenClaw. A fit for developers who want to hand agents the tasks that only exist inside phone apps.

## 5. superdesigndev/treg

⭐ 8,716（今日 +121）· Python · [链接](https://github.com/superdesigndev/treg)

**是什么**：面向 Agent 工具的 OpenRouter。

**What it is**: OpenRouter for agent tools.

**为什么值得关注**：思路是把 OpenRouter 对模型做的事搬到工具上：Agent 只需一个 base URL 和一个 token，就能调用一份经过整理、跨多家供应商的端点目录（SEO 与外链、社交与趋势、人物和公司信息补全、广告、抓取、图像与视频生成），按次计费、最低一美分起，不必逐家注册。README 讲得很直白：Agent 干实事需要的工具大多锁在没人会为单次运行购买的订阅后面，Treg 持有这些账号，再按次计费。团队自己的 API key、OAuth 连接、厂商 CLI 和 `SKILL.md` 也可以注册进去，凭证在服务端注入、不会离开服务器，自有 key 的调用不计费。项目由 Superdesign 团队自用并托管在 treg.to，也可以自托管。

**Why it matters**: The idea is to do for tools what OpenRouter did for models: point an agent at one base URL with one token and it can call a curated catalog of endpoints across many providers (SEO and backlinks, social and trends, people and company enrichment, ads, scraping, image and video generation), priced per call from a cent, with no provider signup. The README is blunt about why: the tools an agent needs for real work sit behind subscriptions nobody buys for a single run, so Treg carries those accounts and bills per call. A team's own API keys, OAuth connections, vendor CLIs and `SKILL.md` files can be registered too, with credentials injected server-side so they never leave the server, and calls on your own key are never metered. Built for the Superdesign team and live at treg.to; anyone can self-host.

## 6. boykopovar/AnyPS5

⭐ 59.7k（今日 +850）· C++ · [链接](https://github.com/boykopovar/AnyPS5)

**是什么**：把 PS5 可执行文件自动移植到 Linux 和 Windows 的工具。

**What it is**: Tool for automatic PS5 executables porting to Linux and Windows.

**为什么值得关注**：今日 +850 星，是今天入选项目里涨得最多的，总星数 5.97 万。它不是模拟器：内含一个重链接器，把可执行文件转换成目标系统的原生格式，再配上适合动态链接的系统库实现，没有模拟层，也没有单独的运行时进程；仅重链接器的构建还能在 macOS（含 Apple silicon）上运行，另有文件不离开本机的网页版转换器。着色器重编译器已能产出 SPIR-V，手柄、键鼠映射都已支持，各游戏的进展记录在仓库的讨论区里。项目采用 GPLv2，声明不包含也不分发任何受版权保护的软件、固件或密钥，用户需自行确保所用二进制文件合法。

**Why it matters**: +850 stars today, the most among today's picks, for 59.7k in total. It isn't an emulator: it includes a relinker that converts an executable to the target system's native format, plus implementations of system libraries suitable for dynamic linking, with no emulation and no separate runtime process; the relinker-only build also runs on macOS including Apple silicon, and there's a web converter where files stay on your device. The shader recompiler already produces SPIR-V, controllers and keyboard-and-mouse mapping are supported, and per-game status lives in the repo's discussions. It's GPLv2 and states that it does not include or distribute copyrighted software, firmware or keys—users are responsible for using binaries lawfully.

A fit for data engineering teams that want a self-hosted, lock-in-free ingestion pipeline.

### 播客 · Latent Space：[Scaling Linear’s GTM to $100M ARR — Cristina Cordova, COO](https://www.youtube.com/watch?v=x0VSm6IjcDQ)

**一句话**："问题追踪已死"说的不是 issue 这个单位消失，而是人工跟踪工作的方式该结束了——Linear 选择自己革自己的命，把产品从追踪工具改造成 Agent 也能高效工作的产品开发系统。

**The takeaway**: "Issue tracking is dead" doesn't mean the issue disappears as a unit—it means manually tracking work should end. Linear chose to disrupt itself, turning a tracker into a product development system that agents can work in as well as humans.

- **嘉宾**：Cristina Cordova，Linear 的 COO，加入约三年半；此前在 Notion 负责平台、合作与自助增长，更早在 Stripe 工作了七年半。她说自己加入以来公司至少增长了 10 倍，目前约 170 人、4 万家付费客户，C 级高管只有创始人和她。
- **Guest**: Cristina Cordova, COO of Linear for about three and a half years; before that she led platform, partnerships and self-serve growth at Notion, and spent seven and a half years at Stripe. She says the company has at least 10x'd since she joined; it's about 170 people with 40,000 paying customers, and the only C-suite are the founders and her.
- **一半的工作已经由 Agent 创建**：Linear 在 2025 年上线 MCP server，她说大约一年半后，超过 50% 的 issue 由 Agent 创建；与此同时，人们回到应用里创建工作的数量也在明显上升，因为聊天界面不适合可视化整个团队的工作，也不适合协作。她不认为"只做一个数据库加 MCP server、把数据交给外部 Agent"会是好的商业模式——必须把 Agent 工作流带进自己的工具，并做得比外部工具更好。
- **Half the work is already created by agents**: Linear launched its MCP server in 2025, and about a year and a half later, she says, over 50% of issues are created by agents; at the same time, work created by people coming back into the app is also going up significantly, because a chat interface isn't great for visualizing a whole team's work or for collaboration. She doesn't think being just a database with an MCP server that hands data to outside agents will be a great business model—you have to bring agentic workflows into your tool and make them better than the external ones.
- **入职三周就划掉了"进军企业市场"**：当时公司约 35 到 40 人，销售只有一个人——"靠一个人是没法向上打企业市场的"。她把目标改成先赢下已经在用其他工具的成长期公司，证明能让客户"拆掉旧系统换成 Linear"；直到 2025 年才正式组建企业销售团队。她认为产品只好 20% 或 30% 不足以让人承担迁移成本。
- **She crossed out "go after enterprise" three weeks in**: The company was 35 to 40 people with one person in sales—"you're not going upmarket to enterprise with one person." She changed the goal to winning growth-stage companies that already had a tool, proving Linear could get customers to rip out and replace; the enterprise sales segment only started in 2025. Being 20% or 30% better, she argues, isn't enough to make people pay the switching cost.
- **刻意不做的事**：没有 SDR——首通电话只问"你们多大、能付多少"对客户毫无价值，AE 应该自己能写外联邮件；没有前线部署工程师，只有解决方案工程师，因为她认为 Linear 应该简单到客户自己就能集成；客服从不外包，AI 只起草回复，由人把关质量。她说三年半里从未收到过一次因客服体验差而升级的投诉。
- **What they deliberately don't do**: No SDRs—a first call that only asks how big you are and what you can pay is useless to the customer, and an AE should be able to write an outbound email; no forward-deployed engineers, only solutions engineers, because Linear should be easy enough for customers to integrate themselves; support is never outsourced, and AI only drafts replies while humans are the quality check. In three and a half years, she says, she has never received an escalation over a poor support experience.
- **计划外的一年和新的定价**：2025 年做的 MCP server、Agent 平台 API 以及与 Codex、Cursor、GitHub Copilot 的合作，年初都不在计划里，代价是一批企业功能没做完——但她认为这反而让很多原本不会考虑 Linear 的大企业把它列入了候选。定价上，席位制保留，原本免费的功能不改收费，只对新的 AI 功能按用量计费：在 Linear 里跑编码会话按模型 API 的公开价格加一点收取，测试期免费并提前告知，宁可先定高再降价。现在的产品路线图最多只排六个月。
- **An unplanned year and new pricing**: The MCP server, the agents platform APIs and the partnerships with Codex, Cursor and GitHub Copilot were not planned at the start of 2025, and a batch of enterprise features didn't get done as a result—yet she believes it put Linear on the consideration list of enterprises that wouldn't have looked otherwise. On pricing, seat-based stays and nothing previously free becomes paid; only new AI features are usage-based: coding sessions in Linear are charged at the model API's published rate plus a little on top, betas are free with notice before charging, and they'd rather start expensive and lower prices later. The product roadmap now goes out six months at most.
