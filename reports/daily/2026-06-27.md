## 3. QwenLM/Qwen-AgentWorld

⭐ 568（6/22 新建）· Python · [链接](https://github.com/QwenLM/Qwen-AgentWorld)

**是什么**：阿里 Qwen 团队推出的「语言世界模型」，覆盖 MCP、搜索、终端、软件工程、Android、Web、操作系统七大领域，用超千万条真实交互轨迹训练模型去预测环境会如何回应 Agent 的动作。

**What it is**: A "language world model" from Alibaba's Qwen team spanning seven domains — MCP, Search, Terminal, Software Engineering, Android, Web, and OS — trained on over 10M real interaction trajectories so the model can predict how an environment will respond to an agent's actions.

**为什么值得关注**：让 Agent 在「脑内」先模拟一步行动的后果，是规划与强化学习的关键拼图。Qwen 把环境本身做成可预测的模型（CPT 注入环境知识、SFT 激活下一状态推理、RL 打磨模拟保真度），方向上比再堆一个对话模型更前沿，背后又是有持续产出能力的团队，值得长期跟踪。

**Why it matters**: Letting an agent simulate the consequences of an action "in its head" is a key piece of planning and reinforcement learning. Qwen turns the environment itself into a predictable model (CPT injects environment knowledge, SFT activates next-state reasoning, RL sharpens simulation fidelity), a more frontier direction than stacking yet another chat model — and it comes from a team with a proven output track record.

## 4. raiyanyahya/recall

⭐ 571（6/19 新建）· Python · [链接](https://github.com/raiyanyahya/recall)

**是什么**：给 Claude 等编码 Agent 加上持久记忆——不必每个会话都重新解释你的项目，Recall 让 Agent 跨会话记住上下文，省下重复说明和 token。

**What it is**: Persistent memory for coding agents like Claude — stop wasting tokens re-explaining your project every session; Recall gives the agent context that carries across sessions.

**为什么值得关注**：上下文工程正成为 Agent 体验的胜负手。无记忆的 Agent 每次都从零开始，既费 token 又费耐心；Recall 切中这个高频痛点，定位轻巧、即插即用，对每天与编码 Agent 协作的开发者是实打实的效率工具。

**Why it matters**: Context engineering is becoming the deciding factor in agent UX. A memoryless agent starts from scratch each time, burning both tokens and patience; Recall targets that high-frequency pain with a lightweight, drop-in design — a real productivity tool for developers who work with coding agents daily.
