## 1. apple/container

⭐ 33.8k（今日 +2,430）· Swift · [链接](https://github.com/apple/container)

**是什么**：用轻量虚拟机在 Mac 上创建并运行 Linux 容器的工具，用 Swift 编写，专为 Apple 芯片优化。

**What it is**: A tool for creating and running Linux containers using lightweight virtual machines on a Mac, written in Swift and optimized for Apple silicon.

**为什么值得关注**：它把容器化体验深度绑定到 Apple silicon 的虚拟化栈上，每个容器一个轻量 VM，启动快、隔离强。对长期忍受 Docker Desktop 资源占用的 Mac 开发者是一个原生、轻量的替代方案。

**Why it matters**: It binds the container experience tightly to Apple silicon's virtualization stack — one lightweight VM per container, fast to boot and strongly isolated. For Mac developers tired of Docker Desktop's overhead, it's a native, lean alternative.

## 7. ClaudioDrews/memory-os

⭐ 1,088 · 近期新建 · Python · [链接](https://github.com/ClaudioDrews/memory-os)

**是什么**：为 Hermes Agent 打造的 7 层「记忆操作系统」——基于 Qdrant 的持久记忆、结构化事实、织网式召回、自动整理的 wiki，以及精准的上下文注入，本地运行、支持任意 LLM 提供商。

**What it is**: A 7-layer "memory operating system" for Hermes Agent — persistent memory on Qdrant, structured facts, fabric recall, an auto-curated wiki, and surgical context injection. Runs locally with any LLM provider.

**为什么值得关注**：Agent 长期记忆正从「塞向量库」走向分层架构。它把记忆拆成多层并强调本地运行与 provider 无关，是这一方向上较完整的工程化尝试，适合想给 Agent 加持久个性化记忆的开发者参考。

**Why it matters**: Long-term agent memory is moving from "dump everything into a vector store" toward layered architectures. By splitting memory into layers while staying local-first and provider-agnostic, it's a fairly complete engineering take on the problem — a useful reference for developers adding persistent, personalized memory to agents.

### 播客 / Podcast

**《Training Data》——Google DeepMind 的 Logan Kilpatrick：为什么「模型吃掉脚手架」**

**Training Data — Google DeepMind's Logan Kilpatrick: Why the Model Eats the Harness**

要点 / Key takeaways：

- **「模型吃掉脚手架」是真实趋势**：Logan 认为今天大家说的「model」早已不只是权重，而是围绕权重扩张的一整套系统（Agent 工具调用、托管搜索、代码执行、容器化 harness）。脚手架往往领先模型一两步，但随后会被模型「消化」并内化为原生能力。他大胆预测：「12 个月后，今天意义上的 harness 大概率不再成立——alpha 会转移到别处。」

- **"The model eats the scaffolding" is a real trend**: Logan argues that what we still call "the model" is no longer just weights but an entire sprawling system around them (agentic tool-calling, hosted search, code execution, containerized harnesses). Scaffolding tends to run a step or two ahead, then the model digests it into native capability. His bold call: in twelve months, the harness as we think of it today "probably won't be true — the alpha will be somewhere else now."

- **编码即「窄域超级智能」**：他形容当下的编码能力「好到几乎像 narrow superintelligence」，而且没有挤压人类开发者，反而是放大器——让他敢于把每个想法都往「再野心 10 倍」去推。

- **Coding as "narrow superintelligence"**: He describes today's coding ability as "so good it kind of feels like narrow superintelligence," and notably it hasn't displaced human developers — it acts as an accelerant, pushing him to make every idea "ten steps more ambitious."

- **下一批「窄域超智」看可验证性**：数学、金融、科学这类有较强可验证性的领域最可能率先突破，最终走向「锯齿状（jagged）超级智能」。

- **Next verticals hinge on verifiability**: Domains with strong verifiability — math, finance, science — are likeliest to break through first, leading toward a "jagged" superintelligence.

- **Vibe-code 游戏近在咫尺但仍缺「脚手架」**：模型质量已不是瓶颈，缺的是懂游戏的人把 sprite 生成、编排层等产品支架搭对；他判断「今年内」普通人就能 vibe code 出真正好玩的游戏。

- **Vibe-coded games are close but still need scaffolding**: Model quality is no longer the bottleneck; what's missing is someone who knows games assembling the right product scaffolding (sprite generation, orchestration). He bets that "this year" ordinary people will be able to vibe-code genuinely fun games.
