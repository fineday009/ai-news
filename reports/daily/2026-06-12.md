## 2. apple/container

⭐ 33.6k（今日 +2,430）· Swift · [链接](https://github.com/apple/container)

**是什么**：Apple 官方出品，用轻量虚拟机在 Mac 上创建和运行 Linux 容器，为 Apple Silicon 优化。

**What it is**: A tool for creating and running Linux containers using lightweight virtual machines on a Mac. Written in Swift, optimized for Apple silicon. (Apple official)

**为什么值得关注**：Mac 上跑容器长期依赖 Docker Desktop（收费）或 Colima 等社区方案，Apple 亲自下场做原生方案意义重大。Swift 编写、每容器一个轻量 VM 的隔离模型，性能和安全性都优于传统方案。Mac 开发者必关注。

**Why it matters**: Containers on macOS have long depended on Docker Desktop (paid) or community tools like Colima — Apple shipping a native solution is a big deal. The one-lightweight-VM-per-container isolation model beats traditional approaches on both performance and security. A must-watch for Mac developers.

## 6. anomalyco/rift

⭐ 566（创建于 2026-05-31）· Rust · [链接](https://github.com/anomalyco/rift)

**是什么**：git worktree 的替代品，用 Copy-on-Write 技术 0.1 秒内创建完整工作区，几乎不占额外磁盘。

**What it is**: A better alternative to git worktrees — instant workspace creation (<0.1s) via Copy-on-Write, with massive disk savings. Supports macOS and Linux (btrfs / native reflinks), with a CLI and a Node.js FFI library.

**为什么值得关注**：多 Agent 并行改代码需要隔离工作区，git worktree 慢且费磁盘的问题被放大了。rift 用文件系统级 CoW（macOS/Linux reflinks、btrfs）解决，还提供 Node.js FFI 方便集成进 Agent 工具链。星数不大但卡位精准。

**Why it matters**: Parallel multi-agent coding needs isolated workspaces, which amplifies git worktree's slowness and disk cost. rift solves this with filesystem-level CoW and ships a Node.js FFI for easy integration into agent toolchains. Modest star count, but perfectly positioned.
