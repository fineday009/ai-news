## 9. MSNightmare/RoguePlanet

⭐ 1,219 · 近期新建（2026-06-09）· C++ · [链接](https://github.com/MSNightmare/RoguePlanet)

**是什么**：针对 Windows Defender 竞态条件漏洞的概念验证（PoC）利用，可在 Windows 10/11 上将权限提升到 SYSTEM；它借助挂载 ISO 镜像的能力触发，成功率因机器而异，且因标准用户限制在 Windows Server 上无效。

**What it is**: A proof-of-concept exploit for a race-condition vulnerability in Windows Defender that escalates privileges to SYSTEM on Windows 10/11; it triggers via the ability to mount ISO images, with a success rate that varies by machine, and does not work on Windows Server due to standard-user restrictions.

**为什么值得关注**：把「安全软件本身」变成提权入口，是这类竞态漏洞最讽刺也最有教学价值的地方。作为公开 PoC，它对红队复现、蓝队检测加固都有直接参考意义，也提醒大家：装了杀软不等于安全，攻击面可能恰恰来自防护组件。

**Why it matters**: Turning the security software itself into a privilege-escalation vector is the most ironic — and most instructive — aspect of these race conditions. As a public PoC, it's directly useful for red-team reproduction and blue-team detection/hardening, and a reminder that running AV doesn't equal being secure: the attack surface can come from the very component meant to protect you.

### 播客 / Podcast

**《Training Data》——Google DeepMind 的 Logan Kilpatrick：为什么「模型吃掉脚手架」**

**Training Data — Google DeepMind's Logan Kilpatrick: Why the Model Eats the Harness**

要点 / Key takeaways：

- **「模型吃掉脚手架」是真实趋势**：今天大家口中的「model」早已不只是权重，而是围绕权重扩张的一整套系统（Agent 工具调用、托管搜索、代码执行、容器化 harness）。脚手架往往领先模型一两步，但随后会被模型「消化」并内化为原生能力。他大胆预测：「12 个月后，今天意义上的 harness 大概率不再成立——alpha 会转移到别处。」

- **"The model eats the scaffolding" is a real trend**: What we still call "the model" is no longer just weights but a whole sprawling system around them (agentic tool-calling, hosted search, code execution, containerized harnesses). Scaffolding tends to run a step or two ahead, then the model digests it into native capability. His bold call: in twelve months, the harness as we know it today "probably won't be true — the alpha will be somewhere else."

- **编码即「窄域超级智能」**：他形容当下的编码能力「好到几乎像 narrow superintelligence」，而且没有挤压人类开发者，反而是放大器——让他敢于把每个想法都往「再野心 10 倍」去推。

- **Coding as "narrow superintelligence"**: He describes today's coding ability as "so good it kind of feels like narrow superintelligence," and notably it hasn't displaced human developers — it acts as an accelerant, pushing him to make every idea "ten steps more ambitious."

- **下一批「窄域超智」看可验证性**：数学、金融、科学这类可验证性较强的领域最可能率先突破，最终走向「锯齿状（jagged）超级智能」。

- **Next verticals hinge on verifiability**: Domains with strong verifiability — math, finance, science — are likeliest to break through first, leading toward a "jagged" superintelligence.
