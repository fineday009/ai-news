## 1. NousResearch/hermes-agent

⭐ 235.9k（今日 +896）· Python · [链接](https://github.com/NousResearch/hermes-agent)

**是什么**：Nous Research 出品的自我进化 Agent 框架，内置"闭环学习"——从经验中创建并打磨 skill，跨会话保持持久记忆，可在 Telegram/Discord/Slack 等平台或本地 CLI 上运行（MIT 协议）。

**What it is**: A self-improving agent framework from Nous Research with a closed learning loop—it creates and refines skills from experience, keeps persistent memory across sessions, and runs across platforms like Telegram, Discord, and Slack or locally via CLI (MIT license).

**为什么值得关注**：多数 Agent 框架只是"跑一次任务"，hermes-agent 押注"随用随长"——把学习循环和持久记忆做进内核，让 Agent 越用越强、且不绑死在某台机器或某家模型上。它代表 Agent 从"一次性执行器"向"持续积累能力的长期伙伴"演进的方向。

**Why it matters**: Most agent frameworks just "run a task once"; hermes-agent bets on "grows as you use it"—baking a learning loop and persistent memory into the core so the agent gets stronger over time without being locked to one machine or model provider. It embodies the shift from one-off executors toward long-lived partners that accumulate capability.

## 2. stablyai/orca

⭐ 52.9k（今日 +982）· TypeScript · [链接](https://github.com/stablyai/orca)

**是什么**：面向"一队并行 Agent"的 ADE（Agent 开发环境），让你在一个界面里同时编排、观察与干预多个并发运行的 Agent。

**What it is**: An ADE (agent development environment) built for working with a fleet of parallel agents—orchestrate, observe, and intervene on many concurrently running agents from one interface.

**为什么值得关注**：当开发者从"用一个 Agent"走向"同时跑十几个 Agent"，缺的正是像 IDE 之于代码那样的统一操作台。orca 把并行 Agent 的调度、可视化与人工介入收进一处，直击"多 Agent 难以观测与掌控"的痛点，是今日涨星最猛的项目之一。

**Why it matters**: As developers move from "using one agent" to "running a dozen at once," what's missing is a unified cockpit—an IDE-equivalent for agents. orca folds scheduling, visualization, and human intervention for parallel agents into one place, hitting the pain of "many agents are hard to observe and control." One of today's fastest risers.

## 4. diegosouzapw/OmniRoute

⭐ 54.5k（今日 +667）· TypeScript · [链接](https://github.com/diegosouzapw/OmniRoute)

**是什么**：一个免费、MIT 协议的 AI 网关——单个 OpenAI 兼容端点接入 350+ 家模型提供商（其中 90+ 家有免费额度）、1200+ 个模型，内置自动故障切换与 token 压缩，兼容 Claude Code、Cursor、Cline 等工具。

**What it is**: A free, MIT-licensed AI gateway—one OpenAI-compatible endpoint routing across 350+ model providers (90+ with free tiers) and 1,200+ models, with automatic fallback and token compression, compatible with Claude Code, Cursor, Cline, and more.

**为什么值得关注**：当模型提供商越来越碎片化，一个统一入口 + 自动兜底 + 省 token 的网关，直接解决了开发者"多模型接入与成本控制"的核心痛点。它连日高居涨星榜，印证了"网关不可避免"——把原本要自己搭的路由层做成开箱即用的基础设施。

**Why it matters**: As model providers fragment, a single entry point with automatic fallback and token savings directly addresses developers' core pain—multi-model access and cost control. Its sustained star growth confirms that "gateways are inevitable," turning a routing layer you'd otherwise build yourself into ready-made infrastructure.

**Why it matters**: A rare pure developer tool on today's list, mise folds three long-fragmented concerns—which versions to install, which env vars to set, which scripts to run—into one fast Rust binary. It's another example that solid engineering tools remain essential outside the AI wave, bringing domain balance to the list.

**Madhu Guru（Meta AI 高级总监，曾在 Google 主导 Gemini、Veo、Nano Banana）**：evals 系列第 7 篇提出"金发姑娘原则"——评测要落在"各个待办子任务"的层级，而非只看最终答案。以金融分析 Agent 为例，若只对"最终选股是否正确"打分，就无法定位问题；给"理解客户、收集证据、分析数据、给出建议"各阶段分别建 eval，才能一眼看出是哪一步（如数据分析仅 70%）拖了后腿。

**Madhu Guru (Sr Director, AI at Meta; previously led Gemini, Veo, Nano Banana at Google)**: Part 7 of his evals series offers the "Goldilocks principle"—measure at the level of the jobs to be done, not just the final answer. For a financial-analysis agent, scoring only "was the final stock pick right" can't localize failures; building separate evals for each stage—understanding the client, gathering evidence, analyzing data, making the recommendation—lets you see at a glance which step (e.g. data analysis at 70%) dragged it down.

**Guillermo Rauch (CEO, Vercel)**: Echoing today's gateway surge—intelligence is getting cheaper, and "demand for intelligence is highly elastic": as inference costs fall, usage grows rapidly. **Garry Tan (President & CEO, Y Combinator)**: A bold prediction—"systems of record will need to become AI harnesses or face replacement by agents." The point: traditional SaaS that doesn't expose an actionable surface for agents will be bypassed by agents that can operate tools.

**Peter Yang (writes practical AI tutorials and interviews)**: Relaying a useful distinction from researcher Shreya Shankar—evals split into "top-down" and "bottom-up": the former reasons from the task description alone, which Claude is very good at helping with; the latter means poring over many real sample outputs and externalizing your gut feedback into evals, at which "Claude is very, very bad—that's all you."

**Peter Steinberger (OpenClaw / OpenAI; OpenClaw core contributor)**: An observation on agent interfaces—"CLI is nice; having UI visualizations and your team where you work is nicer"—hinting that the agent experience is moving beyond the pure terminal toward visual, collaborative surfaces.
