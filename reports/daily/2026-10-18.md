## 1. akitaonrails/ai-memory

⭐ 10.0k（今日 +178）· Rust · [链接](https://github.com/akitaonrails/ai-memory)

**是什么**：为各类编码 Agent CLI 提供长期记忆的方案，并让记忆在不同 Agent 厂商之间平滑交接。

**What it is**: A long-term memory solution for agent coding CLIs that also lets memory hand off smoothly between different agent vendors.

**为什么值得关注**：今天重回 Trending 的老项目。随着一个人同时用 Claude Code、Codex、Cursor 成为常态，"记忆锁定在单一工具里"越来越痛；它用 Rust 写了一层厂商无关的记忆层，正好踩在这个痛点上。

**Why it matters**: An older project back on Trending today. As juggling Claude Code, Codex and Cursor at once becomes the norm, memory being locked inside one tool hurts more and more—this builds a vendor-agnostic memory layer in Rust that targets exactly that pain.

**What it is**: Turn your regular JavaScript code into a neural net.

**为什么值得关注**：由前 React 团队的 chenglou 出品，三天冲到 1.7k。它把"手写逻辑"和"可微分网络"之间的界线模糊掉——普通函数也能被当作可训练的网络来优化，是个很有启发性的实验方向。

**Why it matters**: From chenglou (ex-React team), it hit 1.7k in three days. It blurs the line between hand-written logic and a differentiable network—ordinary functions become trainable, a genuinely thought-provoking direction rather than yet another wrapper.

**What it is**: An open-source browser agent that drives web automation over CDP.

**为什么值得关注**：浏览器 Agent 赛道今年很拥挤，但多数要么闭源要么重。Scout 走轻量开源路线、直接用 Chrome DevTools Protocol，适合想把网页操作嵌进自己 Agent 流水线、又不想被 SaaS 锁定的人。

**是什么**：面向 Agent 的逆向工程工具，让任意 ACP Agent 在 macOS/Windows/Linux 上读取、重命名和修补二进制、安卓应用和 GPU kernel。

**What it is**: Agent-first reverse engineering for macOS, Windows and Linux—any ACP agent reads, renames and patches binaries, Android apps and GPU kernels alongside you.

**为什么值得关注**：今年"让 Agent 做逆向"（如 rea）已成一股潮流，eleven 走 ACP（Agent Client Protocol）路线、不绑单一 Agent，并把 Ghidra/Hopper 的能力接进来，是这股逆向工程浪潮里的新一员。

**Why it matters**: "Agents doing reverse engineering" (à la rea) is a real trend this year; eleven rides the ACP (Agent Client Protocol) route so it isn't tied to one agent, and wires in Ghidra/Hopper-grade capabilities—a fresh entrant in the RE wave.

## 9. rohit267/net-merge

⭐ 810 · Go · [链接](https://github.com/rohit267/net-merge)

**是什么**：在 Windows/Linux/Mac 上同时使用所有网络适配器——按连接把 Wi-Fi、以太网和手机/USB 网络共享做负载均衡（基于 TUN + Wintun）。

**Why it matters**: A refreshing non-AI pick. Bonding multiple network paths into one faster, more resilient connection is something pragmatists have long wanted but rarely found as a cross-platform open-source tool—done here in Go, across all three OSes.

**No Priors — "The Changing Physics of Cybersecurity and Drug Development," with OpenAI President Greg Brockman**

  Drug discovery's "physics" is shifting too: if neural nets can be shown more predictive than clinical trials on efficacy/toxicity, regulation should follow—"I think 80% of what's possible will come to fruition very quickly."
