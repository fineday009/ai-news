Agents are also reaching further—Poki taps and types on a real iPhone, a Blender add-on brings MCP into 3D scenes, and ffmpeg-skill lets coding agents edit video locally. ## 1. ag-ui-protocol/ag-ui

⭐ 19.2k（今日 +791）· TypeScript · [链接](https://github.com/ag-ui-protocol/ag-ui)

**是什么**：AG-UI（Agent–用户交互协议），把 Agent 带进前端应用。

**What it is**: AG-UI: the Agent-User Interaction Protocol. Bring Agents into Frontend Applications.

**为什么值得关注**：MCP 解决了 Agent 怎么调用工具，但 Agent 怎么与用户界面实时交互一直缺少统一约定。AG-UI 试图把这一层标准化，让前端应用以同一种方式接入不同的 Agent 后端，而不必为每个框架单独写对接代码。今日 +791 星，适合正在把 Agent 做成产品界面的前端与全栈团队关注。

**Why it matters**: MCP standardized how agents call tools, but how agents interact with a user interface in real time has lacked a shared convention. AG-UI aims to standardize that layer so frontend apps can connect to different agent backends the same way, instead of writing bespoke glue for every framework. Up 791 stars today—worth watching for frontend and full-stack teams turning agents into product UIs.

## 2. NVIDIA/SkillEvaluator

⭐ 2,835（今日 +873）· Python · [链接](https://github.com/NVIDIA/SkillEvaluator)

**是什么**：评测 AI Agent skill 与插件的多层框架：质量门禁、语义重叠检测、合成评测数据集生成，以及衡量 skill 如何影响 Agent 行为的在线 Agent 评测。

**What it is**: Multi-tier framework for evaluating AI agent skills and plugins with quality gates, semantic overlap detection, synthetic evaluation dataset generation, and live agent evaluation that measures how skills affect agent behavior.

**为什么值得关注**：skill 仓库遍地开花，但"装了这个 skill 到底有没有用"很少被量化。SkillEvaluator 先做质量与安全检查，再对比"有/无 skill"两组运行的任务结果；`pip install skillevaluator` 后可在本地、CI 或 Agent 里调用，第一层校验无需 API key。它是 NVIDIA Verified Skills 流水线的一部分，附有论文和官方博客，适合维护 skill 库的团队把评测纳入 CI。

**Why it matters**: Skill repos are everywhere, but whether a skill actually helps is rarely measured. SkillEvaluator runs quality and security checks first, then compares task results with and without the skill; after `pip install skillevaluator` you can run it from the terminal, CI or an agent, and tier-1 validation needs no API key. It's part of NVIDIA's Verified Skills pipeline, with a paper and an official blog post—useful for teams that maintain skill libraries and want evaluation in CI.

Install it once from a Mac or Windows PC and the app then runs tasks on the phone without the computer. You choose the approval level, but payments, deletions and Wallet actions always ask. AGPL-3.0, currently at 0.4.0 Beta.

## 5. kajisho5/ffmpeg-skill

⭐ 6,950（今日 +367）· Python · [链接](https://github.com/kajisho5/ffmpeg-skill)

**是什么**：面向编码 Agent 的本地视频编辑器：42 个带机器可读契约的 FFmpeg 工具和一个 MCP 服务器，支持 Claude Code、Cursor 和 Codex；剪辑、字幕、重构图、响度、各平台导出，无需云服务和 API key。

**What it is**: Local video editor for coding agents: 42 FFmpeg tools with a machine-readable contract and an MCP server, for Claude Code, Cursor and Codex. Cut, captions, reframe, loudness, platform exports. No cloud, no API keys.

**为什么值得关注**：让 Agent 直接拼 FFmpeg 命令行容易出错，这个项目把常用操作封装成有明确输入输出契约的工具，Agent 调用更可靠。全部在本地完成，适合做短视频二次剪辑、字幕和多平台导出的创作者与开发者。

**Why it matters**: Having an agent hand-write FFmpeg command lines is error-prone; this project wraps common operations as tools with explicit input/output contracts, so agent calls are more reliable. Everything runs locally—handy for creators and developers doing short-form recuts, captions and multi-platform exports.

**Vercel CEO Guillermo Rauch**: Introduced xeet, a hermetic, pixel-perfect X post renderer in safe Rust / wasm—no browser, network, filesystem or system fonts—that renders a post to PNG in about 1 ms, 100x–1000x faster than booting a browser and screenshotting. He stresses it's an "autorepo": an oracle boots Chrome to verify tens of thousands of text-layout rules, and a CI canary tracks the original and files signed PRs for agents to act on, all built around "verification engineering." In another post he joked that AI is now good at naming: a small CLI he made to diagnose system slowdowns got named hog 🐖. **AI tutorial creator Peter Yang** (interviewing Nate Parrott of Anthropic): Parrott explains why Claude keeps producing the same design—each time it's in a fresh context and thinks it's inventing the "serif text, off-white background, orange, bars on card edges" style for the first time—so the Claude Design prompt explicitly tells the model it over-biases toward those fonts and colors and not to use them unless asked, which helps a lot. He also notes that testing an idea took weeks at Arc but one to two days at Anthropic: the build cycle is compressed, but not the cycle of putting it in people's hands and learning whether they'll use it.
