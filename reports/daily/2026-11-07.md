## 3. D3voz/openjutsu

⭐ 1,862 · TypeScript · 创建于 2026-10-26 · [链接](https://github.com/D3voz/openjutsu)

**是什么**：开源、本地运行的"一键换角"视频工具（Higgsfield Genjutsu 的开源替代）：拖入一段视频和一张角色照片，视频里的主角就被换成你的角色；也能换发型衣服、移除物体或换场景，镜头、剪辑、动作和配乐保持不变。

**What it is**: One-click character swap for videos—an open-source, local Higgsfield Genjutsu alternative. Drop in a video and a character photo, press Generate, and the main person is replaced by your character; or change hair or clothes, remove something, or move them elsewhere, while the camera, cuts, motion and soundtrack stay.

**为什么值得关注**：全部基于开放权重、在你自己的 GPU 上运行：MiniMax H3 生成视频、SAM 3.1 追踪人物、Qwen3-VL 8B 描述画面与镜头（也可换成更小的视觉语言模型）。前端是基于 ComfyUI 工作流的小型 Next.js 应用，支持多人指定替换、涂抹放置物体、"从图片生成"并重新打光、修复小脸等后处理。对不想把素材上传到云端的创作者来说，是闭源换角服务的完整本地替代。

**Why it matters**: Everything runs on open weights on your own GPU: MiniMax H3 for the video, SAM 3.1 to track people and Qwen3-VL 8B to describe pictures and shots (smaller vision-language models can be swapped in). The app is a small Next.js front end over a ComfyUI workflow, with multi-person "who becomes who" swaps, painted object placement, from-picture generation with relighting, and face-fixing post-processing. For creators who don't want to upload footage to the cloud, it's a complete local alternative to closed swap services.

## 4. interplains/Zero-Breach-Toolkit

⭐ 4,521 · Python · 创建于 2026-10-25 · [链接](https://github.com/interplains/Zero-Breach-Toolkit)

**是什么**：免费开源的离线检测工具，在 Windows、macOS、Linux 电脑、Android 手机和 iPhone 备份中查找已知雇佣间谍软件（Pegasus、Predator、Graphite、Candiru 等）的痕迹。

**What it is**: Free, open-source check for traces of mercenary spyware (Pegasus, Predator, Graphite, Candiru and more) on Windows, macOS and Linux computers, Android phones and iPhone backups.

**为什么值得关注**：10 月 29 日上日报时 2.8k 星，九天后已达 4.5k。它的设计很克制：只读、不改动原始证据和系统设置；扫描时不发任何网络请求、没有上传功能；每份报告都写明发现了什么、证据强度如何、哪些没能检查，并强调"没发现"不等于"安全"。附有面向零技术背景用户的分步教程，并首先建议疑似被针对的人联系 Access Now 或国际特赦组织安全实验室。

**Why it matters**: It had 2.8k stars when it made the daily on October 29 and is at 4.5k nine days later. Its design is restrained: read-only, never modifying source evidence or system settings; no network requests during a scan and no upload feature; every report states what was found, how strong the evidence is and what couldn't be checked, stressing that a clean result is not proof you're safe. It ships step-by-step guides for non-technical users and first points anyone who thinks they're targeted to Access Now's helpline or Amnesty International's Security Lab.

### 播客 / Podcast

**[Unsupervised Learning · Ep 97: Jev Creator on Decision Models, Benchmark Fatigue & Why the Labs Missed It](https://www.youtube.com/@RedpointAI)**

- **机器原生的模型**：嘉宾认为，LLM 作为被软件调用的模块，绝大多数调用结果其实是给程序而不是给人看的；Jev 就是从这种"机器原生的认知内核"倒推设计的决策模型，但他坦言离目标还差很远。

  **Machine-native models**: The guest argues that when LLMs are called as modules inside software, the vast majority of outputs are consumed by programs rather than people; Jev is a decision model designed backward from that "machine-native cognitive core," though he admits it's still far from there.

- **语义类型与语义安全检查**：他设想一种"语义依赖类型"——用自然语言声明输出的性质，再由 Jev 这类模型验证各部分能否组合；并希望在每一次工具调用上加一层又快又便宜、按组织自身规则定义的语义安全检查，而不是依赖模型厂商的通用路由。

  **Semantic types and semantic security checks**: He imagines "semantic dependent typing"—stating output properties in natural language and having Jev-like models verify that everything composes—and wants fast, cheap semantic security checks on every tool call, defined by an organization's own rules rather than a model vendor's generic router.

- **"KV cache 的暴政"**：他认为编码 Agent 几乎所有实质性的 UX 设计都围绕 KV cache 展开，这也是模型路由在 Agent 里不太好用的原因；但对无状态的"任务进、结果出"类调用，可以先用便宜模型加廉价评审，不行再升级到更大的模型或多次采样择优。

  **"The tyranny of the KV cache"**: He says nearly every meaningful UX decision in coding agents is built around the KV cache, which is why routing tends not to work for agents; for stateless "task in, task out" calls, though, you can try a cheap model with a cheap judge first and escalate to a larger model or best-of-n only when needed.

- **对 Anthropic IPO 的谨慎看法**：他认为编码 Agent 极有价值，但实际使用中有多少真正创造价值尚不清楚，这个市场可能大涨也可能回落；他听说前沿实验室最大的长处其实是（尤其在算力交易上的）金融工程，并担心部分估值建立在对 AI 未来的误判上。

  **A cautious take on Anthropic's IPO**: He calls coding agents massively valuable but says it's unclear how much actual use is truly valuable, and the market could swing either way; he's heard the labs' greatest strength is financial engineering—especially on compute deals—and worries some valuations rest on misunderstandings of AI's future.

- **信任边界**：理解 Agent 的关键是"你敢把哪些决策交给它"；代码和数学之所以特殊，是因为下行风险有限——数学只花算力，代码有 git 和人在回路中兜底。

  **Trust boundaries**: The key to understanding agents is which decisions you can trust them with; code and math are special because their downside is capped—math costs only compute, and code has git and humans in the loop.
