## 1. TauricResearch/TradingAgents

⭐ 104.0k（今日 +367）· Python · [链接](https://github.com/TauricResearch/TradingAgents)

**是什么**：一个多智能体的大模型金融交易框架，让多个各司其职的 LLM 智能体像一家交易公司那样协作，共同评估行情并给出交易决策。

**What it is**: A multi-agent LLM financial-trading framework in which specialized language-model agents collaborate like a trading firm to evaluate markets and inform trading decisions.

**为什么值得关注**：它把「分析师—研究员—交易员—风控」的真实分工映射成一组会互相辩论的智能体，是多智能体协作在垂直领域里少见的、成体系的落地样本。已积累 10 万+ star、今日再度进榜，说明「用 Agent 团队替代单体 prompt」的范式在金融这种高价值场景持续被验证。

**Why it matters**: It maps the real division of labor—analyst, researcher, trader, risk manager—onto a set of agents that debate one another, one of the rare, systematic instances of multi-agent collaboration in a vertical domain. With 100k+ stars and a fresh spot on the board today, it shows the "replace a single prompt with a team of agents" paradigm keeps proving out in high-value settings like finance.

## 2. obra/superpowers

⭐ 284.1k（今日 +688）· Shell · [链接](https://github.com/obra/superpowers)

**是什么**：一个可组合的「智能体技能」框架与软件开发方法论——在一组可复用技能之上，给编码智能体配上完整的开发流程（测试驱动、调试、协作、元技能等）。

**What it is**: An agentic skills framework and software-development methodology—a complete workflow for coding agents (TDD, debugging, collaboration, meta-skills) built on top of a set of composable, reusable skills.

**为什么值得关注**：当「技能（skill）」本身成为一种软件形态，如何组织、复用、串联这些技能就成了新战场。superpowers 提供的是「方法论 + 技能库」的一整套地基，被大量后来者引用与二次开发，是理解当下 Agent 生态为何围着 skills 转的必读样本。

**Why it matters**: Now that a "skill" is itself a form of software, how to organize, reuse, and chain those skills has become the new battleground. superpowers offers a full foundation—methodology plus skills library—that many later projects reference and build on, making it essential for understanding why today's agent ecosystem revolves around skills.

## 3. Tencent/teamai-cli

⭐ 3.1k（今日 +556）· TypeScript · [链接](https://github.com/Tencent/teamai-cli)

**是什么**：腾讯开源的「让每个团队 AI 原生」的 CLI——跨 Claude Code、Codex、CodeBuddy、OpenCode、Cursor 等多家智能体，统一管理团队的技能、规则、MCP 与知识库。

**What it is**: Tencent's open-source "make every team AI-native" CLI—managing a team's skills, rules, MCP, and knowledge base uniformly across Claude Code, Codex, CodeBuddy, OpenCode, Cursor, and other agents.

**为什么值得关注**：个人玩 Agent 靠零散配置，团队用 Agent 则需要「规则与知识的统一治理」。teamai-cli 把技能/规则/MCP 抽象成可共享、可版本化的团队资产，正面回应了「多人多工具」协作的痛点。大厂官方下场、今日 +556，值得关注这条「Agent 团队工程化」路线。

**Why it matters**: Individuals get by with scattered config, but teams using agents need unified governance of rules and knowledge. teamai-cli abstracts skills/rules/MCP into shareable, versionable team assets, squarely addressing the pain of "many people, many tools." An official big-tech entry, up 556 today—worth watching as agent teamwork gets engineered.

## 4. cactus-compute/needle

⭐ 10.7k · Python · [链接](https://github.com/cactus-compute/needle)

**是什么**：一个 14MB 的「基础模型」，专为手机、可穿戴、智能家居、机器人等微型设备设计，单个 14MB 二进制、约 28MB 内存即可运行，擅长工具调用与结构化数据抽取。

**What it is**: A 14MB "foundation model" built for tiny devices—phones, wearables, smart home, robots—shipping as a single 14MB binary that runs in roughly 28MB of RAM, tuned for tool calling and structured data extraction.

**为什么值得关注**：当业界忙着把模型做大，needle 反向把「够用的智能」压进 KB 级内存，让端侧、离线、隐私敏感的场景第一次有了现实可行的本地模型。对 IoT、机器人、边缘设备而言，这种「极小但会用工具」的模型可能比云端大模型更贴合需求。

**Why it matters**: While the industry races to scale up, needle goes the other way—squeezing "good-enough" intelligence into kilobytes of RAM, making on-device, offline, privacy-sensitive scenarios feasible with a genuinely local model. For IoT, robotics, and edge hardware, a "tiny but tool-using" model may fit the need better than a cloud-scale one.

## 5. xai-org/x-algorithm

⭐ 33k · Rust · [链接](https://github.com/xai-org/x-algorithm)

**是什么**：为 X（原 Twitter）「For You」信息流提供动力的推荐算法——决定哪些帖子出现在你的首页，融合关注内的内容与机器学习召回、排序而来的关注外内容。

**What it is**: The recommendation algorithm powering X's (formerly Twitter's) "For You" feed—deciding which posts land on your home timeline by combining in-network content with out-of-network content surfaced via ML retrieval and ranking.

**为什么值得关注**：全球最大社交平台之一把推荐核心开源，本身就是罕见的透明度事件；对研究推荐系统、排序、内容分发的人是一手教材。用 Rust 重写、配合 Python 的 ML 组件，也反映了工业级推荐系统在性能与工程化上的取向。

**Why it matters**: One of the world's largest social platforms open-sourcing its ranking core is a rare transparency event in itself, and first-hand teaching material for anyone studying recommender systems, ranking, and content distribution. The Rust rewrite alongside Python ML components also reflects where industrial-scale recommenders are heading on performance and engineering.

**Why it matters**: Complementary to pascalorg/editor, this takes the "skills layer" route—rather than building an editor, it packages the formats and operations of engineering software into skills an agent can call. Manufacturing's digitization has long lacked automation hooks; turning CAD/CAE/CAM into LLM-orchestratable skills is an imaginative direction.

**Anthropic Claude Code team member Boris Cherny (bcherny on X)** on the state of prompt injection: well-aligned models alone aren't enough to solve it yet, but layering the latest models with "prompt-injection probes (on by default for all traffic)" and "auto mode (on by default)" has let them contain it in practice.
