## 3. alibaba/page-agent

**Why it matters**: Most web automation either relies on bolt-on extensions or runs a headless browser server-side — heavy and hard to ship. page-agent inverts this: the agent lives inside the page, embeddable via a single script tag, collapsing the cost of "add an AI assistant to any site."

## 6. TencentCloud/CubeSandbox

⭐ 9.6k（本周 +2,514）· Rust · [链接](https://github.com/TencentCloud/CubeSandbox)

**是什么**：为 AI Agent 打造的即时、并发、安全的轻量沙箱服务，基于 RustVMM 与 KVM，硬件隔离、启动低于 60ms、内存开销极小，并兼容 E2B SDK 便于迁移。

**What it is**: An instant, concurrent, secure and lightweight sandbox service for AI agents, built on RustVMM and KVM — hardware-isolated code execution with sub-60ms boot and minimal memory overhead, plus E2B SDK compatibility for easy migration.

**为什么值得关注**：让 Agent 执行任意代码是能力也是风险，安全沙箱是绕不开的基建。CubeSandbox 用微虚机把「安全」和「够快够省」同时做到，还兼容既有 E2B 生态，是腾讯云开源里对 Agent 落地相当务实的一块拼图。

**Why it matters**: Letting agents run arbitrary code is both a capability and a risk, and a secure sandbox is unavoidable infrastructure. CubeSandbox uses micro-VMs to make "secure" coexist with "fast and cheap," while staying compatible with the existing E2B ecosystem — a pragmatic piece of Tencent Cloud's open-source push toward real agent deployment.

### 🎧 播客 / Podcast

**Unsupervised Learning · Ep 90：AI 先驱 Jürgen Schmidhuber 谈今天的 AI 现状**

**一句话要点**：这位被《纽约时报》《福布斯》称为「现代 AI 之父」的先驱认为，当前的 CapEx（资本开支）狂潮被严重高估，而递归自我改进不会成为任何实验室的护城河。

- **真正的 AI 不能只「在屏幕后面」**：他说从「宇宙尺度」看，我们离超越自己的 AI 与 1970 年代一样近——语言模型已经能通过图灵测试，但真正的 AGI 还需要能与人类身体媲美的机器人与硬件，而这部分远未做好。「你不可能只在屏幕后面就拥有 AGI。」

- **对技术乐观，对模型公司悲观**：他认为 AI 技术前景极好，但对模型公司深表悲观，判断这轮资本开支「严重过度」，甚至可能引发一次股市崩盘。

- **递归自我改进不是护城河**：如今主流做法是让预训练模型改进自己写代码的方式，这「合理但并非最通用」——因为依赖人类数据的系统「极度偏向人类」。他也不认为自我改进会给某家公司带来持久优势。

- **智能即「懒惰」**：一句最凝练的观点——"whenever you are talking about intelligence, you basically are talking about laziness."（谈论智能，本质上就是在谈论懒惰。）智能体追求以最小的努力与能耗完成目标，因此自我改进系统会自带「效率奖励」，用越来越少的资源做越来越多的事。

**The Takeaway**: The pioneer the New York Times and Forbes have called "the father of modern AI" thinks today's CapEx boom is wildly overdone — and that recursive self-improvement won't be a durable moat for any lab.

- **True AI can't live "behind the screen" alone**: From a "cosmic perspective," he says we're as close to superhuman AI as we were in the 1970s — LLMs already pass the Turing test, but real AGI needs robots and hardware rivaling the human body, and that part is far from ready. "You can't have AGI just behind the screen."

- **Optimistic on the tech, pessimistic on the companies**: He's very bullish on AI technology but deeply pessimistic on the model companies, calling this CapEx cycle "massively overdone" — possibly heading toward a market crash.

- **Recursive self-improvement isn't a moat**: The now-standard approach — letting a pretrained model improve how it codes its own code — is "reasonable but not the most general," since systems trained on human data are "super biased towards humans." He doesn't think self-improvement grants any one company a lasting edge.

- **Intelligence is "laziness"**: His sharpest line — "whenever you are talking about intelligence, you basically are talking about laziness." Intelligent beings aim to achieve goals with the least possible effort and energy, so self-improving systems carry a built-in efficiency reward, doing more and more with fewer and fewer resources.
