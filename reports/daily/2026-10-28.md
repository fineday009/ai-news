**What it is**: One 8 KB skill that replaces REA (Reverse Engineer Anything): plain CLI tools, no MCP server, no 207 tools, no setup.

**为什么值得关注**：10 月 17 日创建。REA 是今年星数最高的新仓库，leanrea 的论点是 Agent 本来就会用 otool、nm、jadx、Ghidra 这些工具，MCP 那一层反而是负担。作者的基准（Claude Code 无头模式、4 个逆向任务 × 3 轮）显示：相比 REA，墙钟时间少 38%、成本低 35%、token 少 60%，准确率相当（74/75 对 75/75）；作者也坦言样本少、只测了一个模型。对"skill 还是 MCP"之争，这是少见的带数据的一方。

**Why it matters**: Created Oct 17. REA is this year's most-starred new repo; leanrea's argument is that agents already know how to use otool, nm, jadx and Ghidra, so the MCP layer is overhead. The author's benchmark (headless Claude Code, 4 reverse-engineering tasks × 3 reps) shows 38% less wall time, 35% lower cost and 60% fewer tokens than REA at about the same accuracy (74/75 vs 75/75), with the caveats that it's few reps on one model. In the "skill vs. MCP" debate, it's a rare side that brings numbers.

## 4. amosblomqvist/learnharness

⭐ 3.2k · TypeScript · [链接](https://github.com/amosblomqvist/learnharness)

**是什么**：用来学习难懂知识的 Agent 外壳：Agent 先测出你的理解边界，再规划并讲授从现有理解到目标的课程。

**What it is**: Agent harness for learning difficult things. AI agents plan and teach lessons from your current understanding to your goal, building a detailed picture of what you understand and how you reason.

**为什么值得关注**：流程是"测量 → 规划 → 讲授 → 练习"：先找出你在每个前置知识点上懂到哪，再画出到目标的依赖图，一步一推理地讲，并用不点名知识点的变式题做练习。学到的内容会沉淀为一张持久的命题与推理链图谱，跨会话复用。桌面应用，自带 API key 支持 30 多种模型服务商，数据存本地，AGPL-3.0 开源。

**Why it matters**: The loop is measure → plan → teach → practice: it finds where your understanding ends on each prerequisite, maps the dependencies to your goal, teaches one reasoning step at a time, and then practices with varied problems that don't name the concept up front. What you learn accumulates in a persistent graph of propositions and reasoning chains that later sessions reuse. It's a desktop app, bring-your-own-key across 30+ providers, with local storage, open source under AGPL-3.0.

## 6. unclebob/ub-mode

⭐ 2.5k · [链接](https://github.com/unclebob/ub-mode)

**是什么**：《代码整洁之道》作者 Uncle Bob 的 Agent skill，在 Agent 写代码和改代码时强制执行工程纪律，并配套确定性的质量门禁工具。

**What it is**: An agent skill that enforces disciplined software engineering principles when writing or changing code, paired with deterministic quality-gate tools.

**为什么值得关注**：10 月 25 日创建。它不只是一份"写好代码"的提示词：规则分为"先让它跑起来 → 再让它正确 → 日常实践"三段（TDD、修根因、测行为而非实现、小步提交等），并用作者自己的 crapper（CRAP 分数 < 10）、dryer（重复度 < 0.8）、mutator（变异测试）做硬性检查。用可量化的门禁约束 Agent，比单纯写规则可靠得多。

**Why it matters**: Created Oct 25. It's more than a "write good code" prompt: the rules run in three stages—first make it work, then make it right, then practice (TDD, fix root causes, test behavior not implementation, small ordered commits)—and are backed by the author's own crapper (CRAP score < 10), dryer (duplication < 0.8) and mutator (mutation testing) as hard checks. Constraining agents with measurable gates is far more reliable than rules alone.

The author is explicit that it's an iterative, editable reconstruction workflow, not a one-click scan-to-model converter.

## 9. xevrion/hatchzip

⭐ 2.2k · Rust · [链接](https://github.com/xevrion/hatchzip)

**是什么**：免费开源的跨平台解压工具（Windows、macOS、Linux，带桌面版和命令行），支持 ZIP、7z、RAR、tar 和分卷压缩包，可"原地解压"。

**What it is**: HatchZip is a free, open-source archive extractor for Windows, macOS and Linux that extracts ZIP, 7z, RAR, tar and split archives in place—the archive shrinks as your files hatch.

**为什么值得关注**：一个 180 GB、解压后 200 GB 的游戏包，用 WinRAR、7-Zip 或 unzip 需要 380 GB 空间，因为压缩包和解压结果必须同时存在；HatchZip 从压缩包尾部开始解、边解边释放空间，只需略多于 200 GB。它会先检查空间够不够，全程保留安全余量，中断或崩溃后可续解。一个小而真实的痛点，被认真解决了。

**Why it matters**: A 180 GB game download that unpacks to 200 GB needs 380 GB of disk with WinRAR, 7-Zip or unzip, because the archive and its output must coexist; HatchZip extracts from the end of the archive and frees space as it goes, needing only a little over 200 GB. It checks that the extraction will fit before touching anything, keeps a safety margin throughout, and resumes after an interruption or crash. A small, real pain point, solved carefully.
