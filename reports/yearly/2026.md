## 1. openclaw/openclaw

⭐ 389k · TypeScript · 2025-11-24 创建 · [链接](https://github.com/openclaw/openclaw)

**是什么**：跑在你自己电脑上的开源 AI 助手，主动到你已经在用的渠道里找你——Discord、iMessage、Slack、Teams、Telegram、WhatsApp 等 20 多个平台；数据、凭证、模型选择（Claude、Codex、本地模型）全由你掌控，由独立的非营利组织 OpenClaw Foundation（501(c)(3)）托管。

**What it is**: An open-source AI assistant that runs on your own computer and meets you in the channels you already use—Discord, iMessage, Slack, Teams, Telegram, WhatsApp, and 20+ more. You keep full control of your data, credentials, and model choice (Claude, Codex, or local models), with the project stewarded by the independent nonprofit OpenClaw Foundation, a 501(c)(3).

**为什么值得关注**：全年 star 最高的项目，389k 的体量本身就是现象。它把「隐私优先的个人 AI 助手」做成基金会治理的严肃开源项目，而非某家公司的封闭产品，代表了「AI 助手去中心化、归用户所有」这条与大厂云助手截然不同的路线。

**Why it matters**: The year's most-starred project—389k stars is a phenomenon in itself. It builds a privacy-first personal AI assistant as a foundation-governed, serious open-source project rather than a company's closed product, embodying a "decentralized, user-owned assistant" path sharply different from big-cloud assistants.

## 3. Graphify-Labs/graphify

⭐ 116k · Python · 2026-04-03 创建 · [链接](https://github.com/Graphify-Labs/graphify)

**是什么**：把任意代码库——连同它的文档、SQL schema、配置、PDF——变成一张可查询的知识图谱，并以 `/graphify` 技能的形式供编码 Agent 调用。

**What it is**: Turn any codebase—along with its docs, SQL schemas, configs, and PDFs—into a queryable knowledge graph, exposed as a `/graphify` skill for coding agents.

**为什么值得关注**：Agent 想理解一个大项目，最缺的就是「结构化的全局上下文」。它把散落的代码与资料统一成图谱，让检索从「关键词」升级到「关系」，直击 RAG 与 Agent 代码理解的核心瓶颈。

**Why it matters**: What agents most lack when facing a large project is structured, global context. By unifying scattered code and assets into a graph, it upgrades retrieval from keywords to relationships—hitting the core bottleneck of RAG and agent code comprehension.

## 8. rtk-ai/rtk

⭐ 79k · Rust · 2026-01-22 创建 · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理，在常见开发命令上把 LLM 的 Token 消耗降低 60–90%；单个 Rust 二进制、零依赖。

**What it is**: A CLI proxy that reduces LLM token consumption by 60–90% on common dev commands—a single Rust binary with zero dependencies.

**为什么值得关注**：Agent 越用越贵，Token 就是钱。它不改模型、不改工作流，只在命令输出这一层做压缩，就能砍掉大半开销，是「省钱基建」里最务实、最容易落地的一类，单二进制零依赖也极易采用。

**Why it matters**: The more you use agents, the more expensive it gets—tokens are money. Without touching the model or workflow, it compresses at the command-output layer and cuts most of the cost—among the most pragmatic, deployable of the "cost-saving infra" projects, and trivial to adopt as a single zero-dependency binary.

## 10. headroomlabs-ai/headroom

**为什么值得关注**：与 rtk 遥相呼应，指向同一个全年热点：上下文与 Token 是新的稀缺资源。它专注「喂给模型之前的压缩」，直接改善成本与有效上下文长度，是 Agent 工程化落地时会被反复用到的中间件。

**Why it matters**: Echoing rtk, it points at the same year-long hot spot: context and tokens are the new scarce resource. By focusing on pre-model compression, it directly improves both cost and effective context length—middleware that gets reused again and again as agents move into production.
