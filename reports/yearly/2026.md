## 4. Graphify-Labs/graphify

⭐ 103,567 · Python · 创建于 2026-04-03 / Created 2026-04-03 · [链接](https://github.com/Graphify-Labs/graphify)

**是什么**：把任意代码库连同文档、SQL 结构、配置和 PDF，转成可查询的知识图谱；本地确定性 AST 解析，每条边都可解释，无需向量库。支持 Claude Code、Cursor、Codex、Gemini CLI 等。

**What it is**: Turns any codebase—plus docs, SQL schemas, configs, and PDFs—into a queryable knowledge graph. Local deterministic AST parsing, every edge explained, no vector store. Works with Claude Code, Cursor, Codex, Gemini CLI, and more.

**为什么值得关注**：「怎样让代理真正理解一个大代码库」是今年的核心难题之一。graphify 用可解释的知识图谱替代黑箱向量检索，是代码理解方向最受欢迎的方案之一。

**Why it matters**: "How to make agents truly understand a large codebase" is a central challenge this year. graphify replaces black-box vector retrieval with an explainable knowledge graph—one of the most popular approaches to code comprehension.
