## 1. openclaw/openclaw

⭐ 381,972 · 创建于 2025-11-24 · TypeScript · [链接](https://github.com/openclaw/openclaw)

**是什么**：你自己的个人 AI 助理，任意操作系统、任意平台皆可运行。🦞

**What it is**: Your own personal AI assistant. Any OS. Any Platform. The lobster way. 🦞

**为什么值得关注**：过去一年最耀眼的现象级项目，星标已突破 38 万。它把 20 多个消息平台（WhatsApp、Telegram、Slack、iMessage、微信……）、语音唤醒、可视化画布和技能注册表整合进一个可完全自托管的助理，还获 OpenAI、GitHub、NVIDIA、Vercel 赞助。它把「人人拥有一个属于自己的 AI 助理」从口号变成了可安装的现实。

**Why it matters**: The year's most dazzling phenomenon, now past 380K stars. It integrates 20+ messaging platforms (WhatsApp, Telegram, Slack, iMessage, WeChat…), voice wake-word, a Live Canvas, and a skills registry into a fully self-hostable assistant — backed by sponsors including OpenAI, GitHub, NVIDIA, and Vercel. It turned "everyone has their own AI assistant" from a slogan into an installable reality.

## 2. NousResearch/hermes-agent

⭐ 210,436 · 创建于 2025-07-22 · Python · [链接](https://github.com/NousResearch/hermes-agent)

**是什么**：一个会随你成长的 Agent。

**What it is**: The agent that grows with you.

**为什么值得关注**：出自开放模型阵营的中坚 NousResearch，Hermes Agent 主打持续记忆与个性化——随使用不断适应用户，而非每次从零开始。它代表了「有状态、长期陪伴型 Agent」这一方向，并催生了 Hermes Studio 等庞大的周边生态。

**Why it matters**: From open-model stalwart NousResearch, Hermes Agent centers on persistent memory and personalization — adapting to the user over time rather than starting fresh each session. It exemplifies the "stateful, long-term companion agent" direction and has spawned a large surrounding ecosystem such as Hermes Studio.

## 4. farion1231/cc-switch

⭐ 114,006 · 创建于 2025-08-04 · Rust · [链接](https://github.com/farion1231/cc-switch)

**是什么**：一个跨平台桌面的「多合一」助手，用于在 Claude Code、Codex、OpenCode、OpenClaw、Gemini CLI 等之间切换。

**Why it matters**: With coding agents and CLIs proliferating, developers often run several at once. cc-switch unifies config management and switching in one lightweight Rust desktop tool, solving the real friction of "many agents coexisting" — a direct product of, and beneficiary of, this year's agent-tool explosion.

## 5. thedotmack/claude-mem

⭐ 86,181 · 创建于 2025-08-31 · JavaScript · [链接](https://github.com/thedotmack/claude-mem)

**是什么**：为每个 Agent 提供跨会话的持久上下文——捕捉 Agent 在会话中所做的一切，供后续复用。

**What it is**: Persistent Context Across Sessions for Every Agent — captures everything your agent does during sessions.

**为什么值得关注**：上下文丢失是 Agent 体验的头号痛点：换个会话就「失忆」。claude-mem 把长期记忆做成即插即用的一层，让 Agent 记住你的项目、偏好与历史决策。记忆/上下文工程是全年的核心议题，它是其中普及度最高的实现之一。

**Why it matters**: Context loss is the top pain point of the agent experience — switch sessions and it "forgets." claude-mem adds long-term memory as a plug-and-play layer so agents remember your project, preferences, and past decisions. Memory/context engineering was a central theme all year, and this is one of its most widely adopted implementations.

## 10. rtk-ai/rtk

⭐ 69,008 · 创建于 2026-01-22 · Rust · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理，在常见开发命令上把 LLM 的 token 消耗降低 60–90%，单个 Rust 二进制、零依赖。

**What it is**: CLI proxy that reduces LLM token consumption by 60–90% on common dev commands. Single Rust binary, zero dependencies.

**为什么值得关注**：当开发全流程都接上 LLM，token 成本成了实打实的账单。rtk 以透明代理的方式压缩上下文与输出，在不改工作流的前提下省下大头开销，是「省 token」这一整年新兴品类里最硬核、最受欢迎的一员。

**Why it matters**: Once your whole dev flow runs through LLMs, token cost becomes a real bill. rtk acts as a transparent proxy that compresses context and output, cutting the bulk of the expense without changing your workflow — the hardest-core and most popular member of the "token-saving" category that emerged this year.
