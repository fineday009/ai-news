## 1. openclaw/openclaw

⭐ 384k · 近一年新建 · TypeScript · [链接](https://github.com/openclaw/openclaw)

**是什么**：属于你自己的个人 AI 助手，跨任意操作系统、任意平台运行——"the lobster way 🦞"，由非营利的 OpenClaw 基金会维护。

**What it is**: Your own personal AI assistant, running on any OS and any platform — "the lobster way 🦞" — maintained by the non-profit OpenClaw Foundation.

**为什么值得关注**：38 万星让它成为过去一年最现象级的新项目。它把"个人化、可自托管、不被单一平台绑架的 AI 助手"这一愿景做成了社区共识级产品，代表了 AI 助手从云端封闭走向开源自主的浪潮。

**Why it matters**: 384k stars make it the most phenomenal new project of the year. It turned the vision of a personal, self-hostable AI assistant free of platform lock-in into a community-consensus product — emblematic of assistants shifting from closed cloud to open and self-owned.

## 2. obra/superpowers

⭐ 260k · 2025 年 10 月首发 · Shell · [链接](https://github.com/obra/superpowers)

**是什么**：一个"能真正用起来"的 agentic 技能框架与软件开发方法论，把一套可复用的能力与工作流固化下来供 Agent 使用。

**What it is**: An agentic skills framework and software-development methodology "that works," codifying reusable capabilities and workflows for agents.

**为什么值得关注**：当"skill"成为 2026 年的关键词，superpowers 是其中最有分量、最成体系的一个——它不只是清单，而是一整套方法论，已迭代到 v6.x。它定义了"如何把人的开发方法教给 Agent"这一范式。

**Why it matters**: As "skills" became a 2026 keyword, superpowers is the weightiest and most systematic — not a list but a full methodology, already at v6.x. It helped define the paradigm of "teaching agents a human development method."

## 3. github/spec-kit

⭐ 123k · 近一年新建 · Python · [链接](https://github.com/github/spec-kit)

**是什么**：GitHub 官方推出的规格驱动开发（Spec-Driven Development）工具包，帮助团队从"写规格"开始组织软件开发。

**What it is**: GitHub's official toolkit for Spec-Driven Development, helping teams organize software work starting from written specs.

**为什么值得关注**：在 Agent 大量生成代码的时代，"清晰的规格"成了质量与协作的关键抓手。spec-kit 由 GitHub 亲自下场，把"先写规格、再让 Agent 实现"的流程标准化，是把 AI 编码从随性 vibe coding 拉回工程纪律的代表作。

**Why it matters**: In an era of agent-generated code, clear specs became the key lever for quality and collaboration. Backed by GitHub itself, spec-kit standardizes "write the spec, then let agents implement" — a flagship for pulling AI coding back from freewheeling vibe coding toward engineering discipline.

## 4. OpenCut-app/OpenCut

⭐ 77.7k · 近一年新建 · TypeScript · [链接](https://github.com/OpenCut-app/OpenCut)

**是什么**：开源的 CapCut（剪映）替代品，一个功能完整、可自托管的视频编辑器。

**What it is**: The open-source, self-hostable CapCut alternative — a full-featured video editor.

**为什么值得关注**：过去一年最成功的非 AI 新项目之一。面对强大却封闭、隐私存疑的 CapCut，OpenCut 给全球创作者一个不受平台绑架的开源选择，证明"重做一个开放版的国民级应用"仍是极具号召力的开源命题。

**Why it matters**: One of the year's most successful non-AI newcomers. Against a powerful but closed, privacy-questionable CapCut, OpenCut gives creators worldwide an open, un-lock-in alternative — proof that "rebuild a beloved app, but open" remains a magnetic open-source proposition.

## 5. earendil-works/pi

⭐ 75.6k · 近一年新建 · TypeScript · [链接](https://github.com/earendil-works/pi)

**What it is**: An AI agent toolkit bundling a unified LLM API, an agent loop, a TUI and a coding-agent CLI.

**为什么值得关注**：pi 提供了从 API 到 CLI 的整条竖切，让开发者在一个心智模型里既调模型又跑 Agent，并已长出 pi-web 等生态。它是过去一年"Agent 工具箱整合"这条主线上的标志性项目。

**Why it matters**: pi offers a full vertical slice from API to CLI so developers can call models and run agents in one mental model, and it has grown an ecosystem (pi-web and more). It's a landmark on the year's "consolidated agent toolkit" throughline.

## 9. calesthio/OpenMontage

⭐ 41.3k · 近一年新建 · Python · [链接](https://github.com/calesthio/OpenMontage)

**是什么**：号称全球首个开源的智能体式视频生产系统，内置 12 条生产流水线，从素材到成片自动化协作完成。

**为什么值得关注**：它把"整条视频生产链"交给协作的 Agent，代表创意生产从"工具辅助"迈向"Agent 编排全流程"。作为今年下半年冒头的黑马，它展示了 agentic 工作流从写代码扩展到多媒体创作的可能。

**Why it matters**: It hands the entire video-production chain to collaborating agents — creative work moving from tool-assist to agent-orchestrated pipelines. A late-year breakout, it shows agentic workflows expanding from code into multimedia creation.

## 10. diegosouzapw/OmniRoute

⭐ 25.5k · 近一年新建 · TypeScript · [链接](https://github.com/diegosouzapw/OmniRoute)

**是什么**：MIT 协议的免费 AI 网关，单端点接入 268+ 供应商、500+ 模型，配额感知自动降级，兼容主流编码 Agent。

**What it is**: A free, MIT-licensed AI gateway — one endpoint over 268+ providers and 500+ models, with quota-aware auto-fallback and support for mainstream coding agents.

**为什么值得关注**：过去一年模型路由/网关成为刚需基础设施，OmniRoute 以"免费 + 极广覆盖 + 自动降级 + token 压缩"脱颖而出。它回答了这一年最现实的工程问题：如何不被单一模型厂商锁死、同时把账单管住。

**Why it matters**: Model routing/gateways became must-have infrastructure this year, and OmniRoute stands out on "free + huge coverage + auto-fallback + token compression." It answers the year's most practical engineering question: how to avoid single-vendor lock-in while keeping the bill under control.
