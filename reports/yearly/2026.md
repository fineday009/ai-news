## 5. github/spec-kit

⭐ 114,396 · Python · 创建于 2025-08-21 · [链接](https://github.com/github/spec-kit)

**是什么**：GitHub 官方推出的工具包，帮助你上手"规格驱动开发"（Spec-Driven Development）。

**What it is**: An official GitHub toolkit to help you get started with Spec-Driven Development.

**为什么值得关注**：当代码越来越多由 agent 生成，"先写清楚规格、再让 agent 实现"成为保证质量的关键方法论。GitHub 官方下场把它工具化，推动整个行业从"凭感觉提示"转向"规格驱动"，是这一年开发流程层面影响最深的项目之一，也代表了 AI 之外扎实的开发者工具方向。

**Why it matters**: As more code is generated by agents, "write the spec clearly first, then let the agent implement" becomes the key methodology for quality. GitHub officially tooling this pushes the industry from vibe-prompting toward spec-driven development — one of the year's most influential projects at the process layer, and a solid developer-tooling direction beyond pure AI.

## 8. thedotmack/claude-mem

⭐ 83,422 · JavaScript · 创建于 2025-08-31 · [链接](https://github.com/thedotmack/claude-mem)

**是什么**：为每一个 agent 提供跨会话的持久上下文——记录会话中发生的一切，再用 AI 压缩存档。

**What it is**: Persistent context across sessions for every agent — captures everything an agent does during sessions and compresses it with AI.

**为什么值得关注**：会话结束、上下文清零，是过去一年 agent 体验最大的痛点之一。claude-mem 把"长期记忆"做成可插拔的层，让 agent 在跨会话、跨项目时仍记得历史决策与偏好。8 万星说明"记忆"已和"技能""上下文压缩"并列为 agent 三大基础能力之一。

**Why it matters**: Sessions ending and context resetting was one of the biggest agent pain points of the past year. claude-mem makes long-term memory a pluggable layer so agents remember past decisions and preferences across sessions and projects. With 83k stars, memory has joined skills and context-compression as one of the agent's three core capabilities.
