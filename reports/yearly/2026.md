## 1. openclaw/openclaw

⭐ 391.8k · 2025-11-24 创建 · TypeScript · [链接](https://github.com/openclaw/openclaw)

**是什么**：跑在你自己硬件上的开源 AI 助理，可接 Discord、Slack、Telegram、WhatsApp、iMessage 等消息平台及各大系统的原生应用；状态、记忆、凭据全部留本地，模型与 Agent harness 都是可换插件。

**What it is**: An open-source AI assistant that runs on your own hardware and connects to messaging platforms (Discord, Slack, Telegram, WhatsApp, iMessage) and native OS apps; state, memory and credentials stay local, and models and agent harnesses are swappable plugins.

**为什么值得关注**：它是今年星数最高的项目（约 39 万星），由独立 501(c)(3) 基金会托管、无付费层与代币、默认只做每日版本检查。它把"数据主权 + 可插拔 + 不被厂商绑定"做成了旗帜，是本年度开源 AI 助理路线的象征性胜利。

**Why it matters**: The year's top-starred project (~392k), stewarded by an independent 501(c)(3) foundation with no paid tier or token and only a daily version check by default. It raised the banner of "data sovereignty + pluggable + no vendor lock-in" — a symbolic win for the open-source AI-assistant path this year.

## 4. Graphify-Labs/graphify

⭐ 125.9k · 2026-04-03 创建 · Python · [链接](https://github.com/Graphify-Labs/graphify)

**是什么**：把任意代码库（连同文档、SQL schema、配置、PDF）转成可查询的知识图谱的 `/graphify` 技能，面向 Claude Code、Cursor、Codex、Gemini CLI；全程本地、确定性 AST 解析，每条边都有解释，不依赖向量库。

**What it is**: A `/graphify` skill that turns any codebase — plus docs, SQL schemas, configs and PDFs — into a queryable knowledge graph for Claude Code, Cursor, Codex and Gemini CLI; fully local, deterministic AST parsing, every edge explained, no vector store.

**为什么值得关注**：它代表了今年"代码理解/知识图谱"的热潮，并坚持确定性解析而非向量检索，强调可解释与本地化。对大型代码库的导航、问答与 Agent 上下文供给是极其实用的底座。

**Why it matters**: It represents the year's surge in code understanding / knowledge graphs, insisting on deterministic parsing over vector retrieval and emphasizing explainability and local operation. A highly practical foundation for navigating, querying and feeding agent context over large codebases.
