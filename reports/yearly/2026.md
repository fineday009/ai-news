## 1. openclaw/openclaw

⭐ 392.1k（创建于 2025-11-24）· TypeScript · [链接](https://github.com/openclaw/openclaw)

**是什么**：开源、MIT 协议、运行在你自己电脑上的 AI 助手，通过 WhatsApp、Telegram、Slack、Discord 等聊天应用与你对话；由非营利基金会治理。

**What it is**: An open-source, MIT-licensed AI assistant that runs on your own computer and talks to you through chat apps like WhatsApp, Telegram, Slack, and Discord — governed by a nonprofit foundation.

**为什么值得关注**：过去一年星数登顶的项目。它把「个人/团队 AI 助手」彻底本地优先化——数据、凭证、模型选择都掌握在自己手里，没有付费层也没有托管服务。在隐私与自主可控成为主流诉求的今天，它是这股潮流最有号召力的代表。

**Why it matters**: The year's top project by stars. It makes the "personal/team AI assistant" radically local-first — data, credentials, and model choice all stay in your hands, with no paid tier and no hosted service. As privacy and self-sovereignty become mainstream demands, it's the most compelling banner for that movement.

## 2. morluto/rea

⭐ 273.5k（创建于 2026-04-14）· TypeScript · [链接](https://github.com/morluto/rea)

**是什么**：用 Agent 逆向工程任何东西——从 App 行为一路下探到原生二进制。

**What it is**: Reverse engineer anything with agents, from app behavior down to native binaries.

**为什么值得关注**：它证明了 Agent 能啃下逆向工程这种极硬核、极依赖专家经验的任务，接入 Ghidra/Hopper 等成熟工具链，把「一支逆向专家团队」压缩成一套可编排的 Agent 流程，是年度最具冲击力的能力跃迁之一。

**Why it matters**: It proved agents can tackle reverse engineering — a hardcore, expertise-heavy task — by wiring in mature toolchains like Ghidra and Hopper, compressing "a team of RE experts" into an orchestratable agent pipeline. One of the year's most striking capability leaps.

## 4. Graphify-Labs/graphify

⭐ 126.9k（创建于 2026-04-03）· Python · [链接](https://github.com/Graphify-Labs/graphify)

**是什么**：把任意代码库——连同它的文档、SQL 结构、配置和 PDF——变成可查询的知识图谱；一个面向 Claude Code、Cursor、Codex、Gemini CLI 的 /graphify 技能，用本地确定性 AST 解析、每条边都可解释、无需向量库。

**What it is**: Turn any codebase — along with its docs, SQL schemas, configs, and PDFs — into a queryable knowledge graph. A /graphify skill for Claude Code, Cursor, Codex, and Gemini CLI: local deterministic AST parsing, every edge explained, no vector store.

**为什么值得关注**：当 Agent 要理解大型代码库，向量检索常常「似是而非」。graphify 反其道用确定性 AST 建图、可解释每条关系，给出一条比纯 RAG 更可靠的代码理解路径，年度星数名列前茅。

**Why it matters**: When agents need to understand large codebases, vector retrieval often returns plausible-but-wrong results. graphify goes the other way — deterministic AST-based graphs with every relationship explainable — offering a more reliable path to code comprehension than pure RAG, and ranks among the year's top by stars.

**Why it matters**: From Andrej Karpathy, it grounds "AI doing AI research" on a minimal, reproducible testbed — agents autonomously designing, running, and iterating training experiments on a single GPU. It's both a teaching template and a pragmatic starting point for the grand theme of automated science.

## 7. stablyai/orca

⭐ 93.6k（创建于 2026-03-17）· TypeScript · [链接](https://github.com/stablyai/orca)

**是什么**：面向「一支并行 Agent 舰队」的 ADE（Agent 开发环境），可用你自己的订阅运行任意编码 Agent，支持桌面、移动和远程运行时。

**What it is**: An ADE (agent development environment) for working with a fleet of parallel agents — run any coding agent with your own subscription, across desktop, mobile, and remote runtimes.

**为什么值得关注**：当单个 Agent 不够用，如何同时驾驭几十个 Agent 成了新难题。orca 把 worktree、并行编排、跨端运行打包成一个「IDE 之上的 Agent 工作台」，代表了从「写代码」到「指挥 Agent 舰队」的工作方式转变。

**Why it matters**: When one agent isn't enough, steering dozens at once becomes the new problem. orca packages worktrees, parallel orchestration, and cross-device runtimes into an "agent workbench above the IDE," embodying the shift from "writing code" to "commanding a fleet of agents."

## 8. 666ghj/MiroFish

⭐ 79.5k（创建于 2025-11-26）· Python · [链接](https://github.com/666ghj/MiroFish)

**是什么**：简洁通用的群体智能引擎，预测万物——把新闻、政策草案、金融信号等种子材料变成一个由各具性格与记忆的 Agent 互动的模拟世界，注入变量来预测可能结局；底层构建知识图谱、在 OASIS 引擎上并行仿真。

**What it is**: A simple, general-purpose swarm-intelligence engine for predicting anything — it turns seed material (news, policy drafts, financial signals) into a simulated world of agents with distinct personalities and memories, injects variables to forecast outcomes, builds a knowledge graph, and runs parallel simulations on the OASIS engine.

**为什么值得关注**：它把「多 Agent 模拟」从学术 demo 推向一个通用预测框架，用社会仿真来回答「如果……会怎样」。这条路线与主流「单模型推理」截然不同，在舆情、金融、政策推演上有独特想象空间。

**Why it matters**: It pushes "multi-agent simulation" from academic demo toward a general-purpose prediction framework, using social simulation to answer "what if." This route diverges sharply from mainstream single-model reasoning and opens unique room in opinion analysis, finance, and policy war-gaming.

## 9. rtk-ai/rtk

⭐ 83.5k（创建于 2026-01-22）· Rust · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理，在常见开发命令上把 LLM 的 token 消耗降低 60–90%；单个 Rust 二进制、零依赖。

**What it is**: A CLI proxy that cuts LLM token consumption by 60–90% on common dev commands — a single Rust binary with zero dependencies.

**为什么值得关注**：Agent 编码最大的隐性成本是海量工具输出被塞进上下文。rtk 作为一层透明代理去噪压缩，直接省下大把 token 与钱。它不是 AI 模型，却是让 AI 可负担的关键基础设施，全年热度不减。

**Why it matters**: The biggest hidden cost of agentic coding is vast tool output stuffed into context. rtk sits as a transparent proxy that denoises and compresses it, saving a lot of tokens and money. It's not an AI model, but it's key infrastructure for making AI affordable — and stayed hot all year.

## 10. pbakaus/impeccable

⭐ 81.7k（创建于 2025-11-16）· Rust · [链接](https://github.com/pbakaus/impeccable)

**是什么**：一套设计工具，给 AI 编码助手提供统一的前端设计规范——含一个带 24 条命令（如 audit、polish、critique）的技能，以及 59 条检测规则，用来标记 AI 生成界面里常见的毛病。

**What it is**: A design toolkit that gives AI coding assistants a shared set of frontend design guidance — a skill with 24 commands (such as audit, polish, critique) and 59 detector rules that flag common flaws in AI-generated interfaces.

**为什么值得关注**：AI 能写出能跑的界面，但往往「一眼 AI 味」。impeccable 把设计品味编码成可执行规则，装进 Claude Code、Cursor 等工具，让生成的 UI 从「能用」走向「有审美」。它代表了全年「给 Agent 补上品味」的一类重要尝试。

**Why it matters**: AI can produce working interfaces, but they often scream "made by AI." impeccable encodes design taste into executable rules, dropping into tools like Claude Code and Cursor to lift generated UI from "functional" to "tasteful." It represents a key strand of the year's effort to "give agents taste."
