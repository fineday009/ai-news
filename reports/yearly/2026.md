## 3. Graphify-Labs/graphify

⭐ 100.3k · Python · [链接](https://github.com/Graphify-Labs/graphify)（创建于 2026-04-03 / created 2026-04-03）

**是什么**：把任意代码库连同其文档、SQL schema、配置和 PDF 转成可查询的知识图谱。面向 Claude Code、Cursor、Codex、Gemini CLI 的 `/graphify` 技能：本地确定性 AST 解析，每条边都有解释，无需向量库。

**What it is**: Turn any codebase — with its docs, SQL schemas, configs, and PDFs — into a queryable knowledge graph. A `/graphify` skill for Claude Code, Cursor, Codex, and Gemini CLI: local deterministic AST parsing, every edge explained, no vector store.

**为什么值得关注**：给 Agent「理解一个大项目」提供了确定性的知识底座——不靠向量检索的模糊召回，而是本地 AST 精确解析出可解释的图谱。这条「确定性、可解释」的路线在幻觉频发的 AI 时代尤为可贵，让它成为今年最受欢迎的代码理解基础设施之一。

**Why it matters**: It gives agents a deterministic knowledge substrate for understanding a large project — not fuzzy vector recall, but a locally AST-parsed, explainable graph. This "deterministic and explainable" route is especially valuable in an era of frequent hallucination, making it one of the year's most popular code-understanding infrastructures.

## 5. thedotmack/claude-mem

⭐ 89.3k · JavaScript · [链接](https://github.com/thedotmack/claude-mem)（创建于 2025-08-31 / created 2025-08-31）

**是什么**：为每一个 Agent 提供跨会话的持久上下文——捕捉 Agent 在会话中所做的一切，用 AI 压缩后，把相关上下文注入未来的会话。兼容 Claude Code、OpenClaw、Codex、Gemini、Copilot、OpenCode 等。

**What it is**: Persistent context across sessions for every agent — captures everything your agent does, compresses it with AI, and injects relevant context back into future sessions. Works with Claude Code, OpenClaw, Codex, Gemini, Copilot, OpenCode, and more.

**为什么值得关注**：「Agent 每次会话都失忆」是这一年最普遍的痛点，claude-mem 是最早也是最成功的通用记忆层之一：跨多种主流 Agent、自动压缩与召回。近 9 万 star 说明「持久记忆」已成 Agent 时代的刚需基础设施，而它是这条赛道的标杆。

**Why it matters**: "Agents forget everything each session" was the year's most universal pain point, and claude-mem is one of the earliest and most successful general-purpose memory layers: cross-agent, with automatic compression and recall. Nearly 90k stars show "persistent memory" is now essential infrastructure for the agent era — and this is the benchmark for the category.
