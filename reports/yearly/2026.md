## 6. thedotmack/claude-mem

⭐ 84.2k · JavaScript · 创建于 2025-08-31 · [链接](https://github.com/thedotmack/claude-mem)

**是什么**：为各类 Agent 提供跨会话的持久上下文——捕获 Agent 在会话中所做的一切，用 AI 压缩，并在未来会话中注入相关上下文。兼容 Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCode 等。

**What it is**: Persistent context across sessions for every agent — captures everything an agent does during a session, compresses it with AI, and injects relevant context into future sessions. Works with Claude Code, OpenClaw, Codex, Gemini, Hermes, Copilot, OpenCode and more.

**为什么值得关注**："会话一结束就失忆"是 Agent 体验的最大痛点之一。claude-mem 把记忆做成跨工具的通用层，捕获、压缩、再注入，让 Agent 跨会话保持连续性。广泛的兼容性使它成为今年记忆基础设施的代表作。

**Why it matters**: "Forgetting everything when the session ends" is one of the biggest pain points in agent UX. claude-mem builds memory as a cross-tool universal layer — capture, compress, re-inject — so agents stay continuous across sessions. Its broad compatibility makes it a flagship of this year's memory infrastructure.

## 10. rtk-ai/rtk

⭐ 65.8k · Rust · 创建于 2026-01-22 · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理，在常见开发命令上把 LLM 的 token 消耗降低 60–90%。单一 Rust 二进制、零依赖。

**为什么值得关注**：Agent 大规模使用后，token 成本成了真金白银的负担。rtk 从命令行这一最高频入口切入，用代理层裁剪冗余上下文，号称省下 60–90% token。它代表了今年另一条重要主线——在"用得起"上做工程优化，让 Agent 规模化落地更经济。

**Why it matters**: Once agents are used at scale, token cost becomes a real expense. rtk targets the command line — the highest-frequency entry point — using a proxy layer to trim redundant context, claiming 60–90% savings. It represents another key 2026 thread: engineering for affordability so agents can scale economically.
