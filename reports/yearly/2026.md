## 8. headroomlabs-ai/headroom

⭐ 59.7k · 创建于 2026-01-07 · Python · [链接](https://github.com/headroomlabs-ai/headroom)

**是什么**：在工具输出、日志、文件和 RAG 片段进入 LLM 之前先压缩它们——编码 Agent 省 20% token，JSON 省 60–95%，答案不变。提供库、代理与 MCP server。

**What it is**: Compress tool outputs, logs, files, and RAG chunks before they reach the LLM. 20% fewer tokens for coding agents, 60-95% fewer for JSON, same answers. Library, proxy, MCP server.

**为什么值得关注**：与 rtk 同属「上下文/成本工程」浪潮，但切入点更靠近数据本身——在进入模型前无损压缩上下文。以库/代理/MCP 三种形态提供，落地灵活，反映了本年度「省 token = 省钱 = 提速」的强共识。

**Why it matters**: In the same "context/cost engineering" wave as rtk, but closer to the data itself — losslessly compressing context before it reaches the model. Shipping as a library, proxy and MCP server makes it flexible to adopt, reflecting the year's strong consensus that "fewer tokens = less cost = more speed."
