## 9. rtk-ai/rtk

⭐ 68.5k · Rust · 创建于 2026-01-22 · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理，在常见开发命令上把 LLM 的 token 消耗降低 60–90%。单一 Rust 二进制、零依赖。

**What it is**: A CLI proxy that reduces LLM token consumption by 60–90% on common dev commands. A single Rust binary with zero dependencies.

**为什么值得关注**：编码 Agent 最直接的成本来自海量命令输出灌进上下文。rtk 通过智能过滤、分组、截断与去重压缩这些输出，实测能把一次编码会话从约 11.8 万 token 降到约 2.4 万。它接入 Claude Code、Cursor、Copilot、Gemini 等 14 个平台，是「省钱」这件事上最务实的开源工具之一。

**Why it matters**: The most direct cost of coding agents comes from massive command output flooding the context. rtk compresses that output through smart filtering, grouping, truncation, and deduplication — measured to cut a coding session from ~118k tokens to ~24k. Integrating with 14 platforms including Claude Code, Cursor, Copilot, and Gemini, it's one of the most pragmatic open-source tools for saving money.
