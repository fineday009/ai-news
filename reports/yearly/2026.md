## 9. thedotmack/claude-mem

⭐ 87.1k · 创建于 2025-08-31 · JavaScript · [链接](https://github.com/thedotmack/claude-mem)

**是什么**：为每一个 agent 提供跨会话的持久上下文——捕获 agent 在会话中做的一切并压缩存储，供后续调用。

**What it is**: Persistent context across sessions for every agent—capturing everything an agent does during a session and compressing it for later recall.

**为什么值得关注**：无状态、会话一关就「失忆」是当前 agent 的核心短板，记忆系统因此是本年度最刚需的方向之一。claude-mem 以近 8.7 万星证明了跨会话记忆的普遍需求，把「agent 记住过去」做成通用组件，对所有想让 agent 长期陪伴、持续积累的人都是关键拼图。

**Why it matters**: Statelessness—forgetting everything once a session closes—is a core weakness of today's agents, making memory one of the year's most essential directions. At nearly 87k stars, claude-mem proves the broad demand for cross-session memory, turning "agents remembering the past" into a reusable component—a key piece for anyone wanting agents that accompany and accumulate over time.
