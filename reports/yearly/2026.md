## 8. rtk-ai/rtk

⭐ 68.7k · Rust · 2026-01-22 创建 · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理，可将常见开发命令的 LLM token 消耗降低 60–90%；单一 Rust 二进制、零依赖。

**What it is**: A CLI proxy that reduces LLM token consumption by 60–90% on common dev commands; a single Rust binary with zero dependencies.

**为什么值得关注**：当编码 Agent 全面按量计费，「省 token」直接等于省钱。rtk 以极简的单二进制代理压缩命令输出与上下文，把成本大幅打下来，一年内近 7 万星，代表了「token 效率」这一年内快速壮大的实用工具细分。

**Why it matters**: When coding agents are billed by usage, "saving tokens" is saving money. rtk uses a minimal single-binary proxy to compress command output and context, cutting cost substantially; nearly 70k stars in a year make it a standout in the "token efficiency" niche that grew fast this year.
