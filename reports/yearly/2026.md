The reference point for the "self-hosted personal assistant" movement.

## 8. rtk-ai/rtk

⭐ ~72k · Rust · 创建于 2026-01-22 · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理，把常见开发命令的 LLM token 消耗降低 60–90%，单一 Rust 二进制。

**What it is**: A CLI proxy that reduces LLM token consumption by 60–90% on common dev commands — a single Rust binary.

**为什么值得关注**：编码 Agent 越用越贵，token 成本成了真金白银的痛点。rtk 从命令输出层做压缩与裁剪，直接砍掉大部分无效 token，思路新、见效快，是今年"降本"方向里最实用的基建之一。

**Why it matters**: Coding agents get expensive fast, and token cost is a real-money pain. rtk compresses and trims at the command-output layer, cutting most wasted tokens — a novel, fast-acting approach and one of the year's most practical cost-reduction infrastructures.
