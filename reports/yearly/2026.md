## 10. rtk-ai/rtk

⭐ 62,137 · 创建于 2026-01-22 · Rust · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理，在常见开发命令上把 LLM token 消耗降低 60–90%。

**What it is**: A CLI proxy that reduces LLM token consumption by 60–90% on common dev commands.

**为什么值得关注**：随着智能体编码普及，token 成本成为团队的真实账单。rtk 以代理方式截断冗余、压缩上下文，宣称大幅削减消耗。它与 headroom 等共同代表了今年"省 token = 省钱"的工程化潮流。

**Why it matters**: As agentic coding spreads, token cost becomes a real bill for teams. rtk sits as a proxy that trims redundancy and compresses context, claiming major savings. Together with the likes of headroom, it represents this year's engineering wave of "save tokens = save money."
