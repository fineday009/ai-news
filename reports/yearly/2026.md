> Looking back over the year, GitHub's dominant theme is "personal AI assistants + coding agents + memory/context systems": from open-source assistants and agent frameworks to persistent memory and token-saving tools, the top-starred projects are almost entirely the AI agent ecosystem; solid developer infrastructure like spec-kit and rtk fills the non-AI slots. This yearly edition is a snapshot, labeled with total stars and creation date, without per-period increments.

## 1. openclaw/openclaw

⭐ 379.8k · 新建于 2025-11-24 · TypeScript · [链接](https://github.com/openclaw/openclaw)

**是什么**：属于你自己的私人 AI 助手。任意操作系统、任意平台。「龙虾之道」。🦞

**What it is**: Your own personal AI assistant. Any OS. Any Platform. The lobster way. 🦞

**为什么值得关注**：以近 38 万星稳居本年度第一，是「自托管、属于你自己」的个人 AI 助手浪潮的旗帜性项目。跨平台、强调数据自有，回应了用户对把私人助手交给大厂云的普遍不安。

**Why it matters**: At nearly 380k stars, the year's clear number one and the flagship of the "self-hosted, own-your-data" personal AI assistant wave. Cross-platform and data-ownership-first, it answers widespread unease about handing a personal assistant to Big Tech's cloud.

## 3. github/spec-kit

⭐ 114.6k · 新建于 2025-08-21 · Python · [链接](https://github.com/github/spec-kit)

**是什么**：帮助你上手「规格驱动开发」（Spec-Driven Development）的工具包。💫

**What it is**: 💫 Toolkit to help you get started with Spec-Driven Development.

**为什么值得关注**：GitHub 官方出品，把「先写规格、再让 AI 实现」的方法论工程化，是这一年「如何与编码 agent 协作」讨论中最具分量的实践之一。对团队规范化 AI 辅助开发流程影响深远。

**Why it matters**: An official GitHub toolkit that operationalizes the "write the spec first, then let AI implement" methodology—one of the most substantial practices in this year's debate over how to collaborate with coding agents. It has deep influence on how teams formalize AI-assisted development.

## 4. karpathy/autoresearch

⭐ 88.0k · 新建于 2026-03-06 · Python · [链接](https://github.com/karpathy/autoresearch)

**是什么**：让 AI agent 在单 GPU 的 nanochat 训练上自动开展研究。

**What it is**: AI agents running research on single-GPU nanochat training automatically.

**为什么值得关注**：Andrej Karpathy 的项目，把「AI agent 自主做 ML 研究」这个最前沿、也最具想象力的方向做成了可上手的开源实验场，且刻意控制在单 GPU 规模，门槛友好。是探讨「递归自我改进」绕不开的一个实物。

**Why it matters**: An Andrej Karpathy project that turns "AI agents autonomously doing ML research"—one of the most frontier and imaginative directions—into a hands-on open-source playground, deliberately scoped to a single GPU for accessibility. A concrete artifact you can't avoid when discussing recursive self-improvement.

## 5. thedotmack/claude-mem

⭐ 83.6k · 新建于 2025-08-31 · JavaScript · [链接](https://github.com/thedotmack/claude-mem)

**是什么**：为每个 agent 提供跨会话的持久上下文——捕捉 agent 在会话中做的一切，用 AI 压缩后，把相关上下文重新注入未来的会话。兼容 Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCode 等。

**What it is**: Persistent Context Across Sessions for Every Agent — captures everything your agent does during sessions, compresses it with AI, and injects relevant context back into future sessions. Works with Claude Code, OpenClaw, Codex, Gemini, Hermes, Copilot, OpenCode + more.

**为什么值得关注**：「记忆」是贯穿全年的核心命题，claude-mem 是其中采用最广的方案之一，跨多家 agent 通用。它把「压缩 + 重注入上下文」做成即插即用的记忆层，直接缓解了长期协作中的「失忆」痛点。

**Why it matters**: Memory is a defining theme of the whole year, and claude-mem is one of the most widely adopted solutions, working across many agents. It packages "compress + reinject context" into a plug-and-play memory layer, directly easing the "amnesia" pain of long-term collaboration.

## 7. nexu-io/open-design

⭐ 68.7k · 新建于 2026-04-28 · TypeScript · [链接](https://github.com/nexu-io/open-design)

**是什么**：本地优先、开源的 Claude Design 替代品。原生桌面应用，259+ 技能、142+ 设计系统，覆盖网页/桌面/移动原型、幻灯片、图片、视频；沙箱预览，支持 HTML/PDF/PPTX/MP4 导出；兼容 Claude Code、OpenClaw、Codex、Cursor 等 17+ 种 CLI。

**What it is**: Local-first, open-source Claude Design alternative. Native desktop app, 259+ skills, 142+ design systems—covering web/desktop/mobile prototypes, slides, images, and videos; sandboxed preview with HTML/PDF/PPTX/MP4 export; compatible with Claude Code, OpenClaw, Codex, Cursor, and 17+ CLIs.

**为什么值得关注**：把「AI 做设计」从云端服务搬到本地优先的开源桌面应用，覆盖从原型到 PPT、视频的完整产出链路。是设计创作侧本年度最完整、最有野心的开源方案之一。

**Why it matters**: It moves "AI for design" from a cloud service to a local-first, open-source desktop app, covering the full output chain from prototypes to decks and videos. One of the year's most complete and ambitious open-source efforts on the design-creation side.

## 10. rtk-ai/rtk

⭐ 64.6k · 新建于 2026-01-22 · Rust · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理，在常见开发命令上把 LLM 的 token 消耗降低 60–90%。单个 Rust 二进制，零依赖。

**What it is**: CLI proxy that reduces LLM token consumption by 60-90% on common dev commands. Single Rust binary, zero dependencies.

**为什么值得关注**：「省 token」是贯穿全年、并在六月达到高潮的主题，rtk 用单文件 Rust 二进制把开发命令的 token 消耗砍掉 60–90%，工程极简、即插即用。是这一年「上下文经济学」最务实的代表之一。

**Why it matters**: "Saving tokens" is a theme that ran through the whole year and peaked in June; rtk uses a single-file Rust binary to cut token consumption on dev commands by 60-90%, minimalist and plug-and-play. One of the year's most pragmatic embodiments of "context economics."
