> 回望这一年（按过去 12 个月新建项目的总星标排序），主旋律无可争议是「Agent 基础设施」：从人人可用的个人 AI 助手（openclaw），到 agentic 技能框架与方法论（superpowers）、Agent 外壳性能优化系统（ECC），再到规格驱动开发（spec-kit）、多代理切换器（cc-switch）、跨会话记忆（claude-mem）、Agent 工具箱（pi）与省 token 代理（rtk）。开发者把这一年花在「怎么让 Agent 更省、更稳、更可复用」上。非 AI 阵营则由 tw93 的 Mac 终端利器 Mole 守住一席。

> Looking back over the year (ranked by total stars among repos created in the past 12 months), the dominant theme is unmistakably agent infrastructure: from a personal AI assistant for everyone (openclaw), to an agentic skills framework and methodology (superpowers) and an agent-harness performance system (ECC), through spec-driven development (spec-kit), a multi-agent switcher (cc-switch), cross-session memory (claude-mem), an agent toolkit (pi), and a token-saving proxy (rtk). Developers spent the year making agents cheaper, steadier, and more reusable — with tw93's Mac terminal tool Mole holding a spot for the non-AI camp.

## 7. thedotmack/claude-mem

Nearly 90k stars this year shows persistent memory has gone from nice-to-have to necessity.

## 9. rtk-ai/rtk

⭐ 74.4k · Rust · 创建于 2026-01-22 · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理，在常见开发命令上把 LLM 的 token 消耗降低 60–90%，单一 Rust 二进制。

**What it is**: A CLI proxy that reduces LLM token consumption by 60–90% on common dev commands — a single Rust binary.

**为什么值得关注**：这一年「token 成本」成了实打实的支出项，省 token 就是省钱。rtk 用一个轻量代理拦截并压缩喂给模型的命令输出，在日常开发场景里砍掉大半 token，还做成零依赖单二进制、易于接入。年内 7.4 万星，代表「AI 成本优化」正式成为一个独立且刚需的工具品类。

**Why it matters**: Token cost became a real line item this year, and saving tokens is saving money. rtk uses a lightweight proxy to intercept and compress command output fed to models, cutting most tokens in everyday dev workflows, shipped as a zero-dependency single binary that's easy to adopt. 74k stars this year marks "AI cost optimization" as a distinct, must-have tool category.
