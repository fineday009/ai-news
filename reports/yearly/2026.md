## 2. Graphify-Labs/graphify

⭐ 117,036 · Python · 创建于 2026-04-03 · [链接](https://github.com/Graphify-Labs/graphify)

**是什么**：把任意代码库连同文档、SQL schema、配置、PDF 一起转成可查询的知识图谱；本地确定性 AST 解析、每条边可解释、无需向量库。

**What it is**: Turns any codebase — with its docs, SQL schemas, configs and PDFs — into a queryable knowledge graph, using local deterministic AST parsing, every edge explained, and no vector store.

**为什么值得关注**：它给编码代理提供了「结构化、可解释」的代码理解层，规避了向量检索的幻觉与黑盒；面向 Claude Code、Cursor、Codex、Gemini CLI 通用，是今年「代理理解代码」这一命题下最有分量的开源答案之一。

**Why it matters**: It gives coding agents a structured, explainable layer for code comprehension, sidestepping the hallucination and opacity of vector retrieval; working across Claude Code, Cursor, Codex and Gemini CLI, it's one of the year's weightiest open answers to "how agents understand code."
