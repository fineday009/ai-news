## 3. Graphify-Labs/graphify

⭐ 109.3k（总 star）· 创建于 2026-04-03 · Python · [链接](https://github.com/Graphify-Labs/graphify)

**是什么**：把任意代码库连同文档、SQL schema、配置、PDF 变成可查询的知识图谱；为 Claude Code、Cursor、Codex、Gemini CLI 提供 `/graphify` 技能，采用本地确定性 AST 解析、每条边都可解释、无需向量库。

**What it is**: Turns any codebase—with its docs, SQL schemas, configs, and PDFs—into a queryable knowledge graph. A `/graphify` skill for Claude Code, Cursor, Codex, and Gemini CLI: local deterministic AST parsing, every edge explained, no vector store.

**为什么值得关注**：多数"代码理解"工具依赖向量检索，结果难解释也不确定。graphify 反其道用确定性 AST 构图，"每条边都能说清为什么存在"，既可复现又可审计。它代表了"让 Agent 真正读懂大型代码库"这一年度核心难题的一个扎实答案。

**Why it matters**: Most "code understanding" tools rely on vector retrieval that is opaque and non-deterministic. graphify instead builds graphs from deterministic AST parsing, where "every edge can be explained," making it reproducible and auditable. It is a solid answer to one of the year's core problems—getting agents to truly understand large codebases.
