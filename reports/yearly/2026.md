## 1. openclaw/openclaw

⭐ 391.9k · 2025-11-24 创建 · TypeScript · [链接](https://github.com/openclaw/openclaw)

**是什么**：一个运行在你自己电脑上的开源 AI 助理——状态、记忆与凭据都留在本地硬件。它以"网关（Gateway）"形式串起各类聊天渠道、工具与模型供应商，可随意切换模型、用技能和插件扩展；支持 Discord、Slack、Telegram、WhatsApp、iMessage，以及 macOS/iOS/Android/Windows/Linux 原生应用。

**What it is**: An open-source AI assistant that runs on your own computer, keeping state, memory and credentials on your hardware. It runs as a "Gateway" linking chat channels, tools and model providers — swap models freely, extend with skills and plugins — and supports Discord, Slack, Telegram, WhatsApp and iMessage plus native apps for macOS, iOS, Android, Windows and Linux.

**为什么值得关注**：近 39 万星、8 万多 fork，是 2026 年最具人气的开源项目之一。它以"隐私优先、无付费档、数据自持"的姿态，给出了一条与云端大厂助理截然不同的路线——把个人 AI 的控制权彻底交还用户，是年度最具代表性的"主权 AI"实践。

**Why it matters**: With ~392k stars and 82k+ forks, it's one of 2026's most popular open-source projects. Its "privacy-first, no paid tier, own-your-data" stance offers a sharp alternative to cloud-vendor assistants — handing control of personal AI fully back to the user, the year's defining "sovereign AI" practice.

**Why it matters**: One of the year's largest repos by stars, it mirrors a shared user demand — a cross-tool, reusable "behavior and memory layer" instead of reinventing the wheel in every agent. It elevates "how to make coding agents more reliable" from personal lore to shareable methodology.

**Why it matters**: It hands the high-barrier craft of reverse engineering to agent orchestration, dramatically lowering the cost of going from behavior observation to binary analysis — a flagship of the year's "AI + security/RE" thread. It brings real value to security research, vulnerability analysis and education.

## 5. Graphify-Labs/graphify

⭐ 126.2k · 2026-04-03 创建 · Python · [链接](https://github.com/Graphify-Labs/graphify)

**是什么**：把任意代码库——连同文档、SQL schema、配置与 PDF——变成可查询的知识图谱。以 `/graphify` 技能形式接入 Claude Code、Cursor、Codex、Gemini CLI 等，采用本地确定性 AST 解析，每条边都有解释，不依赖向量库。

**What it is**: Turns any codebase — with its docs, SQL schemas, configs and PDFs — into a queryable knowledge graph. Available as a `/graphify` skill for Claude Code, Cursor, Codex and Gemini CLI, it uses local deterministic AST parsing, explains every edge, and needs no vector store.

**为什么值得关注**：它针对"Agent 读不懂大型代码库"的核心痛点，给出一条可解释、可审计、无需向量检索的路线。对要让 AI 真正理解复杂工程、而非靠 RAG 猜测的团队，这种确定性知识图谱是更可靠的底座。

**Why it matters**: It targets the core pain of "agents can't grasp large codebases" with an explainable, auditable route that skips vector retrieval. For teams who want AI to truly understand complex engineering rather than guess via RAG, a deterministic knowledge graph is a sturdier foundation.

## 8. stablyai/orca

⭐ 91.7k · 2026-03-17 创建 · TypeScript · [链接](https://github.com/stablyai/orca)

**是什么**：面向"一队并行 Agent"的 ADE（Agent 开发环境）——可用你自己的订阅运行任意编码 Agent，支持桌面、移动与远程运行时，内置 worktree、并行编排等。

**What it is**: An ADE (agent development environment) for working with a fleet of parallel agents — run any coding agent with your own subscription, across desktop, mobile and remote runtimes, with worktrees and parallel orchestration built in.

**为什么值得关注**：当"一次跑一个 Agent"已不够用，orca 把"同时驾驭一群 Agent"做成了 IDE 级的工作台，是并行智能体工程化的代表。对追求吞吐、想把编码 Agent 当团队来管的开发者，它提供了成熟的编排与可视化。

**Why it matters**: When "one agent at a time" is no longer enough, orca turns "driving a fleet of agents" into an IDE-grade workbench — a standard-bearer for productionizing parallel agents. For developers chasing throughput who want to manage coding agents like a team, it offers mature orchestration and visibility.
