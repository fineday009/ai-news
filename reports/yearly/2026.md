## 4. Graphify-Labs/graphify

⭐ 128k · Python · 创建于 2026-04-03 / created 2026-04-03 · [链接](https://github.com/Graphify-Labs/graphify)

**是什么**：把任意代码库连同文档、SQL schema、配置、PDF，转成可查询的知识图谱——本地确定性 AST 解析，每条边都有解释，不依赖向量库。

**What it is**: Turn any codebase—plus its docs, SQL schemas, configs and PDFs—into a queryable knowledge graph: local deterministic AST parsing, every edge explained, no vector store.

**为什么值得关注**：今年"让 Agent 真正读懂代码库"方向里最硬核的一个。它不走向量检索的玄学路线，而是用确定性 AST 解析构建可解释的图谱，直面了 RAG 在大型代码库上"检索不准、来源不明"的核心痛点。

**Why it matters**: The most rigorous entry this year in the "let agents truly understand a codebase" direction. Instead of the black-box vector-retrieval route, it builds an explainable graph via deterministic AST parsing, confronting RAG's core pain on large codebases—imprecise retrieval and murky provenance.

## 9. rtk-ai/rtk

⭐ 84k · Rust · 创建于 2026-01-22 / created 2026-01-22 · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理，在常见开发命令上把 LLM token 消耗降低 60–90%，单个 Rust 二进制、零依赖。

**What it is**: A CLI proxy that cuts LLM token consumption by 60–90% on common dev commands—a single Rust binary, zero dependencies.

**为什么值得关注**：今年"省 token"成了显学（caveman、headroom、billion-context 等层出不穷），rtk 是其中最务实的一支：不玩梗、不改模型，只在 CLI 层把冗余输出压掉。当 Agent 调用越来越贵，这类节流基建直接关系到能不能用得起。

**Why it matters**: "Save tokens" became a whole genre this year (caveman, headroom, billion-context…), and rtk is the most pragmatic of them: no gimmicks, no model changes, just squeezing redundant output at the CLI layer. As agent calls get pricier, this kind of throttling infra directly decides whether you can afford to run them.
