> Generated 2026-06-24 (yearly snapshot of high-star repos created in the past year). The undisputed throughline of the year is "personal / self-hosted agents" — from 380k-star openclaw, to superpowers baking engineering methodology into a skills framework, to the self-growing hermes-agent. A full ecosystem formed around agent memory, design, prediction, toolchains and multi-harness switchers; a few non-agent projects (spec-driven dev, containers) earned their spots on raw merit.

## 1. openclaw/openclaw

⭐ 380,164 · TypeScript · 创建于 2025-11-24 · [链接](https://github.com/openclaw/openclaw)

**是什么**：你自己的个人 AI 助手，任意操作系统、任意平台——"龙虾之道"🦞。本地优先、自托管，作为统一网关接入 WhatsApp、Telegram、Slack、Discord 等你已经在用的消息平台。

**What it is**: Your own personal AI assistant. Any OS. Any Platform. The lobster way. 🦞 Local-first and self-hosted, it acts as a unified gateway across WhatsApp, Telegram, Slack, Discord and the messaging channels you already use.

**为什么值得关注**：仅创建半年余便冲到 38 万星，是本年度的现象级项目。它精准踩中"想要一个私有、常驻、够快的个人 AI"这一普遍诉求，把隐私、速度、本地优先做成卖点，并围绕它长出了一整套生态与文化（"龙虾"梗），是 2026 年自托管智能体浪潮的旗帜。

**Why it matters**: It hit 380k stars in barely half a year — the phenomenon of the year. It nails the broad desire for a private, always-on, fast personal AI, selling privacy, speed and local-first, and has grown an entire ecosystem and subculture (the "lobster" meme) around itself. The banner project of 2026's self-hosted agent wave.

## 2. obra/superpowers

⭐ 237,029 · Shell · 创建于 2025-10-09 · [链接](https://github.com/obra/superpowers)

**是什么**：一套"管用"的智能体技能框架兼软件开发方法论，强制让编码智能体走纪律化流程：设计校验 → 详细规划 → 测试驱动实现 → 代码审查闭环，适配 Claude Code、Cursor、Copilot CLI、Gemini 等。

**What it is**: "An agentic skills framework & software development methodology that works." It enforces a disciplined process on coding agents — design validation → detailed planning → test-driven implementation → review loop — across Claude Code, Cursor, Copilot CLI, Gemini and more.

**为什么值得关注**：在"AI 一把梭、不做规划"的乱象里，它把资深工程师的工作纪律产品化，从根上提升智能体产出的可靠性。23 万星说明业界共识：让智能体强不只靠模型，更靠方法论与流程约束。它定义了今年"agent skills"这一品类的标杆。

**Why it matters**: Against the "AI just dives in, no planning" chaos, it productizes a senior engineer's discipline, raising the reliability of agent output at the root. 237k stars reflect a consensus: making agents strong isn't only about the model but about methodology and process constraints. It set the standard for this year's "agent skills" category.

## 3. NousResearch/hermes-agent

⭐ 201,062 · Python · 创建于 2025-07-22 · [链接](https://github.com/NousResearch/hermes-agent)

**是什么**：一个会"随你成长"的开源智能体——从经验中自己提炼并改进技能，跨会话保持长期记忆，可从 5 美元 VPS 一路跑到 Serverless。

**What it is**: An open-source AI agent that "grows with you" — it creates and improves skills from experience, keeps persistent memory across sessions, and runs anywhere from a $5 VPS to serverless.

**为什么值得关注**：出自口碑扎实的 Nous Research，是本年度"自学习智能体"路线的代表作。它把"无状态、上下文受限"这个老问题，用内置学习闭环正面解决，20 万星的长期热度证明社区把它当作严肃的自托管智能体基座。

**Why it matters**: From the well-regarded Nous Research, it's the flagship of this year's "self-learning agent" line. It tackles the old stateless, context-limited problem head-on with a built-in learning loop; sustained popularity at 200k stars shows the community treats it as a serious self-hosted agent substrate.

## 4. github/spec-kit

⭐ 115,060 · Python · 创建于 2025-08-21 · [链接](https://github.com/github/spec-kit)

**是什么**：GitHub 官方推出的工具包，帮助你上手"规范驱动开发"（Spec-Driven Development）。

**What it is**: A GitHub toolkit to help you get started with Spec-Driven Development.

**为什么值得关注**：非智能体阵营里最有分量的方法论工具之一。在 AI 大量产代码的时代，"先把规范写清楚、再让工具/智能体落地"成为保证质量的关键路径；GitHub 亲自背书让 spec-driven 从理念走向标准化实践，影响面覆盖整个开发流程。

**Why it matters**: One of the weightiest methodology tools outside the agent camp. In an era of AI mass-producing code, "nail the spec first, then let tools/agents implement" becomes a key path to quality; GitHub's own backing moves spec-driven from idea to standardized practice, touching the entire development workflow.

## 7. thedotmack/claude-mem

⭐ 83,963 · JavaScript · 创建于 2025-08-31 · [链接](https://github.com/thedotmack/claude-mem)

**是什么**：为每个智能体提供跨会话的持久上下文——捕捉智能体做过的一切，让记忆在会话之间延续。

**What it is**: Persistent context across sessions for every agent — captures everything your agent does so memory carries over between sessions.

**为什么值得关注**：智能体最大的体验断点就是"一关窗口全忘光"。claude-mem 把记忆持久化做成通用插件层，让智能体真正"记得上次聊到哪"。它是今年"智能体记忆"这一关键基础设施类别的代表，与各类编码智能体广泛搭配使用。

**Why it matters**: An agent's biggest UX break is "close the window, forget everything." claude-mem makes persistent memory a general plugin layer so agents actually "remember where you left off." It's the representative of this year's key "agent memory" infrastructure category, widely paired with coding agents.

## 9. 666ghj/MiroFish

⭐ 67,064 · Python · 创建于 2025-11-26 · [链接](https://github.com/666ghj/MiroFish)

**是什么**：一个简洁通用的群体智能引擎，号称"预测一切"。上传种子信息并描述预测需求，系统部署成千上万个有独立性格与记忆的智能体，模拟复杂互动来推演未来结果。

**What it is**: A simple, universal swarm-intelligence engine that claims to "predict anything." Upload seed info and describe what you want predicted; it deploys thousands of agents with distinct personalities and memories to simulate complex interactions and forecast outcomes.

**为什么值得关注**：它代表了今年一条独特的支线——不只是"单个智能体干活"，而是"群体智能体做仿真预测"。把多智能体模拟用于金融、政策、创意等场景的无风险推演，思路新颖，7 万星说明这个方向获得了真实关注。

**Why it matters**: It represents a distinctive side-thread of the year — not just "one agent does work" but "swarms of agents simulate to predict." Applying multi-agent simulation to risk-free scenario testing in finance, policy and creative domains is a novel angle, and 67k stars show the direction drew real attention.
