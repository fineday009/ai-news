## 4. Graphify-Labs/graphify

⭐ 99.8k · Python · 创建于 2026-04-03 · [链接](https://github.com/Graphify-Labs/graphify)

**是什么**：把任意代码库连同其文档、SQL 架构、配置与 PDF 转化为可查询的知识图谱。

**What it is**: Turn any codebase — with its docs, SQL schemas, configs and PDFs — into a queryable knowledge graph.

**为什么值得关注**：Agent 要理解大型代码库，光靠向量检索不够；graphify 用知识图谱把代码与文档的结构关系显式化，为 Agent 提供更可靠的「代码理解」底座，是 2026 年代码智能方向的代表。

**Why it matters**: For agents to understand large codebases, vector search alone isn't enough; graphify makes structural relationships explicit as a knowledge graph, giving agents a more reliable "code comprehension" substrate — a landmark in 2026 code intelligence.

## 10. rtk-ai/rtk

⭐ 74.2k · Rust · 创建于 2026-01-22 · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理层，在常见开发命令上把 LLM token 消耗降低 60–90%；单个 Rust 二进制、零依赖。

**为什么值得关注**：Agent 编码成本高企的当下，rtk 用一层轻量代理大幅削减 token 用量，几乎零成本接入，直击「用 Agent 太烧钱」的现实痛点，是效率工具里的年度黑马。

**Why it matters**: With agent coding costs high, rtk slashes token usage via a lightweight proxy at near-zero integration cost, hitting the real pain that "agents burn money" — an efficiency-tool dark horse of the year.
