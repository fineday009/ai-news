## 1. openclaw/openclaw

Any Platform. 🦞" A self-hosted open-source personal AI assistant whose local Gateway acts as the control plane for sessions, tools, and channels — connecting Discord, Slack, Telegram, and WhatsApp, with native apps across platforms, supporting both Claude and local models.

**为什么值得关注**：今年星标最高的项目之一，提交与 PR 历史庞大、治理与安全策略齐备（把入站消息视为不可信、提供沙箱指引）。它代表了"把个人助手跑在自己机器上、真正去动手做事"这一路线的集大成者。

**Why it matters**: One of the year's most-starred projects, with a large commit/PR history and mature governance and security posture (treating inbound messages as untrusted, with sandboxing guidance). It's the fullest expression of the "run your personal assistant on your own machine and actually take actions" approach.

**是什么**：CLI 代理，在常见开发命令上把 LLM token 消耗降低 60–90%，单个 Rust 二进制、零依赖。

**What it is**: A CLI proxy that reduces LLM token consumption by 60–90% on common dev commands — a single Rust binary with zero dependencies.

**为什么值得关注**：当编码 Agent 的真实成本越来越多地由 token 决定，省 token 就是省钱。它以极简形态（一个二进制、零依赖）切入这个痛点，是今年"Agent 经济学"基础设施的代表。

**Why it matters**: As the real cost of coding agents is increasingly set by tokens, saving tokens means saving money. Its minimalist form (one binary, zero dependencies) targets that pain point directly — emblematic of this year's "agent economics" infrastructure.
