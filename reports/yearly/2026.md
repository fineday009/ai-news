## 10. rtk-ai/rtk

⭐ 62,327 · 创建于 2026-01-22 · Rust · [链接](https://github.com/rtk-ai/rtk)

**是什么**：一个 CLI 代理，在常见开发命令上把大模型 token 消耗降低 60–90%。

**What it is**: A CLI proxy that reduces LLM token consumption by 60–90% on common dev commands.

**为什么值得关注**：随着 Agent 把命令行包进每一步操作，token 成本成了真金白银的痛点。rtk 用 Rust 写成的代理层在不改变工作流的前提下大幅压缩 token，与 headroom、caveman 等「省 token」工具共同构成了今年最务实的成本优化赛道。

**Why it matters**: As agents wrap the command line into every step, token cost becomes a real-money pain point. rtk's Rust proxy layer compresses tokens sharply without changing the workflow, and together with token-savers like headroom and caveman it forms this year's most pragmatic cost-optimization lane.
