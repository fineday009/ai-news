## 1. openclaw/openclaw

⭐ 384.5k（2025-11-24 创建）· TypeScript · [链接](https://github.com/openclaw/openclaw)

**是什么**：你自己的私人 AI 助手，跨任意操作系统与平台——"the lobster way"（龙虾之道）🦞，强调自主掌控数据。

**What it is**: Your own personal AI assistant, on any OS and any platform — "the lobster way" 🦞 — with a focus on owning your data.

**为什么值得关注**：以 38 万 star 稳居本年度榜首，是开源社区对"人人可自托管的通用 AI 助手"最响亮的回应。它围绕本地/自托管、数据自主构建生态，催生了大量围绕它的工具（cc-switch、claude-mem 等都把它列为支持对象），俨然成为 2026 年开源 AI 助手的中心节点。

**Why it matters**: At 384k stars it tops the year by a wide margin — the open community's loudest answer to "a general AI assistant anyone can self-host." Built around local/self-hosted, data-ownership principles, it spawned an ecosystem of tooling (cc-switch, claude-mem, and others list it as supported), effectively becoming the hub of open-source AI assistants in 2026.

**Why it matters**: Official from GitHub, 120k+ stars. In a year of rampant "vibe coding" and uneven AI-generated code, spec-kit argues for "write the spec clearly first, then let AI implement," turning PRDs/specs into an executable workflow — one of the most influential official takes on software-engineering methodology in the AI era.

## 3. farion1231/cc-switch

⭐ 122.3k（2025-08-04 创建）· Rust · [链接](https://github.com/farion1231/cc-switch)

**是什么**：跨平台的桌面一站式助手，统一管理 Claude Code、Codex、OpenCode、OpenClaw、Grok Build 与 Hermes Agent。

**What it is**: A cross-platform desktop all-in-one assistant to manage Claude Code, Codex, OpenCode, OpenClaw, Grok Build, and Hermes Agent.

**为什么值得关注**：12 万+ star。当开发者手上同时装了五六个 coding agent、各自有配置、密钥与提供商时，切换和管理成了新麻烦。cc-switch 用 Rust/Tauri 做了统一的桌面管理层，正是"多 agent 并存"这一年催生出的典型工具，实用性极强。

**Why it matters**: 120k+ stars. When developers run five or six coding agents at once — each with its own config, keys, and providers — switching and managing becomes the new headache. cc-switch builds a unified desktop management layer in Rust/Tauri, a hallmark tool born from the "many-agents-coexist" year, and intensely practical.

## 5. thedotmack/claude-mem

⭐ 89.0k（2025-08-31 创建）· JavaScript · [链接](https://github.com/thedotmack/claude-mem)

**是什么**：为各类 agent 提供"跨会话持久记忆"——捕获 agent 在会话中做的一切，用 AI 压缩后，在未来会话中注入相关上下文。

**What it is**: Persistent context across sessions for every agent — captures everything an agent does, compresses it with AI, and injects relevant context into future sessions.

**为什么值得关注**：89k star。"上下文丢失"是当前所有 coding agent 的通病，claude-mem 用记忆引擎+向量检索把过往会话沉淀成可复用的长期记忆，兼容 Claude Code、OpenClaw、Codex、Gemini 等一众客户端。它是这一年"给 agent 装上记忆"方向最受欢迎的方案。

**Why it matters**: 89k stars. "Context loss" plagues every coding agent today; claude-mem uses a memory engine plus vector retrieval to distill past sessions into reusable long-term memory, working with Claude Code, OpenClaw, Codex, Gemini, and more. It's the year's most popular approach to "giving agents memory."
