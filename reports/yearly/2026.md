## 1. openclaw/openclaw

⭐ 累计约 390,000 · 过去一年内新建 · TypeScript · [链接](https://github.com/openclaw/openclaw)

**是什么**：一个「真正会做事」的通用 AI，宣称支持任意操作系统、任意平台。🦞

**What it is**: "The AI that really does things" — a general-purpose agent claiming to run on any OS and any platform. 🦞

**为什么值得关注**：以约 39 万 star 领跑全年，是过去一年「通用 Agent」叙事的旗帜性项目；其跨平台、可执行真实任务的定位，代表了本年度开源社区对「能干活的 AI」最强烈的期待与投入。

**Why it matters**: Leading the year at ~390k stars, it's the flagship of the past year's "general agent" narrative; its cross-platform, does-real-work positioning captures the community's strongest expectation of and investment in AI that actually gets things done.

⭐ 累计约 222,000 · 过去一年内新建 · TypeScript · [链接](https://github.com/deepseek-ai/deepseek-harness)

**What it is**: DeepSeek's agent harness built on the principle "Everything is a Plugin."

**Why it matters**: It makes the agent runtime fully pluggable — capabilities, tools and models all swappable — and as a top model vendor's official harness it's both an ecosystem entry point and a definition of an extensible agent architecture.

## 6. JustVugg/colibri

⭐ 累计约 28,700 · 过去一年内新建 · C · [链接](https://github.com/JustVugg/colibri)

**是什么**：在你现有硬件上运行前沿 MoE 大模型——纯 C、零依赖，专家权重从磁盘流式加载。

**What it is**: Run frontier MoE models on hardware you already own — pure C, zero dependencies, experts streamed from disk.

**为什么值得关注**：用「磁盘流式加载专家」的巧思，把巨型 MoE 模型带到内存受限的普通设备上，纯 C 零依赖极易部署；是本年度本地推理领域最务实的突破之一。

**Why it matters**: With its disk-streaming-of-experts trick it brings giant MoE models to ordinary memory-limited devices, and pure-C zero-dependency makes deployment trivial — one of the year's most pragmatic local-inference breakthroughs.

## 10. firecrawl/anydoc

⭐ 累计约 21,300 · 过去一年内新建 · Rust · [链接](https://github.com/firecrawl/anydoc)

**是什么**：把 Word、PowerPoint、Excel、OpenDocument、RTF、EPUB、CSV、PDF 转成干净 Markdown，Rust 实现，含 Node.js 与 Python 绑定。

**What it is**: Converts Word, PowerPoint, Excel, OpenDocument, RTF, EPUB, CSV and PDF to clean Markdown — built in Rust with Node.js and Python bindings.

**为什么值得关注**：LLM/RAG 时代「先把文档转成干净 Markdown」是刚需，anydoc 用 Rust 追求性能与稳定、格式覆盖广、绑定齐全，是本年度数据预处理工具里的高质量代表。

**Why it matters**: In the LLM/RAG era, "convert documents to clean Markdown first" is a hard requirement; anydoc pursues speed and robustness in Rust with broad format coverage and ready bindings — a high-quality representative among this year's preprocessing tools.
