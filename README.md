# ai-news

GitHub 最有价值开源项目精选（以 AI 为主、不限于 AI），由 Claude Code skill 自动生成。

- **Skill**：`.claude/skills/github-digest/` — 抓取 GitHub Trending + Search API 候选，精选 10 个项目并生成中文榜单
- **报告**：`reports/{daily,weekly,monthly,yearly}/`
- **定时**：云端 routine 每天 11:00（Asia/Shanghai）自动生成日报并提交到本仓库

手动使用：在 Claude Code 中运行 `/github-digest`（可加 `weekly` / `monthly` / `yearly`）。
