# ai-news

GitHub 最有价值开源项目精选（以 AI 为主、不限于 AI），中英双语，由 Claude Code skill 自动生成。

GitHub's most valuable open-source projects (AI-focused but not AI-only), bilingual (Chinese/English), auto-generated by a Claude Code skill.

## 报告 · Reports

每天 11:00（Asia/Shanghai）用最新数据全量更新四个视图：

| 视图 | 路径 | 更新方式 |
|---|---|---|
| 📅 日榜 Daily | [`reports/daily/`](reports/daily/) | 每天新增一份 |
| 📆 周榜 Weekly | [`reports/weekly/`](reports/weekly/) | 当周快照，每天刷新 |
| 🗓️ 月榜 Monthly | [`reports/monthly/`](reports/monthly/) | 当月快照，每天刷新 |
| 🏆 年榜 Yearly | [`reports/yearly/`](reports/yearly/) | 当年快照，每天刷新 |

每份报告精选 10 个项目，附 star 动量、一句话简介和推荐理由。

## Skill

`.claude/skills/github-digest/` — 抓取 GitHub Trending + Search API 候选（约 50 个），按"AI 优先、实质优先、看动量和新意"的标准精选。

手动使用：在 Claude Code 中运行 `/github-digest`（可加 `weekly` / `monthly` / `yearly` / `all`）。
